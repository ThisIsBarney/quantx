REST API¶

QuantX Engine ships a FastAPI REST server that exposes the C++ solver backend and most Python modules as HTTP endpoints.

Starting the server¶

cd quantx/
uvicorn server.main:app --reload --port 8000

Interactive Swagger UI is available at http://localhost:8000/docs.

Authentication¶

When the QUANTX_API_KEY environment variable is set, all /jobs/* endpoints require a bearer token:

Authorization: Bearer <api-key>

Obtain a token via POST /auth/token (see /docs for the schema).
