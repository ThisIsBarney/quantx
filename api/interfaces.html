Interfaces & Integrations¶

Modules providing interoperability with external frameworks and tools.

PennyLane Plugin¶

Register QuantX as a PennyLane device (requires quantx-engine[pennylane]):

import pennylane as qml

dev = qml.device("quantx.statevector", wires=4)

@qml.qnode(dev)
def circuit():
    qml.Hadamard(0)
    qml.CNOT(wires=[0, 1])
    return qml.expval(qml.PauliZ(0))

print(circuit())

PennyLane device plugin for QuantX.

Usage:

import pennylane as qml
from quantx_engine.pennylane_plugin import QuantXDevice

dev = QuantXDevice(wires=3)

@qml.qnode(dev)
def circuit(x):
    qml.RX(x, wires=0)
    qml.CNOT(wires=[0, 1])
    return qml.expval(qml.PauliZ(0))

print(circuit(0.5))

For proper qml.device("quantx.statevector", ...) support the package must be installed so that its entry-point is visible to PennyLane:

[project.entry-points."pennylane.plugins"]
"quantx.statevector" = "quantx_engine.pennylane_plugin:QuantXDevice"

References

[1]

Bergholm, V. et al. (2022). PennyLane: Automatic differentiation of hybrid quantum-classical computations. arXiv:1811.04968. https://doi.org/10.48550/arXiv.1811.04968

[2]

Schuld, M. et al. (2019). Evaluating analytic gradients on quantum hardware. Phys. Rev. A 99, 032331. https://doi.org/10.1103/PhysRevA.99.032331

Qiskit V2 Primitives¶

Estimator + Sampler hardware-agnostic primitives — M85.

Provides:

  • SparsePauliOp: lightweight observable specification (Pauli tensor products with complex coefficients).

  • Estimator: compute ⟨ψ|O|ψ⟩ expectation values for circuits and observables, with optional noise and shot sampling.

  • Sampler: sample quasi-probability distributions from circuits.

  • EstimatorResult, SamplerResult: typed result containers.

Both primitives use a pure-NumPy statevector simulator (noiseless default) or a density-matrix simulator when a NoiseModel is supplied. No C++ engine binary is required.

Qubit ordering convention (same as Qiskit): qubit 0 is the least-significant bit of the statevector index. Pauli strings are written MSB-first, so "ZI" means Z on qubit 1, I on qubit 0 (matching the index ordering of the computational basis ket |q1 q0⟩).

Quick reference:

from quantx_engine.primitives import Estimator, Sampler, SparsePauliOp

bell = {
    "n_qubits": 2,
    "operations": [
        {"name": "h",  "qubits": [0]},
        {"name": "cx", "qubits": [0, 1]},
    ],
}

# Exact expectation value  ⟨Bell|ZZ|Bell⟩ = 1
result = Estimator().run([bell], [SparsePauliOp("ZZ")])
print(result.values)  # [1.]

# Probability distribution (exact)
sresult = Sampler().run([bell])
print(sresult.quasi_dists[0])  # {0: 0.5, 3: 0.5}  (|00⟩ and |11⟩)

References

[1]

Qiskit Community (2023). Qiskit: An open-source framework for quantum computing. Zenodo. https://doi.org/10.5281/zenodo.2573505 (Estimator/Sampler V2 primitives specification)

[2]

Bravyi, S. & Gosset, D. (2016). Improved classical simulation of quantum circuits dominated by Clifford gates. Phys. Rev. Lett. 116, 250501. https://doi.org/10.1103/PhysRevLett.116.250501

class quantx_engine.primitives.Estimator(noise_model=None, shots=None, seed=None)[source]¶

Bases: object

Hardware-agnostic expectation-value estimator.

Computes ⟨ψ|O|ψ⟩ for each (circuit, observable) pair using a pure-NumPy statevector (noiseless) or density-matrix (noisy) simulator.

Parameters:

  • noise_model – Optional NoiseModel instance. When provided a density-matrix simulation is used; otherwise the computation is exact.

  • shots (int | None) – When positive, draw shots measurement outcomes and estimate the expectation value empirically (adds shot noise). None or 0 → exact value.

  • seed (int | None) – Random seed for reproducible shot sampling.

Example

from quantx_engine.primitives import Estimator, SparsePauliOp

bell = {
    "n_qubits": 2,
    "operations": [
        {"name": "h",  "qubits": [0]},
        {"name": "cx", "qubits": [0, 1]},
    ],
}
result = Estimator().run([bell], ["ZZ"])
# result.values ≈ [1.0]

Jupyter Widgets¶

Interactive visualisation widgets for Jupyter notebooks (requires ipywidgets).

M117: Jupyter interactive widgets for QuantX.

Provides three rich notebook widgets for interactive circuit editing, Bloch-sphere visualisation, and job monitoring. All widgets degrade gracefully when running outside Jupyter (no hard dependency on ipywidgets or anywidget — their absence raises WidgetError with an actionable message).

  • CircuitWidget — drag-and-drop gate palette + circuit grid. Tracks gate placements and exports the final circuit as a list of {"gate": str, "qubits": list[int]} dicts.

  • BlochSphereWidget — live 3-D Bloch-sphere rendering from a single-qubit statevector. Updates continuously while the user drags a time slider.

  • JobMonitorWidget — polls a job-store URL and displays a progress bar with status chips.
