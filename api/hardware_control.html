Hardware & Control¶

Modules for pulse-level simulation, optimal control, and hardware-specific noise characterisation.

Pulse-Level Simulation¶

Drive pulse scheduling, drag pulses, frame tracking.

Pulse-level quantum simulator — M89.

Simulates time evolution under a time-dependent Hamiltonian

H(t) = H₀ + Σ_j [Re(Ω_j(t))/2 · σx_j + Im(Ω_j(t))/2 · σy_j]

in the rotating frame. H₀ = Σ_j Δ_j/2 · σz_j where Δ_j = ω_j − ω_drive_j is the qubit–LO detuning.

All frequencies / amplitudes share the same angular-frequency unit (e.g. rad/ns). T1 / T2 times are in the matching time unit (e.g. ns).

References

[1]

Allen, L. & Eberly, J. H. (1987). Optical Resonance and Two-Level Atoms. Dover Publications. ISBN 978-0-486-65533-4. (Bloch equations, rotating frame, DRAG pulses)

[2]

Krantz, P. et al. (2019). A quantum engineer’s guide to superconducting qubits. Appl. Phys. Rev. 6, 021318. https://doi.org/10.1063/1.5089550

[3]

Motzoi, F. et al. (2009). Simple pulses for elimination of leakage in weakly anharmonic qubits. Phys. Rev. Lett. 103, 110501. https://doi.org/10.1103/PhysRevLett.103.110501

Physical validation¶

Pi pulse (Gaussian, area = pi): drives |0> -> |1> with fidelity 1.0 in the absence of decoherence (ideal two-level system). DRAG suppression: derivative correction eliminates leakage to |2> to first order in 1/anharmonicity [Motzoi2009].

quantx_engine.pulse.pi_pulse_area(sigma)[source]¶

Return the Gaussian amplitude that gives a π-rotation for the given σ.

For H(t) = Ω(t)/2 · σx, the π condition is ∫ Ω dt = π. Gaussian area = amp · σ · √(2π), so amp = π / (σ · √(2π)).

Optimal Control (GRAPE / CRAB)¶

Quantum Optimal Control — M84.

Implements two pulse-shaping algorithms:

  • GRAPESolver — Gradient Ascent Pulse Engineering (Khaneja et al. 2005). Computes analytical gradients of the gate fidelity with respect to piecewise- constant control amplitudes and performs gradient ascent.

  • CRABSolver — Chopped Random Basis (Doria et al. 2011). Parameterises each control as a sum of random Fourier harmonics and optimises the scalar coefficients with Nelder-Mead (gradient-free).

Both solvers work with pure-NumPy exact density-matrix / propagator arithmetic. Matrix exponentials are computed via eigendecomposition of the (Hermitian) total Hamiltonian at each time step, giving exact propagators for any step size.

Quick reference:

import numpy as np
from quantx_engine.optimal_control import GRAPESolver

# Drive a single qubit from |0⟩ to |1⟩ using an X-rotation
X = np.array([[0,1],[1,0]], dtype=complex)
Z = np.array([[1,0],[0,-1]], dtype=complex)
solver = GRAPESolver(
    H_drift=0.5 * Z,       # free precession along Z
    H_controls=[X],        # one control field along X
    U_target=np.array([[0,1],[1,0]], dtype=complex),  # X gate
    n_steps=20,
    total_time=math.pi,
)
result = solver.run(n_iterations=200, learning_rate=0.5)
print(f"Fidelity: {result.fidelity_history[-1]:.6f}")   # → ≈ 1.0

References

[1]

Khaneja, N. et al. (2005). Optimal control of coupled spin dynamics: Design of NMR pulse sequences by gradient ascent algorithms. J. Magn. Reson. 172, 296–305. https://doi.org/10.1016/j.jmr.2004.11.004

[2]

Caneva, T. et al. (2011). Chopped random-basis quantum optimization. Phys. Rev. A 84, 022326. https://doi.org/10.1103/PhysRevA.84.022326

[3]

de Fouquieres, P. et al. (2011). Second order gradient ascent pulse engineering. J. Magn. Reson. 212, 412–417. https://doi.org/10.1016/j.jmr.2011.07.023

Physical validation¶

GRAPE gradient for a single-qubit pi rotation: analytic gradient of F = |<target|U>|^2 with respect to pulse amplitudes. The gradient has magnitude ~ |target - U| * |dU/dparam|. For a Gaussian ansatz, dF/da_k = 2*Re(<target|dU/da_k>) [Khaneja2005].

class quantx_engine.optimal_control.GRAPESolver(H_drift, H_controls, U_target, n_steps=20, total_time=3.141592653589793, seed=None)[source]¶

Bases: object

GRAPE — Gradient Ascent Pulse Engineering.

Maximises the gate fidelity:

Φ = |Tr(U†_target U_prop)|² / d²

with respect to piecewise-constant control amplitudes u[j, k] (j = control index, k = time step index).

The gradient is computed analytically:

∂Φ/∂u_j[k] = (2 dt / d²) Im(IP* · Tr(A[k+1] H_j F[k+1]))

where F[k+1] = U_k … U_0 (forward propagator through step k), A[k+1] = U†_target · U_{n-1} … U_{k+1} (backward propagator using forward unitaries, NOT their adjoints), and IP = Tr(U†_target U_prop).

Parameters:

  • H_drift (np.ndarray) – Time-independent drift Hamiltonian, shape (d, d), Hermitian.

  • H_controls (list[np.ndarray]) – List of control Hamiltonians H_j, each shape (d, d), Hermitian.

  • U_target (np.ndarray) – Target unitary, shape (d, d).

  • n_steps (int) – Number of piecewise-constant time steps.

  • total_time (float) – Total evolution time (same units as Hamiltonian).

  • seed (int | None) – Optional seed for initial random controls.

CRAB — Chopped Random Basis optimal control.

Represents each control field as a sum of n_harmonics random-frequency Fourier components:

u_j(t) = ∑_k (a_k cos(ω_k t) + b_k sin(ω_k t))

Dynamical Decoupling¶

XY-4, CPMG, Uhrig DD sequences.

M126: Quantum memory with dynamical decoupling.

Dynamical decoupling (DD) suppresses decoherence by applying periodic pulse sequences that average out system–bath interactions. This module provides:

  • DynamicalDecoupling — library of DD sequences (FID, Hahn, CPMG, XY4, XY8, KDD) and their filter functions.

  • QuantumMemory — single-qubit or multi-qubit quantum memory with configurable noise models and DD pulse sequences; simulates fidelity decay and coherence time enhancement.

DD Sequences¶

  • FID (free induction decay): no pulses, reference baseline.

  • Hahn Echo: single X pulse at t/2; cancels static inhomogeneity.

  • CPMG: n equally spaced X pulses; cancels slowly varying fields.

  • XY4: π-pulses in alternating X–Y pattern; first-order robust.

  • XY8: eight-pulse version of XY4; second-order robust.

  • KDD: Knill dynamical decoupling; robust to pulse imperfections.

Noise Models¶

  • Dephasing (T₂*): |0⟩⟨0| + e^{-t/T2*}|1⟩⟨1| off-diagonal decay.

  • Relaxation (T₁): amplitude damping.

  • Combined T₁/T₂ noise.

References

  • Viola, L. & Lloyd, S. (1998). Dynamical suppression of decoherence. Phys. Rev. A 58, 2733.

  • Gullion, T. et al. (1990). New, compensated Carr-Purcell sequences. J. Magn. Reson. 89, 479–484.

  • Souza, A. M. et al. (2011). Robust dynamical decoupling for quantum computing and quantum memory. Phys. Rev. Lett. 106, 240501.

References (updated with DOIs)¶

[2]

[3]

Physical validation¶

Hahn echo (CPMG-1): two pi pulses at t/4 and 3t/4 cancel quasi-static dephasing to first order. Filter function F(omega) = |1 - 2e^{i omega t/2} + 2e^{i omega 3t/4} - e^{i omega t}|^2 / omega^2. Low-frequency cutoff ~1/t. CPMG-n improves coherence time T2 by factor sqrt(n) for 1/f noise [Viola1999].

Single-qubit quantum memory with configurable noise and DD sequences.

Simulates the time evolution of a qubit under: - Dephasing (T₂ decay of off-diagonal density matrix elements). - Amplitude damping (T₁ decay of excited state population). - DD pulse sequences that partially suppress decoherence.

Parameters:

Crosstalk Characterisation¶

Crosstalk and ZZ coupling model — M90.

Models parasitic qubit–qubit interactions of the form

H_ZZ = Σ_{(j,k)} ζ_{jk} / 2 · σz_j ⊗ σz_k

which accumulate phase during idle periods and degrade two-qubit gate fidelity. The module provides:

  • CouplingGraph — weighted graph of ZZ coupling strengths.

  • CrosstalkModel — builds the full idle Hamiltonian H₀ + H_ZZ and integrates it to compute idle crosstalk phase accumulation.

  • zz_routing_cost() — SABRE-compatible edge-cost function that adds ZZ coupling weight to standard swap costs.

  • echo_sequence() — convenience function that generates a PulseSchedule with X–X refocusing echoes to cancel ZZ accumulation between two qubits.

Distributed Simulation (Ray)¶

Multi-node statevector simulation with Ray (requires quantx-engine[distributed]).

M111: Distributed statevector simulation via Ray.

Implements a sharded statevector simulator that distributes the 2^n amplitude array across multiple Ray actors (one per shard), enabling simulation of large circuits across a multi-core machine or cluster. Falls back transparently to single-process numpy when Ray is unavailable.

Sharding strategy¶

The 2^n statevector is partitioned into num_shards contiguous blocks, each of size shard_size = 2^n // num_shards. Shard k owns amplitudes with indices in the range [k * shard_size, (k+1) * shard_size).

Gate classification¶

For an n-qubit statevector split into 2^s shards (s = log2(num_shards)):

  • Local gates (qubit index < n − s): both paired amplitudes lie within the same shard → each actor applies the gate independently in parallel.

  • Global gates (qubit index >= n − s): paired amplitudes live in different shards → the two affected shard actors exchange data, apply the gate jointly, and write back. In the CPU-fallback path the same exchange is performed in-process using numpy.

Quick start:

from quantx_engine.ray_sim import DistributedSVSimulator

sim = DistributedSVSimulator(n_qubits=20, num_shards=4)
sim.h(0)

    sim.cx(q, q + 1)
