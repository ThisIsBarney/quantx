quantx_engine.finite_size¶

Finite-size scaling and quantum phase-transition analysis (M74).

Three main components:

binder_cumulant — compute the Binder cumulant U = 1 − ⟨m⁴⟩/(3⟨m²⟩²) from order-parameter samples. U → 0 in the disordered phase (Gaussian fluctuations) and U → 2/3 in the ordered phase (bimodal distribution).

entanglement_scaling — compute the bipartite von Neumann entropy S(A) for all subsystem sizes A = 1, …, L−1 via SVD of the reshaped state vector, and fit the 1D CFT formula S(A) = (c/3) ln[(L/π) sin(πA/L)] + const to extract the central charge c.

FiniteSizeScaling — locate the critical coupling J_c from Binder cumulant data at multiple system sizes L:

  1. binder_crossings() finds parameter values where adjacent-size curves intersect (linear interpolation).

  2. fit_critical_point() averages those crossings into a single estimate of J_c ± σ.

  3. data_collapse(jc, nu) measures how well data from different L collapse onto a single scaling curve when plotted against (J − J_c) L^{1/ν}.

Quick start:

import numpy as np
from quantx_engine.finite_size import FiniteSizeScaling, binder_cumulant

# Simulated Binder cumulants near J_c = 1.0
params = np.linspace(0.7, 1.3, 30)
sizes  = [8, 16, 32, 64]
nu     = 1.0  # correlation-length exponent
J_c    = 1.0
def logistic(x): return (2/3) / (1 + np.exp(-4 * x))
binder = np.array([logistic((params - J_c) * L**(1/nu)) for L in sizes])

fss    = FiniteSizeScaling(sizes, params, binder)
result = fss.fit_critical_point()
print(f"J_c = {result.critical_point:.4f} ± {result.critical_point_std:.4f}")

Physical validation¶

Binder cumulant U_4 = 1 - <m^4>/(3*<m^2>^2): at the critical point, U_4 curves for different system sizes L all cross at the same value U_4^* (≈ 0.610 for the 3D Ising model) [Binder1981]. For an ordered phase (T << T_c): U_4 -> 2/3. For disordered (T >> T_c): U_4 -> 0.

data_collapse(jc, nu, observable=None, beta_over_nu=0.0)[source]¶

Measure data-collapse quality for given (J_c, ν).

Rescales the parameter axis as x̃ = (J − J_c) · L^{1/ν} and (if observable and beta_over_nu are provided) the observable axis as Ỹ = O · L^{β/ν}, then computes the mean-squared distance between adjacent rescaled curves (interpolated onto a common grid).

A perfect collapse gives cost = 0.

Parameters:

  • jc (float) – Trial critical coupling.

  • nu (float) – Trial correlation-length exponent (must be > 0).

  • observable (ndarray | None) – 2D array (n_sizes, n_params) of order-parameter values. If None, the Binder cumulant is used (and β/ν = 0).

  • beta_over_nu (float) – β/ν exponent for y-axis rescaling. Use 0 for Binder cumulant.

Returns:

Mean squared deviation averaged over all N(N−1)/2 unique pairs of rescaled curves (not just adjacent pairs). Using all pairs makes the metric more robust when sizes span a wide range. Lower is better. Returns float('inf') if no pair has an overlapping rescaled-x region with at least 2 points; this can happen when jc is far outside the supplied parameter range or nu is very small.

Return type:

float

Raises:

FiniteSizeError – If nu <= 0 or observable has wrong shape.

quantx_engine.finite_size.binder_cumulant(samples)[source]¶

Compute the Binder cumulant U = 1 − ⟨m⁴⟩ / (3⟨m²⟩²).

The Binder cumulant is a dimensionless ratio that distinguishes phases without needing the thermodynamic limit:

  • U → 0 disordered phase (Gaussian fluctuations: ⟨m⁴⟩ = 3⟨m²⟩²)

  • U → 2/3 ordered phase (bimodal: |m| ≈ const)

At the critical point, Binder cumulant curves for different system sizes L cross at a universal value U* ∈ (0, 2/3).

Note

This function uses raw moments ⟨m²⟩ and ⟨m⁴⟩ (the standard definition in the condensed-matter literature). These are not centred cumulants. Passing samples with a non-zero mean correctly gives U ≈ 2/3 for a biased ordered phase (e.g. ferromagnet in an external field), which is the physically correct result.

Parameters:

samples (ndarray) – 1D (or ravelled) array of order-parameter values. At least 2 samples are required.

Returns:

Binder cumulant U. Theoretically in [0, 2/3], but may be slightly outside this range due to finite sampling.

Return type:

float

Raises:

FiniteSizeError – If fewer than 2 samples are provided or ⟨m²⟩ ≈ 0.

quantx_engine.finite_size.entanglement_scaling(psi, L, d=2)[source]¶

Compute bipartite von Neumann entropy S(A) for all bipartitions.

Reshapes the length-d^L state vector as a (d^A, d^{L−A}) matrix and computes the von Neumann entropy

S(A) = −Tr(ρ_A ln ρ_A) = −∑_i λ_i ln λ_i,

where λ_i = σ_i² are the eigenvalues of the reduced density matrix ρ_A obtained from the singular values σ_i of the reshaped matrix.

For a 1D critical system described by a CFT with central charge c, the entropy satisfies

S(A) = (c/3) ln[(L/π) sin(πA/L)] + s₀.

A least-squares fit of this formula (for L ≥ 4) returns the central charge.

Parameters:

  • psi (ndarray) –

    State vector, shape (d^L,). Must be exactly d^L elements. Need not be normalised (normalisation is applied internally).

    Storage convention: the state is indexed in standard tensor-product (row-major / C) order, i.e. psi[i] = ⟨s_0 s_1 … s_{L-1}|ψ⟩ where site 0 is the most-significant index. Equivalently, index = s_0·d^{L-1} + s_1·d^{L-2} + … + s_{L-1}. This is the natural NumPy ordering and the convention used throughout QuantX.

  • L (int) – Number of lattice sites.

  • d (int) – Local Hilbert-space dimension (default 2 for qubits/spin-1/2).

Return type:

EntanglementResult

Raises:

FiniteSizeError – If len(psi) != d^L or psi has near-zero norm.
