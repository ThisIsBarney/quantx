quantx_engine.contrib.ft_tgate¶

M120: Fault-tolerant T gate via magic state injection.

Implements four components for fault-tolerant T-gate synthesis:

  • MagicStateFactory — simulates 7-to-1 and 15-to-1 magic state distillation protocols to produce high-fidelity |T⟩ states.

  • FTTGate — gate-teleportation T gate consuming one |T⟩ magic state.

  • FTCCXGate — fault-tolerant Toffoli via the Clifford+T decomposition (7 T gates, Selinger 2013).

  • TCountOptimizer — T-count/T-depth analyser and algebraic reducer.

References

[1]

Bravyi, S. & Kitaev, A. (2005). Universal quantum computation with ideal Clifford gates and noisy ancillas. Phys. Rev. A 71, 022316. https://doi.org/10.1103/PhysRevA.71.022316

[2]

Selinger, P. (2013). Quantum circuits of T-depth one. Phys. Rev. A 87, 042302. https://doi.org/10.1103/PhysRevA.87.042302

[3]

Campbell, E. T., Terhal, B. M. & Vuillot, C. (2017). Roads towards fault-tolerant universal quantum computation. Nature 549, 172. https://doi.org/10.1038/nature23460

Physical validation¶

15-to-1 distillation output error: epsilon_out = 35*epsilon_in^3. For epsilon_in = 0.01: epsilon_out = 3.5e-5 [Bravyi2005]. Toffoli gate T count: 7 T gates in the Selinger decomposition [Selinger2013].

class quantx_engine.contrib.ft_tgate.MagicStateFactory(protocol='7_to_1', input_error_rate=0.01)[source]¶

Bases: object

Simulates magic state distillation for fault-tolerant T gates.

Two protocols are supported:

  • 7-to-1 — consumes 7 noisy |T⟩ copies; uses the [[7,1,3]] Steane code to detect and discard corrupted states. Output error rate ≈ 35 ε³.

  • 15-to-1 — consumes 15 noisy copies; uses the [[15,1,3]] Reed-Muller code. Output error rate ≈ 35 ε³ (with a smaller coefficient in practice).

Parameters:

  • protocol ({"7_to_1", "15_to_1"}) – Distillation protocol.

  • input_error_rate (float) – Per-copy error rate of the noisy input |T⟩ states (must be in (0, 1)).

class quantx_engine.contrib.ft_tgate.FTTGate(magic_state_fidelity=0.999999)[source]¶

Bases: object

Fault-tolerant T gate via magic state injection (gate teleportation).

Protocol¶

  1. Prepare ancilla in |T⟩ = (|0⟩ + e^{iπ/4}|1⟩)/√2.

  2. Apply CNOT (data qubit = control, ancilla = target).

  3. Measure ancilla in the Z basis.

  4. If outcome is |1⟩, apply S correction to the data qubit.

The resulting operation applies T to the data qubit (up to global phase).

param magic_state_fidelity:

Fidelity of the injected |T⟩ magic state with the ideal state. Controls the effective gate error rate.

class quantx_engine.contrib.ft_tgate.TCountOptimizer(circuit)[source]¶

Bases: object

Analyses and minimises the T-count of a Clifford+T quantum circuit.

The circuit is specified as a list of gate-operation dicts. Each dict must contain a "gate" key; qubit indices are passed via "qubit", "control"/"target", or "controls"/"target" keys.

Example:

circuit = [
    {"gate": "H",    "qubit": 0},
    {"gate": "T",    "qubit": 0},
    {"gate": "CNOT", "control": 0, "target": 1},
    {"gate": "T†",   "qubit": 1},
    {"gate": "CCX",  "controls": [0, 1], "target": 2},
]
Parameters:

circuit (list[dict]) – Circuit as a list of gate-operation dicts.

t_count()[source]¶

Return all T and T†-gate operations.

optimize()[source]¶

Return a new TCountOptimizer with a reduced T-count.

Applies algebraic cancellations repeatedly until no further reduction is possible:

  • T·T → S

  • T†·T† → S†

  • T·T† → I (and T†·T → I)

  • S·S → Z, S†·S† → Z, S·S† → I

  • Z·Z → I, X·X → I, Y·Y → I, H·H → I

Only consecutive operations on the same single qubit are reduced.

Returns:

New optimiser wrapping the reduced circuit.

Return type:

TCountOptimizer
