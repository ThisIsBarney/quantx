quantx_engine.fault_tolerant¶

Fault-tolerant logical qubits — M91.

Provides:

  • LogicalQubit — encode, apply logical Clifford gates, and decode using a distance-d repetition code or surface code backed by the MWPM decoder from quantx_engine.qec.

  • MagicStateDistillery — 15-to-1 magic state distillation protocol for injecting T gates into a fault-tolerant computation.

  • FaultTolerantCircuit — compile a logical gate sequence to a list of physical operations that can be dispatched to LogicalQubit.

All simulations are purely classical (no statevector), operating on syndrome tables and logical Pauli frames, which is the standard technique for fault-tolerant threshold analysis.

References

[1]

Fowler, A. M. et al. (2012). Surface codes: Towards practical large-scale quantum computation. Phys. Rev. A 86, 032324. https://doi.org/10.1103/PhysRevA.86.032324

[2]

Bravyi, S. & Kitaev, A. (2005). Universal quantum computation with ideal Clifford gates and noisy ancillas. Phys. Rev. A 71, 022316. https://doi.org/10.1103/PhysRevA.71.022316

[3]

Knill, E., Laflamme, R. & Zurek, W. H. (1998). Resilient quantum computation. Science 279, 342. https://doi.org/10.1126/science.279.5349.342

Physical validation¶

15-to-1 magic state distillation: output error = 35*epsilon^3 for input error epsilon (cubic suppression). Verified against formula in Bravyi & Kitaev 2005, Table I.

class quantx_engine.fault_tolerant.LogicalQubit(distance, physical_error_rate=0.001, rng_seed=None)[source]¶

Bases: object

A logical qubit encoded in a distance-d repetition code.

The repetition code encodes one logical qubit in d physical qubits with the logical operators L_X = X⊗X⊗…⊗X and L_Z = Z⊗I⊗…⊗I. It corrects ⌊(d−1)/2⌋ single-qubit Z errors.

Parameters:

  • distance (int) – Code distance (must be odd, ≥ 3).

  • physical_error_rate (float) – Per-physical-qubit error rate (probability of a single-qubit Z flip per syndrome measurement round).

  • rng_seed (int, optional) – Seed for reproducible simulations.

class quantx_engine.fault_tolerant.MagicStateDistillery(p_in=0.01, rng_seed=None)[source]¶

Bases: object

15-to-1 magic state distillation for fault-tolerant T gates.

The 15-to-1 protocol (Bravyi & Kitaev 2005) takes 15 noisy |T⟩ states with input error rate p_in and outputs one |T⟩ state with error rate approximately 35·p_in³.

Parameters:

  • p_in (float) – Input |T⟩ state error rate (probability that a state is |T̄⟩ = Z|T⟩).

  • rng_seed (int, optional)
