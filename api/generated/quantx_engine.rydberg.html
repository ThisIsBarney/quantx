quantx_engine.rydberg¶

M118: Neutral-atom backend — Rydberg blockade simulator.

Simulates neutral-atom quantum processors (QuEra Aquila, Pasqal) based on the Rydberg blockade mechanism. Atoms are modelled as two-level systems |g⟩ (ground) and |r⟩ (Rydberg), driven by a global laser field.

Physics model¶

The many-body Hamiltonian (in units where ħ = 1) is:

H(t) = (Ω/2) Σ_i σ^x_i  −  δ Σ_i n_i  +  Σ_{i<j} V_{ij} n_i n_j

where:

  • Ω — Rabi frequency of the global drive

  • δ — laser detuning

  • n_i = |r⟩⟨r|_i — Rydberg population on atom i

  • V_{ij} = C₆ / r_{ij}⁶ — van der Waals blockade interaction (C₆ is the Rydberg C₆ coefficient, r_{ij} the inter-atom distance)

For r_{ij} < R_b (blockade radius R_b = (C₆/Ω)^{1/6}), two atoms cannot simultaneously occupy the Rydberg state.

Usage¶

atoms = [(0.0, 0.0), (5.0, 0.0), (10.0, 0.0)]  # μm
sim = RydbergSimulator(atom_positions=atoms, Omega=1.0, delta=0.0, C6=862690)
result = sim.evolve(t_final=2*pi, n_steps=100)
# result.populations[i] = Rydberg population ⟨n_i⟩(t)

Physical validation¶

Van der Waals blockade: V(r) = C_6 / r^6. Blockade radius r_b defined by V(r_b) = Omega (Rabi frequency). For r < r_b, doubly-excited state is energetically suppressed. Rabi oscillations: Omega_eff = sqrt(n)*Omega for an n-atom ensemble in the blockade regime [Lukin2001].

Bases: object

Neutral-atom Rydberg blockade simulator.

Simulates the coherent dynamics of n neutral atoms under a global laser drive using exact statevector evolution.

Parameters:

  • atom_positions (list[tuple[float, float]] | list[RydbergAtom]) – Atom positions in μm (2-D). Accepted as (x, y) tuples or RydbergAtom objects.

  • Omega (float, default 1.0) – Global Rabi frequency.

  • delta (float, default 0.0) – Laser detuning (negative = red-detuned, positive = blue-detuned).

  • C6 (float, default 862690.0) – van der Waals C₆ coefficient in MHz·μm⁶.

  • max_atoms (int, default 16) – Hard limit on atom count (exact diagonalisation scales as 2^n).
