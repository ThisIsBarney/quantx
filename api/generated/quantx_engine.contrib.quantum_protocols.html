quantx_engine.contrib.quantum_protocols¶

Quantum communication protocols — M97.

Implements four landmark quantum protocols built on the quantum network infrastructure from M96 (quantum_network):

  • BB84 — Bennett–Brassard 1984 QKD with optional eavesdropping.

  • E91 — Ekert 1991 entanglement-based QKD with CHSH Bell test.

  • Teleportation — Quantum state teleportation over an entangled channel.

  • SuperDenseCoding — Two classical bits per one qubit transmission.

All protocols are purely classical/statistical simulations of the relevant quantum information flows; no wavefunction is stored. Fidelity parameters from quantum_network are propagated throughout.

Classes¶

  • ProtocolError — base exception.

  • BB84Result — result of one BB84 key-exchange run.

  • BB84Protocol — BB84 key distribution simulator.

  • E91Result — result of one E91 run.

  • E91Protocol — E91 / Ekert-91 protocol simulator.

  • TeleportationResult — result of a teleportation run.

  • TeleportationProtocol — quantum teleportation simulator.

  • DenseCodingResult — result of a dense coding run.

  • teleportation_fidelity() — fidelity of teleported state given channel F.

[2]

Physical validation¶

BB84 key rate: r = 1 - 2*h(e) (Shor-Preskill formula). At e=11% threshold, r = 0 [Shor2000]. Teleportation fidelity of a Werner state rho_W(F): F_tel = (2F+1)/3 [Bennett1993].

class quantx_engine.contrib.quantum_protocols.BB84Protocol(channel_error_rate=0.02, eve_intercept_fraction=0.0, detection_threshold=0.11, seed=None)[source]¶

Bases: object

Simulate the BB84 quantum key distribution protocol.

Alice encodes random bits in randomly chosen bases (rectilinear Z or diagonal X). Bob measures in randomly chosen bases. After classical sifting, only bits where bases matched are kept. Noise (channel error rate) and an optional intercept-resend eavesdropper (Eve) are modelled statistically.

Parameters:

  • channel_error_rate (float ∈ [0, 0.5]) – Intrinsic QBER from channel noise (no Eve).

  • eve_intercept_fraction (float ∈ [0, 1]) – Fraction of qubits that Eve intercepts and re-sends. Eve introduces an additional QBER of 0.25 * eve_intercept_fraction.

  • detection_threshold (float) – QBER threshold above which Eve is considered detected (default: 0.11).

  • seed (int or None)

class quantx_engine.contrib.quantum_protocols.E91Protocol(bell_pair_fidelity=0.95, channel_error_rate=0.01, seed=None)[source]¶

Bases: object

Simulate the Ekert-91 entanglement-based QKD protocol.

Alice and Bob share Bell pairs from a source. Each independently chooses among three measurement angles. Pairs where they chose the same angle contribute to the key; pairs with different angles are used to compute the CHSH S-parameter as a security test.

The channel is characterised by a Bell-pair fidelity F. Under the Werner state model, the correlation function for ideal angles is:

E(θ_A, θ_B) = -(2F − 1/2) cos(2(θ_A − θ_B))

(derived from Werner state correlations for the singlet component).

Parameters:

  • bell_pair_fidelity (float ∈ [0.25, 1]) – Fidelity of the entangled pairs shared between Alice and Bob.

  • channel_error_rate (float ∈ [0, 0.5]) – Additional bit-flip error on top of Werner-state correlations.

  • seed (int or None)

class quantx_engine.contrib.quantum_protocols.TeleportationProtocol(channel_fidelity=0.95, bsm_fidelity=0.99, seed=None)[source]¶

Bases: object

Simulate quantum state teleportation.

Alice and Bob share a Bell pair with fidelity F. Alice performs a BSM on her qubit and the input state, communicates 2 classical bits to Bob, and Bob applies the corresponding Pauli correction.

The average fidelity of the teleported state (over the Bloch sphere) is:

f_tele = (2F + 1) / 3

This exceeds the classical f = 2/3 bound iff F > 1/2.

Parameters:

  • channel_fidelity (float ∈ [0.25, 1]) – Bell-pair fidelity shared between Alice and Bob.

  • bsm_fidelity (float ∈ (0, 1]) – Alice’s BSM gate fidelity.

  • seed (int or None)

class quantx_engine.contrib.quantum_protocols.DenseCodingProtocol(channel_fidelity=0.95, seed=None)[source]¶

Bases: object

Simulate superdense coding.

Alice encodes 2 classical bits into one qubit by applying a Pauli operation to her half of a shared Bell pair, then sends the qubit to Bob. Bob performs a BSM to decode both bits.

The channel capacity in the presence of Werner-state noise F is:

C = 1 + (4F - 1)/3 · 1 + (1-(4F-1)/3) · 0
  = 1 + (4F-1)/3   [bits/qubit, approximate for Werner noise]

More precisely, the Holevo capacity of the dense coding channel is:

χ = h(F + (1-F)/4) - h((1-F)/4) * 3   [nats, Werner model]

We use the simpler error-rate model: probability of decoding error from Werner noise is (1 - (4F-1)/3) * 3/4.

Parameters:

  • channel_fidelity (float ∈ [0.25, 1]) – Bell-pair fidelity of the shared channel.

  • seed (int or None)

quantx_engine.contrib.quantum_protocols.bb84_key_rate(qber)[source]¶

Asymptotic BB84 secure key rate per sifted bit.

Uses the Shor–Preskill formula:

r = 1 - 2·h₂(QBER)

where h₂ is the binary Shannon entropy. Returns 0 if QBER ≥ 11 %.

Parameters:

qber (float ∈ [0, 0.5]) – Quantum Bit Error Rate after sifting.

Return type:

float ∈ [0, 1]

quantx_engine.contrib.quantum_protocols.chsh_inequality_value(correlations)[source]¶

Compute the CHSH S-parameter from four correlation measurements.

The CHSH inequality is S = |E(a,b) - E(a,b') + E(a',b) + E(a',b')|. Classical bound: |S| ≤ 2. Tsirelson’s quantum bound: |S| ≤ 2√2 ≈ 2.828.

Parameters:

correlations (dict mapping (alice_basis, bob_basis) → E ∈ [-1, 1]) – Must contain keys (0,0), (0,1), (1,0), (1,1).

Return type:

float (S-parameter)

quantx_engine.contrib.quantum_protocols.teleportation_fidelity(channel_fidelity)[source]¶

Average fidelity of teleported qubit state as function of channel F.

For a Werner-state channel with Bell-pair fidelity F, the average teleportation fidelity over the Bloch sphere is:

f_tele = (2F + 1) / 3

This saturates at f = 1 for F = 1 (perfect channel) and gives f = 1/2 for F = 1/4 (maximally mixed channel, same as classical guess).

Parameters:

channel_fidelity (float ∈ [0, 1])

Return type:

float ∈ [1/3, 1]
