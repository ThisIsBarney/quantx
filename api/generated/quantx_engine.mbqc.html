quantx_engine.mbqc¶

M125: Measurement-based quantum computation (MBQC).

Implements the one-way quantum computation model (1WQC / cluster-state QC):

  1. Prepare a resource state — a graph state |G⟩ on the vertices of a graph G.

  2. Perform adaptive single-qubit measurements in chosen bases.

  3. Read off the result from the remaining (output) qubits, correcting for the randomness of each measurement outcome using feed-forward (Pauli corrections).

Classes¶

GraphState

Build and manipulate graph states from an adjacency specification.

MBQCPattern

Specify and simulate an MBQC computation pattern (measurement sequence, correction rules, input/output qubits).

References

  • Raussendorf, R. & Briegel, H. J. (2001). A one-way quantum computer. Phys. Rev. Lett. 86, 5188.

  • Danos, V. et al. (2007). The measurement calculus. J. ACM 54, 8.

Physical validation¶

Linear cluster state |+>-CZ-…-CZ-|+>: measuring all qubits in the X basis gives a uniformly random bit string (no correlations in X-basis) [Raussendorf2001]. Single-qubit rotation R_z(theta): teleported via MBQC pattern with angles {-theta, 0} and appropriate feed-forward [Raussendorf2003].

measure(qubit, angle, seed=None, outcome=None)[source]¶

Measure qubit in the basis (|+_θ⟩, |−_θ⟩).

The measurement basis vectors are:

|+_θ⟩ = (|0⟩ + e^{iθ}|1⟩)/√2 |−_θ⟩ = (|0⟩ - e^{iθ}|1⟩)/√2

Parameters:

  • qubit (int) – Index of the qubit to measure.

  • angle (float) – Measurement angle θ.

  • seed (int or None) – RNG seed for random outcome sampling.

  • outcome (int or None) – If given, force the measurement outcome (0 or 1) — useful for deterministic testing.
