quantx_engine.tensor_network¶

Tensor Network methods for the QuantX engine.

Implements Matrix Product States (MPS), Matrix Product Operators (MPO), Time-Evolving Block Decimation (TEBD), and Density Matrix Renormalization Group (DMRG) in pure Python / NumPy.

Classes:

MPS — Matrix Product State representation of N-qubit states MPO — Matrix Product Operator representation of Hamiltonians TEBD — Trotterized time evolution under nearest-neighbor Hamiltonians DMRG — Two-site DMRG ground-state search DMRGResult — Result container returned by DMRG.run()

Usage:

from quantx_engine.tensor_network import MPS, MPO, TEBD, DMRG

# Build a 6-qubit |000000⟩ product state
mps = MPS.product_state([0, 0, 0, 0, 0, 0])

# Build transverse-field Ising Hamiltonian MPO
mpo = MPO.ising(n=6, J=1.0, h=0.5)

# Find ground state with DMRG
dmrg = DMRG(mpo=mpo, max_chi=16, n_sweeps=10)
result = dmrg.run()
print(f"Ground state energy: {result.energy:.6f}")

# Time-evolve with TEBD
tebd = TEBD(mps=MPS.product_state([0]*6), max_chi=16)
history = tebd.evolve_ising(J=1.0, h=0.5, dt=0.01, n_steps=100)

Physical validation¶

GHZ state norm conservation: after n TEBD steps the state norm stays 1.0 to within floating-point precision (verified in test_physics_validation_2.py). DMRG ground-state energy for 6-site TFIM (J=1, h=0.5) converges within 1e-4 of the exact value from numpy.linalg.eigvalsh.

Matrix Product State: N-site state as rank-3 tensors.

Each tensor A[i] has shape (chi_left, d, chi_right) where:

  • d = local Hilbert-space dimension (2 for qubits)

  • chi_left = 1 for the leftmost site

  • chi_right = 1 for the rightmost site

Parameters:

static ising(n, J=1.0, h=0.5)[source]¶

Transverse-field Ising MPO: H = -J Σ Z_i Z_{i+1} − h Σ X_i.

Uses D=3 MPO with the standard W matrix:

W = [[I,    0,    0  ],
     [Z,    0,    0  ],
     [-h*X, -J*Z, I  ]]

Boundary: W_0 = last row (1×3), W_{N-1} = first column (3×1).

static heisenberg(n, J=1.0, hz=0.0)[source]¶

Heisenberg MPO: H = J Σ (XX+YY+ZZ) + hz Σ Z.

Uses D=5 MPO.

evolve_ising(J, h, dt, n_steps)[source]¶

Second-order Suzuki-Trotter evolution under H = -J Σ ZZ − h Σ X.

Uses: exp(-iH_X dt/2) · exp(-iH_ZZ dt) · exp(-iH_X dt/2) per step, with H_ZZ applied layer-by-layer (even/odd bonds).
