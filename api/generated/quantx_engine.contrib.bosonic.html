quantx_engine.contrib.bosonic¶

M119: Bosonic codes — cat qubits and GKP (Gottesman-Kitaev-Preskill) codes.

Provides hardware-biased-noise bosonic encodings that are at the centre of near-term fault-tolerant quantum computing roadmaps (AWS, Yale cat-qubit, INRIA/Alice&Bob).

Cat qubits¶

A Kerr-cat qubit encodes a logical qubit in the two coherent-state superpositions |C_α±⟩ ∝ |α⟩ ± |−α⟩ inside a driven Kerr oscillator:

H = −K a†²a² + ε₂(a†² + a²)

Bit-flip errors (X_L) are exponentially suppressed ~ exp(−2|α|²) while phase-flip errors (Z_L) scale polynomially, yielding a biased noise channel ideal for concatenation with a repetition code.

GKP codes¶

The Gottesman-Kitaev-Preskill code encodes a qubit in a harmonic oscillator whose Hilbert space is infinite-dimensional (or truncated at N_max photons). The logical code words are superpositions of squeezed states on a square phase-space lattice with spacing √π. We implement the finite-energy (approximate) GKP state with Gaussian envelope parameter δ and the small-big-small (SBS) correction sequence for shift errors.

Physical validation¶

Cat qubit: Kerr-cat Hamiltonian H = -K a†²a² + epsilon_2(a†²+a²) has two degenerate ground states in Fock basis at large alpha. Verified via exact diagonalisation of the truncated Fock-space matrix. GKP state: finite-energy square-lattice code has displacement variance sigma^2 = Delta^2/(1 + Delta^2) [Gottesman2001].

class quantx_engine.contrib.bosonic.CatQubit(K=1.0, eps2=4.0, N_max=30, noise=None, *, alpha=None, kerr=None, truncation=None)[source]¶

Bases: object

Kerr-cat qubit in a truncated Fock space.

The Kerr-cat Hamiltonian is

H = −K a†²a² + ε₂(a†² + a²)

which stabilises a two-component cat state with amplitude α = √(ε₂/K).

Parameters:

  • K (float) – Kerr nonlinearity (anharmonicity). Must be > 0.

  • eps2 (float) – Two-photon drive amplitude. Must be > 0.

  • N_max (int) – Fock-space truncation. Should satisfy N_max ≫ 2|α|² + 10.

  • noise (CatNoiseModel | None) – Optional noise model. If None, uses CatNoiseModel defaults with alpha_sq derived from eps2/K.

class quantx_engine.contrib.bosonic.GKPState(delta=0.3, N_max=60, *, truncation=None)[source]¶

Bases: object

Finite-energy GKP (Gottesman-Kitaev-Preskill) code state.

The ideal GKP code encodes a qubit in a harmonic oscillator with stabilisers S_q = e^{i2√π q̂} and S_p = e^{-i2√π p̂}. The finite-energy approximation uses a Gaussian envelope with width δ in Fock space.

Parameters:

  • delta (float) – Envelope/squeezing parameter δ > 0. Smaller δ → better code words but more photons. Physical squeezing in dB ≈ −20 log₁₀(δ/√(2π)).

  • N_max (int) – Fock-space truncation.

Notes

The code words are constructed as a superposition of displaced squeezed vacuum states at lattice points n√π in phase space.

class quantx_engine.contrib.bosonic.GKPDecoder(gkp, n_rounds=1)[source]¶

Bases: object

Small-Big-Small (SBS) shift error correction for GKP codes.

The SBS sequence applies alternating small and big displacements to map shift errors back toward the lattice points:

D_small(−ξ) · D_big(+ξ + correction) · D_small(−ξ)

where the correction direction is estimated from a syndrome measurement of the shift-error magnitude.

Parameters:

  • gkp (GKPState) – The GKP state object (defines δ, N_max, lattice).

  • n_rounds (int) – Number of SBS correction rounds to apply.
