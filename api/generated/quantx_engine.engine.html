quantx_engine.engine¶

C++ engine bridge — ctypes / pybind11 interface to the QuantX native library.

Provides the Engine facade that dispatches to native C++ solvers (Lanczos, Trotter, MPS) when the shared library is available, and falls back transparently to the pure-Python implementations otherwise.

M159 adds a pybind11 fast path: when the _quantx_py extension module is importable (built with QX_ENABLE_PYBIND=ON), methods such as Engine.run_statevector() and Engine.run_circuit_sv() return NumPy arrays directly without any JSON round-trip overhead.

The native library is located via the environment variable QUANTX_LIB_PATH or by searching the standard platform-specific paths (quantx_engine.dll on Windows, libquantx_engine.so on Linux, libquantx_engine.dylib on macOS).

exception quantx_engine.engine.QuantXNativeUnavailable[source]¶

Bases: RuntimeError

Raised when the native QuantX shared library cannot be loaded.

This happens when quantx-engine is installed as a pure-Python wheel (no C++ build) or when the library path is incorrect. All pure-Python modules — simulators, chemistry solvers, error-correction codes, etc. — continue to work normally; only features that call through to the native C++ engine require the library.

run_statevector(problem, options=None)[source]¶

Run a Hamiltonian simulation and return the statevector.

When the pybind11 extension is available (pybind11_available() is True), this method returns a numpy.ndarray of dtype complex128 with shape (2**n_qubits,) — no JSON serialisation is performed.

Without pybind11 the result falls back to the ctypes JSON path and the statevector is returned as a list of [re, im] pairs embedded in the normal result dict under the "state" key.

Parameters:

  • problem (dict) – Problem specification (same schema as run()).

  • options (dict, optional) – Runtime options.

Returns:

NumPy array via pybind11, or full result dict via ctypes fallback.

Return type:

numpy.ndarray (complex128) or dict

run_circuit_sv(circuit)[source]¶

Execute a gate-level circuit and return the output statevector.

When the pybind11 extension is available, this returns a numpy.ndarray[complex128] directly. Otherwise it calls the ctypes path and returns the full result dict.

Parameters:

circuit (dict) – Circuit payload (same schema as run_circuit()).

Return type:

numpy.ndarray (complex128) or dict

run_circuit_counts_np(circuit)[source]¶

Execute a gate-level circuit and return measurement counts.
