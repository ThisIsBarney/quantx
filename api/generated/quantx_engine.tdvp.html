quantx_engine.tdvp¶

TDVP time evolution for MPS — Python wrapper over the native C++ engine.

Wraps qx_tdvp_evolve (src/tdvp.hpp via src/dmrg_capi.cpp): real- and imaginary-time evolution of a spin-1/2 Heisenberg chain by the time-dependent variational principle (TDVP1 one-site, or TDVP2 two-site bond-adaptive).

Example

from quantx_engine import Engine from quantx_engine.tdvp import TDVPSolver

s = TDVPSolver(Engine()) # real-time quench from the Neel state r = s.evolve(10, dt=0.05, n_steps=40, chi_max=64, two_site=True) print(r.times, r.staggered_mag) # <m_stag>(t)

# imaginary-time cooling to the ground state g = s.evolve(10, dt=0.1, n_steps=200, imag=True) print(g.energy)

Evolve a Heisenberg chain by TDVP.

Parameters:

  • n_qubits (int) – Number of spin-1/2 sites.

  • J (float) – Heisenberg coupling (H = J sum_i sigma_i . sigma_{i+1}).

  • dt (float) – Time step.

  • n_steps (int) – Number of steps (total time = dt * n_steps).

  • chi_max (int) – Maximum bond dimension (TDVP2 truncation).

  • imag (bool) – Imaginary-time evolution (cooling toward the ground state) if True; real-time otherwise.

  • two_site (bool) – TDVP2 (bond-adaptive, needed for entanglement growth) if True; TDVP1 (fixed bond) otherwise.

  • initial (str) – Initial state: "neel" (|up dn up dn...>) or "up" (all up).

Return type:

TDVPResult

Result of a TDVP evolution.

Variables:

  • energy (float) – Final ground-state-convention energy <psi|H|psi> (H = J sum sigma.sigma).

  • sz (list[float]) – Final <sigma^z_i> per site.

  • times (list[float]) – Time grid (length n_steps+1, including t=0).

  • staggered_mag (list[float]) – Staggered magnetization (1/N) sum_i (-1)^i <sigma^z_i> at each time.

  • max_bond (int) – Largest MPS bond dimension reached.

  • wall_time_s (float) – Native wall-clock time for the evolution loop.

  • method (str) – "tdvp1" or "tdvp2".

Bases: object

Loschmidt echo / DQPT of an XXZ quench (native C++ backend).

Prepares the ground state of XXZ(J, delta), quenches the anisotropy to delta_f, evolves with block-sparse TEBD, and returns the return probability L(t) and rate function. Heisenberg/XXZ chain only.
