quantx_engine.lanczos¶

Lanczos and Arnoldi sparse eigensolver for large quantum Hamiltonians.

Fills the gap for systems too large for dense O(n³) Jacobi diagonalization. The Lanczos algorithm reduces an N×N symmetric matrix to a k×k tridiagonal form in k matrix-vector products, making it practical for quantum Hamiltonians with dim = 2^n where n is the system size.

References

[1]

Lanczos, C. (1950). An iteration method for the solution of the eigenvalue problem of linear differential and integral operators. J. Res. Natl. Bur. Stand. 45, 255–282. https://doi.org/10.6028/jres.045.026

[2]

Cullum, J. K. & Willoughby, R. A. (1985). Lanczos Algorithms for Large Symmetric Eigenvalue Computations, Vol. 1. Birkhäuser. ISBN 978-0-8176-3058-4.

[3]

Paige, C. C. (1971). The computation of eigenvalues and eigenvectors of very large sparse matrices. PhD thesis, University of London.

Physical validation¶

The 4-site antiferromagnetic Heisenberg chain (H = ½ Σ σ_i·σ_{i+1}, open BC) has ground-state energy E₀ = −3.2321 with our normalization, corresponding to E₀/J = −1.6160254 in the standard S = σ/2 convention.

solve_heisenberg(n_sites, J=1.0, Jz=1.0, h=0.0)[source]¶

Find lowest k eigenpairs of the 1D Heisenberg chain.

Routes through the native C++ Heisenberg solver when the QuantX native library is available (QUANTX_LIB_PATH is set), giving ≥10× speedup for n_sites ≥ 10. Falls back transparently to the pure-Python Lanczos algorithm otherwise.

Parameters:

  • n_sites (int) – Number of spin-½ sites (Hilbert-space dimension = 2^n_sites).

  • J (float) – Transverse exchange coupling (XX + YY part, scaled by J/2 in the Hamiltonian).

  • Jz (float) – Longitudinal exchange (ZZ part). Jz = J → isotropic Heisenberg.

  • h (float) – Uniform longitudinal field h Σ Z_i.

Returns:

Eigenvalues are in ascending order; at most self.k values are returned (may be fewer if the Hilbert space is small).

Return type:

EigenResult

static ising_1d(n_sites, J=1.0, h=0.5)[source]¶

1D transverse-field Ising H = -J sum ZiZi+1 - h sum Xi (periodic BC).

Hilbert space: 2^n_sites, basis states |s0 s1 … s_{n-1}>, si in {0,1}. State index: i = s0 + 2*s1 + 4*s2 + …

static heisenberg_1d(n_sites, J=1.0, hz=0.0)[source]¶

1D Heisenberg H = J sum (Xi Xi+1 + Yi Yi+1 + Zi Zi+1) + hz sum Zi (open BC).

XX+YY = 2(S+S- + S-S+): flips adjacent antiparallel spins. ZZ: diagonal. For spin-1/2: S+|0>=|1>, S+|1>=0; S-|1>=|0>, S-|0>=0 (|0>=up, |1>=down). Xi Xi+1 + Yi Yi+1 = 2(S+i S-i+1 + S-i S+i+1) where S+/- = sigma+/-/2. Matrix element for antiparallel flip: J * 0.5.

static from_pauli_terms(n_sites, terms)[source]¶

Build a SparseHamiltonian from a list of Pauli-string terms.

Each term is a (coefficient, ops, sites) triple where:

  • coefficient — real or complex scalar prefactor.

  • ops — string of single-character Pauli labels, one per site (e.g. "ZZ", "XY", "Z"). Supported: 'I', 'X', 'Y', 'Z'.

  • sites — list of qubit indices, same length as ops.

The Hamiltonian acts on a 2ⁿ-dimensional Hilbert space with the computational basis ordered as \(|s_0, s_1, \ldots, s_{n-1}\rangle\) where \(s_i = (\text{state} >> i) \& 1\).

Parameters:

  • n_sites (int) – Number of qubits.

  • terms (list[tuple[float | complex, str, list[int]]]) – List of (coefficient, ops, sites) tuples.

Return type:

SparseHamiltonian

Examples

Reproduce a 3-site ZZ + transverse-field Ising model:

H = SparseHamiltonian.from_pauli_terms(3, [
    (-1.0, "ZZ", [0, 1]),
    (-1.0, "ZZ", [1, 2]),
    (-0.5, "X",  [0]),
    (-0.5, "X",  [1]),
    (-0.5, "X",  [2]),
])
static xxz_chain(n_sites, J=1.0, delta=1.0, hz=0.0)[source]¶

1D XXZ spin chain (open BC).

\[H = J \sum_{i=0}^{n-2} \left[ \frac{1}{2}(\sigma^+_i \sigma^-_{i+1} + \text{h.c.}) + \Delta\, Z_i Z_{i+1} \right] + h_z \sum_i Z_i\]

where \(\sigma^+ = \begin{pmatrix}0&1\\0&0\end{pmatrix}\), J is the overall exchange scale, and delta (Δ) is the anisotropy ratio.

Special cases:

  • delta=1: isotropic Heisenberg antiferromagnet; xxz_chain(n, J=J, delta=1) equals heisenberg_1d(n, J=J)

  • delta=0: XX model (free-fermion), no ZZ coupling

  • delta→∞: classical Ising limit

Parameters:

  • n_sites (int) – Number of spins. Must be >= 1.

  • J (float) – Overall exchange coupling (energy scale).

  • delta (float) – Anisotropy Δ = J_z / J_xy.

  • hz (float) – Uniform longitudinal field.

static heisenberg_2d(Lx, Ly, J=1.0)[source]¶

2D Heisenberg model on an Lx × Ly rectangular lattice (open BC).

\[H = J \sum_{\langle ij \rangle} \left[ Z_i Z_j + \frac{1}{2}(\sigma^+_i \sigma^-_j + \text{h.c.}) \right]\]

Sites are labelled (x, y) → x + y·Lx. Bonds connect (x, y)–(x+1, y) (horizontal) and (x, y)–(x, y+1) (vertical).

Parameters:

  • Lx (int) – Lattice dimensions. Total sites = Lx * Ly ≤ 20 (dense backend).

  • Ly (int) – Lattice dimensions. Total sites = Lx * Ly ≤ 20 (dense backend).

  • J (float) – Exchange coupling.

static bose_hubbard(L, t=1.0, U=4.0, max_occ=4)[source]¶

Bose-Hubbard model on a 1D chain (open BC).

\[H = -t \sum_i (a^\dagger_i a_{i+1} + \text{h.c.}) + \frac{U}{2} \sum_i n_i(n_i - 1)\]

Fock basis: each site holds 0 … max_occ bosons. State index:

\[\text{idx} = \sum_{i=0}^{L-1} n_i \cdot M^i, \quad M = \text{max\_occ} + 1\]

Hilbert space dimension: (max_occ + 1)^L.

Parameters:

  • L (int) – Number of sites.

  • t (float) – Hopping amplitude.

  • U (float) – On-site interaction strength.

  • max_occ (int) – Maximum occupation per site (truncation).

static hubbard_1d(L, t=1.0, U=4.0)[source]¶

Single-band Fermi-Hubbard model on a 1D chain (open BC).

\[H = -t \sum_{i,\sigma} (c^\dagger_{i,\sigma} c_{i+1,\sigma} + \text{h.c.}) + U \sum_i n_{i,\uparrow} n_{i,\downarrow}\]

Encoding: spin-up occupations in the lower L bits (bit i = site i spin-up), spin-down occupations in the upper L bits. State index: up_bits | (down_bits << L). Hilbert space dimension: 4^L = 2^{2L}.

JW ordering — (\uparrow_0, \uparrow_1, \ldots, \downarrow_0, \downarrow_1, \ldots) — gives sign +1 for nearest-neighbour intra-sector hopping.

Parameters:

  • L (int) – Number of sites.

  • t (float) – Hopping amplitude.

  • U (float) – On-site Hubbard interaction.
