quantx_engine.structure_factor¶

Dynamical spin structure factor S(k, omega) via MPS time evolution.

Wraps qx_spectral (src/dmrg_blocks.cpp via src/dmrg_capi.cpp): computes the time-dependent ground-state correlations:

C_{j,l0}(t) = <psi0| sigma^z_j  e^{-i(H-E0) t}  sigma^z_{l0} |psi0>

for a central source site l0 of a spin-1/2 Heisenberg chain – DMRG for the ground state, block-sparse (Sz-symmetric) real-time TEBD for the evolution, and a block two-MPS overlap for the measurement. A space+time Fourier transform turns C into the dynamical structure factor

S(k, omega) = sum_{r,t} e^{-i k r} e^{i omega t} C_r(t).

This is distinct from quantx_engine.contrib.spectral (Lehmann/Krylov spectral functions on dense/sparse Hamiltonians); this module is the MPS route that scales to large chains.

Example

from quantx_engine import Engine from quantx_engine.structure_factor import StructureFactorSolver

s = StructureFactorSolver(Engine()) r = s.correlations(24, dt=0.05, n_steps=400, chi_max=128) k, w, S = s.structure_factor(r) # 2-D array S[k, omega] >= 0

static structure_factor(res, *, n_omega=512, omega_max=None, eta=0.1)[source]¶

Fourier transform C_{j,l0}(t) into S(k, omega).

Uses a Gaussian time window exp(-(eta t)^2 / 2) to damp finite-time truncation ringing, the symmetry C_r(-t) = conj(C_{-r}(t)) to extend to negative time, and a discrete spatial transform on the open chain (referenced to the source site l0).

Parameters:

  • res (DSFResult) – Output of correlations.

  • n_omega (int) – Number of omega grid points in [0, omega_max].

  • omega_max (float, optional) – Max frequency (default 2*pi).

  • eta (float) – Gaussian frequency broadening (time-domain damping rate).

Returns:

  • ks (np.ndarray, shape (n,)) – Momenta in [0, 2*pi).

  • omegas (np.ndarray, shape (n_omega,))

  • S (np.ndarray, shape (n, n_omega), real) – Dynamical structure factor.

class quantx_engine.structure_factor.ConductivitySolver(engine)[source]¶

Bases: object

Spin conductivity of the XXZ chain (native C++ backend).

Computes the zero-temperature current-current correlator C(t) = <J(t)J(0)> (J = total spin current) via DMRG ground state + block MPO x MPS apply (phi = J|psi0>) + block TEBD evolution + two-MPS overlap. sigma(omega) is the Fourier transform of C(t).
