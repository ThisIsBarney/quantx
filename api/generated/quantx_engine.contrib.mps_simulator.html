quantx_engine.contrib.mps_simulator¶

M104/M109: MPS simulator — adaptive bond dimension, environment caching, GPU acceleration (CuPy backend), and benchmarks for 50+ qubit circuits.

Three additions to the existing tensor-network stack:

Adaptive truncation

SVD-compress each bond to keep only singular values above a relative threshold eps * S_max, up to max_bond. Bond dimension grows and shrinks dynamically instead of being pinned at a fixed value.

MPSSimulator

Gate-level MPS circuit simulator:

  • Single-qubit gates — applied directly (no truncation needed).

  • Two-qubit gates on adjacent sites — two-site SVD with adaptive truncation.

  • Accumulated truncation error tracked across all gates.

  • Left/right environment cache for fast expectation-value sweeps.

CachedDMRG

DMRG variant that retains the left-environment stack built during the left-to-right pass and reuses it during the right-to-left pass, reducing environment reconstruction from O(N²) to O(N) per sweep.

Benchmark + validation helpers

mps_benchmark — time a random circuit, report truncation error. ghz_fidelity — fidelity of MPS-prepared GHZ state vs exact. compare_mps_sv — cross-validate MPS against statevector for n ≤ 20.

Quick start:

from quantx_engine.contrib.mps_simulator import (
    MPSSimulator, mps_benchmark, ghz_fidelity, gpu_mps_benchmark,
)

# CPU simulation (default)
sim = MPSSimulator(n_qubits=50, max_bond=2, eps=1e-12)
sim.h(0)
for q in range(49):
    sim.cx(q, q + 1)
fid = ghz_fidelity(50, max_bond=2)
print(f"GHZ fidelity at n=50: {fid:.6f}")

# GPU simulation — falls back to CPU when CuPy is unavailable
sim_gpu = MPSSimulator(n_qubits=30, max_bond=32, backend="cuda")
sim_gpu.h(0)
for q in range(29):
    sim_gpu.cx(q, q + 1)

# GPU vs CPU throughput benchmark
result = gpu_mps_benchmark(n_qubits=30, circuit_depth=10, max_bond=32)
print(result)

Physical validation¶

GHZ state at n=50 with bond dimension chi=2 achieves fidelity = 1.0 (exact because GHZ has Schmidt rank 2 at every bipartition). Verified against explicit statevector inner product in the test suite.

Bases: object

Gate-level MPS circuit simulator with adaptive bond dimension.

Initialised in the computational-basis state |000…0⟩. Single-qubit gates are applied in-place with no truncation; two-qubit gates on adjacent qubits use a two-site SVD contraction.

Parameters:

  • n_qubits (int) – Number of qubits.

  • max_bond (int) – Hard bond-dimension cap.

  • eps (float) – Relative SVD truncation threshold.

  • backend ("cpu" | "cuda") – Compute backend. "cuda" uses CuPy for GPU-accelerated tensor contractions and SVD; falls back to NumPy silently when CuPy is absent so code is portable across CPU-only machines.

class quantx_engine.contrib.mps_simulator.CachedDMRG(mpo, max_chi=32, eps=1e-10, n_sweeps=10, tol=1e-08, seed=None)[source]¶

Bases: object

DMRG with cached environment tensors for O(N) per-sweep complexity.

The standard DMRG rebuilds the left-environment from scratch during the right-to-left pass (_build_left_env_to, O(N) cost per site → O(N²) total). This variant retains the left-environment stack built during the left-to-right pass and reads from it during the right-to-left pass.

Parameters:

  • mpo (MPO) – Hamiltonian.

  • max_chi (int) – Hard bond-dimension cap.

  • eps (float) – Relative SVD truncation threshold for adaptive bond dimension. If None, fall back to fixed max_chi truncation.

  • n_sweeps (int) – Maximum number of left+right sweeps.

  • tol (float) – Convergence threshold on the per-sweep energy change.

  • seed (int | None) – Random seed for the initial MPS.

  • eps (float) – Relative SVD truncation threshold.

  • seed (int | None) – Random seed for the rotation angles.

quantx_engine.contrib.mps_simulator.ghz_fidelity(n_qubits, max_bond=2, eps=1e-12)[source]¶

Fidelity of an MPS-prepared GHZ state vs the exact GHZ state.

The GHZ circuit is: H on qubit 0, then CNOT(i, i+1) for i = 0 … n-2. The exact GHZ state has bond dimension 2 everywhere, so max_bond=2 is sufficient for lossless representation.

Parameters:

  • n_qubits (int) – Number of qubits (works for n ≥ 1, useful at n = 50).

  • max_bond (int) – MPS bond dimension cap.

  • eps (float) – Relative SVD truncation threshold.

Returns:

Fidelity F = |⟨GHZ_exact | GHZ_MPS⟩|² ∈ [0, 1].

Return type:

float

quantx_engine.contrib.mps_simulator.gpu_mps_benchmark(n_qubits=30, circuit_depth=10, max_bond=32, eps=1e-12, seed=0, warmup=True)[source]¶

Compare GPU vs CPU throughput for an MPS circuit simulation.

Runs the same random circuit twice — once on CPU (NumPy) and once on GPU (CuPy when available, otherwise a second CPU run) — and reports wall-clock times and speedup.

Parameters:

  • n_qubits (int) – Number of qubits. Default 30 exercises meaningful bond growth.

  • circuit_depth (int) – Number of alternating Ry + CZ entangling layers.

  • max_bond (int) – Hard bond-dimension cap.

  • eps (float) – Relative SVD truncation threshold.

  • seed (int | None) – Random seed for rotation angles (same for both runs).

  • warmup (bool) – When True, run a single-layer warm-up pass on the GPU before timing to avoid CUDA JIT compilation latency in the timed run.

Return type:

GpuBenchmarkResult
