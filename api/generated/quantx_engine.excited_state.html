quantx_engine.excited_state¶

M113: Excited-state quantum chemistry.

Provides tools for computing excited-state energies and wavefunctions using variational quantum methods:

  • Exact diagonalization (ED) — exact for n_qubits ≤ 16; returns all eigenvalues/vectors via numpy.linalg.eigh.

  • Deflation VQE — iteratively adds a penalty λ|ψ_k⟩⟨ψ_k| to the Hamiltonian so that subsequent minimizations converge to the next excited state rather than repeating the ground state.

  • Folded-spectrum VQE — minimises ⟨(H − ω)²⟩ to target the eigenstate closest to a chosen energy ω.

Conical-intersection (near-degeneracy) detection sweeps a molecular geometry parameter and finds the crossing points between adjacent eigenvalue curves.

[2]

McClean, J. R. et al. (2017). Hybrid quantum-classical hierarchy for mitigation of decoherence and determination of excited states. Phys. Rev. A 95, 042308. https://doi.org/10.1103/PhysRevA.95.042308

[3]

Santagati, R. et al. (2018). Witnessing eigenstates for quantum simulation of Hamiltonian spectra. Sci. Adv. 4, eaap9646. https://doi.org/10.1126/sciadv.aap9646

Physical validation¶

Deflation VQE on a 4-qubit Hamiltonian reproduces the gap between the two lowest eigenvalues to within 1e-4 of exact diagonalisation (numpy.linalg.eigh reference). Folded-spectrum VQE targeting the first excited state converges to E_1 within 1e-3.

class quantx_engine.excited_state.ExcitedStateVQE(hamiltonian, n_states=3, method='exact', penalty_weight=10.0)[source]¶

Bases: object

Variational computation of multiple excited states.

Parameters:

  • hamiltonian (PauliHamiltonian) – The molecular Hamiltonian (or any Hermitian operator).

  • n_states (int, default 3) – Number of states to compute (including the ground state).

  • method ({"exact", "deflation", "folded_spectrum"}, default "exact") –

    Algorithm to use:

    • "exact" — full numpy diagonalisation (best for n ≤ 16).

    • "deflation" — variational deflation: penalise previously found states with a positive-definite projection term.

    • "folded_spectrum" — minimise ⟨(H−ω)²⟩ for a sequence of ω values spaced across the spectrum.

  • penalty_weight (float, default 10.0) – Weight λ used in the deflation penalty ΔH = λ Σ |ψ_k⟩⟨ψ_k|. Only used when method="deflation".

quantx_engine.excited_state.detect_conical_intersections(hamiltonians, parameter_values, n_states=3, gap_threshold=0.01, state_pairs=None)[source]¶

Detect near-degeneracies (conical intersections) along a parameter scan.

Sweeps a molecular geometry (or any continuous parameter) and finds the values at which two adjacent eigenvalue curves come within gap_threshold of each other.

Parameters:

  • hamiltonians (list[PauliHamiltonian]) – Hamiltonian at each parameter value (same length as parameter_values).

  • parameter_values (list[float]) – Parameter values (e.g. bond lengths in Ångström).

  • n_states (int, default 3) – Number of lowest states to track.

  • gap_threshold (float, default 0.01) – Energy gap below which two states are declared near-degenerate.

  • state_pairs (list[(int, int)] | None) – Which pairs of states to check. Defaults to consecutive pairs (0,1), (1,2), ….

Return type:

ConicalIntersectionResult

quantx_engine.excited_state.pyscf_to_pauli_hamiltonian(mol_data)[source]¶

Convert a PySCF-style molecular data dictionary to a PauliHamiltonian.

This is a lightweight adapter for the most common PySCF output format. It requires PySCF to be installed (pip install pyscf).

Parameters:

mol_data (dict) – Dictionary with keys "one_body_integrals", "two_body_integrals", "n_electrons", and "n_orbitals". This format matches the output of a PySCF RHF calculation processed through openfermion.chem.molecular_data.

Returns:

Jordan-Wigner encoded Hamiltonian.
