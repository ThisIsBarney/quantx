quantx_engine.contrib.qldpc¶

M121: Quantum LDPC codes — hypergraph product and bicycle constructions.

Implements:

  • ClassicalCode — binary parity-check matrix utilities

  • HypergraphProductCode — [[n₁n₂+n₁’n₂’, k₁k₂, d]] CSS code

  • LDPCDecoder — belief-propagation + OSD post-processing

  • bicycle_code() — quasi-cyclic bicycle (QC-LDPC) construction

References

  • Tillich, J.-P. & Zémor, G. (2014). Quantum LDPC codes with positive rate and minimum distance proportional to the square root of the blocklength. IEEE Trans. Inf. Theory 60, 1193–1202.

  • Panteleev, P. & Kalachev, G. (2022). Asymptotically good quantum and locally testable classical LDPC codes. STOC 2022.

  • Fossorier, M. P. C. (2004). Quasi-cyclic low-density parity-check codes. IEEE Trans. Inf. Theory 50, 1788–1793.

Physical validation¶

[[n,k,d]] bicycle code: rate k/n and distance d verified against classical RREF rank calculation. CSS commutativity Hz·Hx^T = 0 (mod 2) checked for all generated codes.

class quantx_engine.contrib.qldpc.HypergraphProductCode(code1, code2)[source]¶

Bases: object

CSS quantum code via the hypergraph product of two classical codes.

Given classical codes C₁ = [n₁, k₁] with parity-check H₁ (m₁×n₁) and C₂ = [n₂, k₂] with H₂ (m₂×n₂), the hypergraph product code has

  • Physical qubits: N = n₁n₂ + m₁m₂

  • Logical qubits: K = k₁k₂ + k₁’k₂’ (k_i’ = n_i − m_i if H_i is full rank)

  • X stabilisers: Hx = [H₁ ⊗ I_{n₂} | I_{m₁} ⊗ H₂ᵀ]

  • Z stabilisers: Hz = [I_{n₁} ⊗ H₂ | H₁ᵀ ⊗ I_{m₂}]

Parameters:

  • code1 (ClassicalCode) – First classical seed code C₁.

  • code2 (ClassicalCode) – Second classical seed code C₂.

quantx_engine.contrib.qldpc.bicycle_code(L, a_shifts, b_shifts)[source]¶

Construct a quasi-cyclic bicycle (QC-LDPC) CSS code.

A bicycle code is built from two circulant matrices A, B of size L × L, where A = Σᵢ P^{aᵢ} and B = Σⱼ P^{bⱼ} (P is the L × L cyclic shift). The parity-check matrices are:

Hx = [A | B]      Hz = [Bᵀ | Aᵀ]

which are the hypergraph product of the circulant codes defined by A and B.

Parameters:

  • L (int) – Circulant size (must be > 0).

  • a_shifts (sequence of int) – Positions of the 1s in the first row of A (shifts of P).

  • b_shifts (sequence of int) – Positions of the 1s in the first row of B (shifts of P).

Returns:

The resulting bicycle CSS code.

Return type:

HypergraphProductCode
