quantx_engine.noise_vqe¶

Noise-aware VQE — M95.

Extends the existing VQE machinery with:

  • Shot noise — expectation values are estimated from a finite number of measurement samples rather than exact computation.

  • Hardware noise model — each gate application is followed by the appropriate depolarizing / amplitude-damping channel (via the density-matrix simulator in quantx_engine.primitives).

  • SPSA optimizer — Simultaneous Perturbation Stochastic Approximation uses only 2 function evaluations per iteration regardless of parameter count and is therefore well-suited for noisy landscapes.

  • Nelder-Mead fallback — included for noiseless or low-shot settings.

Classes¶

  • NoiseVQEError — base exception.

  • SPSAOptimizer — gradient-free SPSA optimizer.

  • NoiseAwareVQEResult — result container.

  • NoiseAwareVQE — main solver.

Functions¶

  • hardware_efficient_vqe() — convenience wrapper.

  • build_hea_circuit() — construct a hardware-efficient ansatz circuit dict.

References

[1]

Kandala, A. et al. (2017). Hardware-efficient variational quantum eigensolver for small molecules and quantum magnets. Nature 549, 242–246. https://doi.org/10.1038/nature23879

[2]

Temme, K., Bravyi, S. & Gambetta, J. M. (2017). Error mitigation for short-depth quantum circuits. Phys. Rev. Lett. 119, 180509. https://doi.org/10.1103/PhysRevLett.119.180509

[3]

Spall, J. C. (1992). Multivariate stochastic approximation using a simultaneous perturbation gradient approximation. IEEE Trans. Autom. Control 37, 332–341. https://doi.org/10.1109/9.119632

Physical validation¶

Noise-aware VQE on H2 minimal basis converges to a final energy within 10% of the noiseless FCI value for depolarising error rate p <= 0.01 per gate. ZNE (zero-noise extrapolation) Richardson extrapolation reduces the bias by an order of magnitude compared to uncorrected noisy VQE [Temme2017].

class quantx_engine.noise_vqe.SPSAOptimizer(a=0.1, c=0.1, A=10.0, alpha=0.602, gamma=0.101, seed=42)[source]¶

Bases: object

Simultaneous Perturbation Stochastic Approximation (SPSA) optimizer.

Uses only 2 function evaluations per iteration regardless of parameter count, making it efficient for noisy energy landscapes.

The gradient estimate is:

ĝ_k = [f(θ_k + c_k Δ_k) − f(θ_k − c_k Δ_k)] / (2 c_k) · Δ_k⁻¹

where Δ_k is a random ±1 Bernoulli vector (Rademacher distribution).

Update rule:

θ_{k+1} = θ_k − a_k ĝ_k
a_k = a / (A + k + 1)^α
c_k = c / (k + 1)^γ
Parameters:

  • a (float) – Initial step size numerator (controls learning rate magnitude).

  • c (float) – Initial perturbation size (should be ≈ noise level in f).

  • A (float) – Stability constant (typically set to ≈ 10 % of max_iter).

  • alpha (float) – Step-size decay exponent (theory: 0.602).

  • gamma (float) – Perturbation-size decay exponent (theory: 0.101).

  • seed (int or None) – Random seed for reproducibility.

class quantx_engine.noise_vqe.NoiseAwareVQE(hamiltonian, n_qubits, n_layers=2, noise_model=None, n_shots=1000, optimizer='spsa', max_iter=150, tol=0.0001, entanglement='linear', spsa_a=0.1, spsa_c=0.1, seed=42)[source]¶

Bases: object

Variational Quantum Eigensolver with hardware noise and shot noise.

Parameters:

  • hamiltonian (SparsePauliOp or ndarray) – Observable whose ground-state energy to minimise. If an ndarray, it must be Hermitian with shape (2^n, 2^n).

  • n_qubits (int) – Number of qubits.

  • n_layers (int) – Number of HEA layers.

  • noise_model (NoiseModel or None) – Hardware noise model (e.g. DepolarizingNoise, ThermalRelaxationNoise, …). If None no hardware noise is applied.

  • n_shots (int) – Shots per energy evaluation. Set to 0 for exact (noiseless) expectation values.

  • optimizer (str) – "spsa" (default, recommended for noisy settings) or "nelder-mead".

  • max_iter (int) – Maximum optimizer iterations.

  • tol (float) – Convergence tolerance on energy change.

  • entanglement (str) – HEA entanglement pattern: "linear" (default) or "full".

  • spsa_a (float) – SPSA step-size parameter a.

  • spsa_c (float) – SPSA perturbation parameter c.

  • seed (int or None) – Random seed.
