quantx_engine.transpiler¶

Hardware-aware circuit transpilation (M76).

Three main components:

CouplingMap — hardware qubit connectivity (undirected graph). Factory methods for common topologies: linear(), ring(), grid(), all_to_all(). Provides BFS shortest-path for routing.

HardwareTranspiler — compiles a circuit (list of GateOp) to a target device:

  1. Gate decomposition — rewrites non-native gates into the device’s native gate set ({CX+Rz} or {CZ+Rz}).

  2. SWAP insertion — moves logical qubits to physically-adjacent positions before each non-adjacent two-qubit gate (greedy path-following algorithm).

  3. Peephole optimisation (optimization_level ≥ 2) — cancels adjacent inverse-gate pairs and redundant SWAP·SWAP sequences.

TranspileResult — reports the transpiled circuit, logical→physical qubit map, number of inserted SWAPs, and gate/depth metrics.

Quick start:

from quantx_engine.transpiler import (
    CouplingMap, GateOp, HardwareTranspiler,
)

dev = CouplingMap.linear(3)            # 0-1-2
circ = [GateOp("cx", [0, 2])]          # non-adjacent CX: needs SWAP
transpiler = HardwareTranspiler(dev, native_gates="cx_rz")
result = transpiler.transpile(circ)
print(result.n_swaps)                  # 1

class quantx_engine.transpiler.HardwareTranspiler(coupling_map, native_gates='cx_rz')[source]¶

Bases: object

Hardware-aware circuit transpiler.

Parameters:

  • coupling_map (CouplingMap) – Physical device topology.

  • native_gates (str | frozenset[str]) –

    Specifies the device’s native gate set. Either a string shorthand ("cx_rz", "cz_rz", "all") or a custom frozenset[str] of lower-case gate names.

    • "cx_rz" — CX/CNOT-based devices (e.g. IBM superconducting): {cx, h, x, y, z, s, sdg, t, tdg, rz, rx, ry, …}

    • "cz_rz" — CZ-based devices (e.g. Google, Rigetti): {cz, h, x, y, z, s, sdg, t, tdg, rz, rx, ry, sx, …}

    • "all" — accept all standard gates (no decomposition).

Examples

>>> dev = CouplingMap.linear(3)
>>> t = HardwareTranspiler(dev)
>>> result = t.transpile([GateOp("cx", [0, 2])])
>>> result.n_swaps
1

transpile(circuit, initial_mapping=None, optimization_level=1)[source]¶

Compile circuit to the target hardware.

Parameters:

  • circuit (list[GateOp]) – Input gate list using logical qubit indices (0, 1, …).

  • initial_mapping (dict[int, int] | None) – Logical → physical qubit assignment. If None, the identity mapping (logical i → physical i) is used. The number of logical qubits must not exceed coupling_map.n_qubits.

  • optimization_level (int) – 0 = no optimisation; 1 = default (basic); 2 = peephole cancellation of adjacent inverse gates.

Return type:

TranspileResult

Raises:

TranspilerError – If the circuit requires more logical qubits than the device has physical qubits, or if a gate cannot be decomposed.
