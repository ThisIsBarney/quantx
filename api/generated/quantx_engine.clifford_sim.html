quantx_engine.clifford_sim¶

M110: Large-scale Clifford (stabilizer) simulation.

Implements the Aaronson-Gottesman binary symplectic tableau algorithm [arXiv:quant-ph/0406196] which tracks an n-qubit stabilizer state in O(n²) bits and applies every Clifford gate in O(n) time. The algorithm scales to 10 000+ qubits where state-vector simulation is completely infeasible.

Classes¶

StabilizerState

Full Aaronson-Gottesman tableau: (2n) × (2n+1) boolean array. Initialised to |0…0⟩.

CliffordSimulator

Gate-level interface wrapping StabilizerState. Supported gates:

h(q)          Hadamard
s(q)          Phase (S = √Z)
sdg(q)        S†
x(q)          Pauli-X
y(q)          Pauli-Y
z(q)          Pauli-Z
cx(ctrl, tgt) CNOT
cz(q0, q1)    CZ   (= H·CNOT·H)
swap(q0, q1)  SWAP (= CX·CX†·CX)
measure(q)    Single-qubit Z-measurement (returns 0 or 1,
              collapses state randomly when outcome is
              indeterminate)
StimCircuit

Lightweight Stim-compatible circuit parser. Reads the textual Stim circuit format and translates supported gates to CliffordSimulator calls:

QUBIT_COORDS, TICK             skipped
H, S, S_DAG, X, Y, Z          single-qubit Clifford
CNOT, CX, CZ, SWAP            two-qubit Clifford
M, MZ                         Z-measurement

Quick start:

from quantx_engine.clifford_sim import CliffordSimulator, StimCircuit

# 10 000-qubit GHZ circuit
sim = CliffordSimulator(n_qubits=10_000)
sim.h(0)
for q in range(9_999):
    sim.cx(q, q + 1)

# Measure all qubits — should all collapse to the same value
outcomes = [sim.measure(q) for q in range(10_000)]
assert len(set(outcomes)) == 1        # all 0s or all 1s

# Stim circuit import
stim_text = '''
H 0
CNOT 0 1
M 0 1
'''
circ = StimCircuit.from_string(stim_text)
results = circ.run()                  # returns list of measurement outcomes

Physical validation¶

Bell state prepared via H(0)+CNOT(0,1): stabilizer generators are <XX, ZZ>. Clifford simulation reproduces Bell-state correlations: Z_0 Z_1 = +1, X_0 X_1 = +1, Z_0 Z_1 Y_0 Y_1 = -1 (standard Bell-state relations). 10000-qubit GHZ state runs in O(n) time via tableau updates [Aaronson2004].

class quantx_engine.clifford_sim.StabilizerState(n_qubits)[source]¶

Bases: object

Aaronson-Gottesman binary symplectic tableau for n-qubit stabilizer states.

Tableau layout (following [AG04] Section 4)¶

Row indices 0..n-1 : destabilizer generators Row indices n..2n-1 : stabilizer generators Column layout per row: [x_0, …, x_{n-1}, z_0, …, z_{n-1}, r]

where x_i, z_i ∈ {0,1} and r ∈ {0,1} is the phase (r=1 means −1 factor).

All Clifford gates are O(n) vectorized numpy operations (no Python loops).

param n_qubits:

Number of qubits. The tableau shape is (2n) × (2n+1).

type n_qubits:

int

Gate-level Clifford circuit simulator using the Aaronson-Gottesman tableau.

All operations run in O(n) time; the full state fits in O(n²) bits, enabling 10 000+ qubit simulation on commodity hardware.

pauli_expectation(pauli)[source]¶

Return expectation value of a Pauli string: +1.0, -1.0, or 0.0.

Returns +1 if the Pauli is in the stabiliser group, -1 if its negative is, and 0 if the outcome is indeterminate (the Pauli does not commute with at least one generator).

Parameters:

pauli (str) – Pauli string of length n_qubits, each character in {I,X,Y,Z}.
