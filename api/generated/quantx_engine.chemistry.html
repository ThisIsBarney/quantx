quantx_engine.chemistry¶

Quantum chemistry module for the QuantX engine.

Provides Jordan-Wigner transformation of molecular Hamiltonians and pre-built molecular VQE problem instances for small molecules.

Molecules included:

H2 (hydrogen molecule) — 2 electrons, 2 spatial orbitals → 4 qubits LiH (lithium hydride) — 4 active electrons, 5 spatial orbitals → 10 qubits BeH2 (beryllium hydride) — 4 active electrons, 6 spatial orbitals → 12 qubits

Usage:

from quantx_engine.chemistry import MolecularVQE problem = MolecularVQE.h2(bond_length=0.735) vqe_opts = problem.to_vqe_options(ansatz=”uccsd”, shots=1024) result = engine.run_vqe(vqe_opts)

References

[1]

Peruzzo, A. et al. (2014). A variational eigenvalue solver on a photonic chip. Nat. Commun. 5, 4213. https://doi.org/10.1038/ncomms5213

[2]

Jordan, P. & Wigner, E. (1928). Ueber das Paulische Aequivalenzverbot. Z. Phys. 47, 631–651. https://doi.org/10.1007/BF01331938

[3]

Helgaker, T., Jorgensen, P. & Olsen, J. (2000). Molecular Electronic- Structure Theory. Wiley. ISBN 978-0-471-96755-2.

Physical validation¶

H2 minimal-basis VQE (4 qubits, UCCSD ansatz, bond length 0.735 Angstrom) converges to E_FCI = -1.8572750 Hartree (Full-CI reference from Peruzzo 2014, Table 1).

quantx_engine.chemistry.jordan_wigner(one_body, two_body, n_orbitals, constant=0.0)[source]¶

Apply the Jordan-Wigner transform to a second-quantized Hamiltonian.

H = constant + Σ h_pq a†_p a_q + ½ Σ g_pqrs a†_p a†_q a_r a_s

Each fermionic mode p maps to qubit p via:

a†_p = (X_p - iY_p)/2 × Z_0 ⊗ … ⊗ Z_{p-1} a_p = (X_p + iY_p)/2 × Z_0 ⊗ … ⊗ Z_{p-1}

Parameters:

  • one_body (list[tuple[int, int, float]]) – List of (p, q, h_pq) tuples for one-body integrals.

  • two_body (list[tuple[int, int, int, int, float]]) – List of (p, q, r, s, g_pqrs) tuples for two-body integrals (physicist notation: ⟨pq|rs⟩).

  • n_orbitals (int) – Number of spin-orbitals (= 2 × spatial orbitals for spin ½).

  • constant (float) – Nuclear repulsion / constant energy shift.

Returns:

Qubit Hamiltonian in the Pauli basis.

Return type:

PauliHamiltonian

to_vqe_options(ansatz='uccsd', shots=0, max_iterations=200, optimizer='cobyla')[source]¶

Build a VQE options dict suitable for Engine.run_vqe().

The returned dict uses keys expected by the QuantX VQE parser: cost_hamiltonian (list of {label, coefficient}), ansatz_type, and max_iterations.

Note: the Hamiltonian integrals are pre-computed at equilibrium geometry (fixed STO-3G integrals). Changing bond_length only affects the FCI reference energy used for benchmark comparison, not the qubit Hamiltonian itself.

Parameters:

  • ansatz (str) – Ansatz type: ‘uccsd’ or ‘hardware_efficient’.

  • shots (int) – Number of shots per circuit evaluation (0 = statevector).

  • max_iterations (int) – Maximum optimizer iterations.

  • optimizer (str) – Classical optimizer: ‘cobyla’, ‘spsa’, or ‘l_bfgs_b’.

Return type:

dict compatible with Engine.run_vqe() / Engine.run_solver(‘vqe’, …).
