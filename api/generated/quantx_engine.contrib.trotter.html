quantx_engine.contrib.trotter¶

Hamiltonian simulation via Suzuki-Trotter product formulas (M101).

References

[1]

Trotter, H. F. (1959). On the product of semi-groups of operators. Proc. Amer. Math. Soc. 10, 545–551. https://doi.org/10.1090/S0002-9939-1959-0108732-6

[2]

Suzuki, M. (1991). General theory of fractal path integrals with applications to many-body theories and statistical physics. J. Math. Phys. 32, 400–407. https://doi.org/10.1063/1.529425

[3]

Childs, A. M. et al. (2021). Theory of Trotter error with commutator scaling. Phys. Rev. X 11, 011020. https://doi.org/10.1103/PhysRevX.11.011020

Physical validation¶

For non-commuting terms, the 2nd-order (symmetric) decomposition S₂ satisfies ‖S₂(t,n) − e^{−iHt}‖ = O((t/n)³) while 1st-order satisfies O((t/n)²). With H = 0.5·XZ + 0.3·ZZ (non-commuting), t = 1, n = 4 steps:

order-1 error ≈ 3.5 × 10⁻², order-2 error ≈ 1.2 × 10⁻³.

Provides first-, second-, and fourth-order Suzuki-Trotter decompositions for Hamiltonians expressed as weighted sums of Pauli strings:

H = Σ_k  c_k  P_k,   P_k ∈ {I, X, Y, Z}^⊗n

Each term is exponentiated analytically using the identity:

exp(-i θ P) = cos(θ) I - i sin(θ) P

which holds for any Pauli string because P² = I. No full matrix exponentiation is needed for individual terms.

Quick start:

from quantx_engine.contrib.trotter import TrotterSimulator, TrotterTerm

# Heisenberg XY dimer: H = XX + YY
sim = TrotterSimulator(
    n_qubits=2,
    terms=[TrotterTerm(1.0, "XX"), TrotterTerm(1.0, "YY")],
)
result = sim.run(t=1.0, n_steps=50, order=2, compute_exact=True)
print(result.trotter_error)   # ≈ 0 for small dt

# 1D Heisenberg chain factory
from quantx_engine.contrib.trotter import heisenberg_trotter
sim2 = heisenberg_trotter(n=4, J=1.0)
r2 = sim2.run(t=2.0, n_steps=100, order=4)

class quantx_engine.contrib.trotter.TrotterSimulator(n_qubits, terms, initial_state=None)[source]¶

Bases: object

Hamiltonian simulation via Suzuki-Trotter product formulas.

The Hamiltonian is given as a sum of weighted Pauli strings:

H = Σ_k  c_k  P_k

The unitary exp(-iHt) is approximated by composing single-term exponentials exp(-i c_k P_k Δt) (each exact analytically) arranged according to a first-, second-, or fourth-order product formula.

Parameters:

  • n_qubits (int) – System size (≥ 1).

  • terms (sequence of TrotterTerm) – Pauli decomposition of H. Each term’s pauli_string length must equal n_qubits.

  • initial_state (np.ndarray or None) – Initial state vector of length 2**n_qubits. Defaults to the all-zero computational basis state |0…0⟩.

run(t, n_steps=100, order=2, compute_exact=False)[source]¶

Simulate time evolution |ψ(t)⟩ ≈ exp(-iHt)|ψ₀⟩.

Parameters:

  • t (float) – Total simulation time. Negative values evolve backward.

  • n_steps (int) – Number of Trotter steps. Larger values give higher accuracy at proportionally larger cost.

  • order ({1, 2, 4}) – Product-formula order.

  • compute_exact (bool) – If True, compute the exact state via scipy.linalg.expm and store the error ‖ψ_trotter − ψ_exact‖₂ in the result. Requires scipy.

Return type:

TrotterResult

static trotter_error_bound(n_qubits, terms, t, n_steps, order=2)[source]¶

Compute an analytical upper bound on the Trotter error.

Uses spectral-norm commutator sums:

  • Order 1: ‖err‖ ≤ (t²/2n) Σ_{j<k} |c_j c_k| ‖[P_j,P_k]‖

  • Order 2: ‖err‖ ≤ (t³/12n²) Σ_{j,k,j≠k} |c_j² c_k| ‖[[P_j,P_k],P_j]‖

  • Order 4: rough bound via ‖H‖⁵ t⁵ / (120 n⁴)

Parameters:

  • n_qubits (int) – Same semantics as run().

  • terms (Sequence[TrotterTerm]) – Same semantics as run().

  • t (float) – Same semantics as run().

  • n_steps (int) – Same semantics as run().

  • order (int) – Same semantics as run().

Returns:

Non-negative error bound.

Return type:

float
