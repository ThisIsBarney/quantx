quantx_engine.quantum_walk¶

Quantum walk algorithms for the QuantX engine (M100).

Two walk models are provided:

DiscreteTimeWalk — coined quantum walk on an undirected graph. The walker lives in a joint coin ⊗ position Hilbert space. One step applies a coin operator (Hadamard, Grover, or custom) followed by a conditional shift. Efficient for cycle graphs, complete graphs, and hypercubes; extensible to arbitrary adjacency matrices.

ContinuousTimeQuantumWalk (CTQW) — Hamiltonian is the graph Laplacian (or adjacency matrix). State evolves as |ψ(t)⟩ = exp(−iHt)|ψ₀⟩ via Krylov exponentiation (no full diagonalisation for large graphs).

GroverWalk — marks one or more target nodes and uses the quantum walk to achieve quadratic speedup over classical random search. Returns the first step at which the marked-node probability exceeds a threshold (hitting time).

Quick start:

import numpy as np
from quantx_engine.quantum_walk import DiscreteTimeWalk, ContinuousTimeQuantumWalk

# Discrete walk on a 16-node cycle, 20 steps
walk = DiscreteTimeWalk.cycle(n=16, coin="hadamard")
result = walk.run(steps=20)
print(result.position_probs)      # shape (16,)

# Continuous walk on the same cycle
ctqw = ContinuousTimeQuantumWalk.from_adjacency(walk.adjacency)
result_c = ctqw.run(t=5.0)
print(result_c.position_probs)

Physical validation¶

Continuous-time quantum walk on a cycle of N nodes: probability P(0->k,t) = |J_k(2t)|^2 in the large-N limit (Bessel function), where J_k is the k-th order Bessel function of the first kind [Aharonov1993]. Discrete-time Grover walk: quadratic speedup for finding a marked vertex [Grover1996]; amplitude at the marked vertex grows as O(1/sqrt(N)) steps.

class quantx_engine.quantum_walk.DiscreteTimeWalk(adjacency=None, coin='hadamard', initial_pos=0, initial_coin_state=None, *, n_positions=None)[source]¶

Bases: object

Coined discrete-time quantum walk on an undirected graph.

The Hilbert space is coin ⊗ position with dimension (max_degree × n_nodes). The walk operator is W = S · (C ⊗ I) where C is the coin and S is the conditional shift.

Parameters:

  • adjacency (np.ndarray) – n×n symmetric integer adjacency matrix (0/1 entries).

  • coin (str or np.ndarray) – Coin operator: 'hadamard' (default), 'grover', 'identity', or a custom unitary d×d array where d = max degree.

  • initial_pos (int) – Starting node (default 0).

  • initial_coin_state (np.ndarray or None) – Initial coin state (length d). Defaults to uniform superposition.

Continuous-time quantum walk (CTQW) on a graph.

The Hamiltonian is the graph adjacency matrix A (or Laplacian L = D − A). State evolves as |ψ(t)⟩ = exp(−i H t)|ψ₀⟩ computed via the Krylov-Arnoldi algorithm — no full diagonalisation for large graphs.

Parameters:

  • hamiltonian (np.ndarray) – n×n Hermitian matrix (adjacency or Laplacian).

  • initial_state (np.ndarray or None) – Initial state (length n). Defaults to |0⟩.

Quantum walk search using the Grover diffusion coin.

Uses a discrete-time quantum walk with a modified oracle step that flips the phase of the coin state at marked nodes, biasing the walk toward them.

Parameters:

  • graph (DiscreteTimeWalk) – A pre-configured walk (typically on a cycle or complete graph with Grover coin). The walk is reset to its initial state each call to search().

  • marked_nodes (list[int]) – Indices of nodes to find.

  • threshold (float) – Success probability threshold (default 0.5).
