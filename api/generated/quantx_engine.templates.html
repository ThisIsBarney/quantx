quantx_engine.templates¶

Circuit Templates Library — M88.

Provides a collection of standard parameterized quantum circuit ansätze and fully-fixed circuit templates, all returning circuit dicts compatible with the Estimator and Sampler primitives.

Quick reference:

from quantx_engine.templates import hardware_efficient_ansatz, ghz_circuit

# Parameterized HEA on 4 qubits, 2 layers
tmpl = hardware_efficient_ansatz(4, n_layers=2)
bound = tmpl.bind([0.1] * tmpl.n_parameters)
# bound is a plain circuit dict ready for Estimator/Sampler

# Fixed GHZ circuit (no parameters)
ghz = ghz_circuit(3)
circuit_dict = ghz.to_circuit()

References

[1]

Kandala, A. et al. (2017). Hardware-efficient variational quantum eigensolver for small molecules and quantum magnets. Nature 549, 242. https://doi.org/10.1038/nature23879 (Hardware-efficient ansatz template)

quantx_engine.templates.hardware_efficient_ansatz(n_qubits, n_layers=1, rotation='ry')[source]¶

Hardware-efficient ansatz (HEA).

Structure per layer: 1. Single-qubit rotation (rx/ry/rz) on every qubit. 2. Entangling CNOT ladder: CX(0,1), CX(1,2), …, CX(n-2, n-1).

Repeated n_layers times, followed by a final rotation layer.

Total parameters: n_qubits * (n_layers + 1).

Parameters:

  • n_qubits (int) – Number of qubits (>= 1).

  • n_layers (int) – Number of rotation + entangling layers (>= 1).

  • rotation (str) – Single-qubit rotation gate: "rx", "ry", or "rz".

Return type:

CircuitTemplate

quantx_engine.templates.iqp_circuit(n_qubits, depth=2, seed=None)[source]¶

Instantaneous Quantum Polynomial (IQP) circuit.

Structure (repeated depth times): 1. H on every qubit. 2. Diagonal phase layer: RZZ(theta_i_j) on random qubit pairs, then

RZ(phi_i) on each qubit.

Useful for quantum advantage demonstrations.

Parameters:

  • n_qubits (int) – Number of qubits (>= 2).

  • depth (int) – Number of H + diagonal-phase repetitions (>= 1).

  • seed (int | None) – Random seed for choosing which qubit pairs get RZZ interactions. Makes the structure reproducible.

Return type:

CircuitTemplate

quantx_engine.templates.qaoa_circuit(n_qubits, p_layers=1)[source]¶

QAOA ansatz for MaxCut on a ring graph.

Alternating cost (ZZ Ising) and mixer (RX) layers.

Cost layer: RZZ(2*gamma_k, i, i+1) for all ring edges (i, i+1 mod n). Mixer layer: RX(2*beta_k, i) for all qubits.

Total parameters: 2 * p_layers (gamma_0…gamma_{p-1}, beta_0…beta_{p-1}).

Parameters:

  • n_qubits (int) – Number of qubits (>= 2).

  • p_layers (int) – Number of QAOA rounds (>= 1).

Return type:

CircuitTemplate

quantx_engine.templates.quantum_fourier_transform(n_qubits, inverse=False)[source]¶

Quantum Fourier Transform (QFT) or its inverse on n qubits.

Implements the standard recursive QFT decomposition: H gate + controlled-phase gates + SWAP network.

Controlled-Rz decomposition (no native CRZ gate in the simulator):

CRZ(theta, ctrl, tgt):
    RZ(theta/2, tgt)
    CX(ctrl, tgt)
    RZ(-theta/2, tgt)
    CX(ctrl, tgt)

No free parameters (fully fixed circuit).

Parameters:

  • n_qubits (int) – Number of qubits (>= 1).

  • inverse (bool) – If True, return the inverse QFT (IQFT).

Return type:

CircuitTemplate

quantx_engine.templates.uccsd_ansatz(n_electrons, n_qubits)[source]¶

Minimal UCCSD-inspired ansatz for quantum chemistry.

Structure: 1. Hartree-Fock reference: X gates on the first n_electrons qubits

(occupying the lowest orbitals).

  1. Single excitations: For each pair (p, q) with p < n_electrons and q >= n_electrons, a parameterized RY rotation that mixes occupied and virtual orbitals.

  2. Double excitations (simplified): For each pair of single-excitation pairs ((p, q), (r, s)) taken in order, a CNOT + RZ + CNOT sequence on qubits q and s (the virtual orbitals).

This is a simplified approximation suitable for testing/demonstration, not a rigorous UCCSD implementation.

Parameters:

  • n_electrons (int) – Number of electrons (occupied orbitals). Must satisfy 1 <= n_electrons < n_qubits.

  • n_qubits (int) – Total number of spin-orbital modes (qubits). Must be >= 2.

Return type:

CircuitTemplate
