quantx_engine.contrib.sweep¶

Parallel parameter sweep utilities for QuantX.

Run any callable (solver, circuit, QML training loop) over a grid of parameters using Python’s concurrent.futures for CPU-bound parallelism.

Usage:

from quantx_engine.contrib.sweep import ParameterSweep, SweepResult, grid_sweep

# Simple grid sweep over two parameters
def my_solver(J, h):
    # ... run simulation ...
    return {"energy": -J - h}

sweep = ParameterSweep(fn=my_solver, n_workers=4)
result = sweep.run({"J": [0.5, 1.0, 2.0], "h": [0.0, 0.5, 1.0]})
df = result.to_dataframe()   # pandas if available, else list of dicts

References

[1]

Peruzzo, A. et al. (2014). A variational eigenvalue solver on a photonic chip. Nat. Commun. 5, 4213. https://doi.org/10.1038/ncomms5213 (VQE parameter sweeps as canonical example)

[2]

McClean, J. R. et al. (2018). Barren plateaus in quantum neural network training landscapes. Nat. Commun. 9, 4812. https://doi.org/10.1038/s41467-018-07090-4

run(param_grid)[source]¶

Run fn over Cartesian product of param_grid values.

param_grid: {“param1”: [v1, v2, …], “param2”: [u1, u2, …]} Each combination is passed as fn(param1=v1, param2=u1). Result of fn must be a dict (or will be wrapped as {“result”: fn(…)}).

run_list(param_list)[source]¶

Run fn over an explicit list of parameter dicts (not Cartesian product).
