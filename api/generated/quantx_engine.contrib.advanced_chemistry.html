quantx_engine.contrib.advanced_chemistry¶

Advanced quantum chemistry algorithms (M79).

Implements UCCSD, ADAPT-VQE, QAOA, and QITE as pure-Python/NumPy exact statevector solvers. All methods operate on the full 2ⁿ-dimensional Hilbert space (feasible for n ≤ 16) and build on the PauliHamiltonian representation from quantx_engine.contrib.chemistry.

Quick reference:

from quantx_engine.contrib.chemistry import MolecularVQE
from quantx_engine.contrib.advanced_chemistry import UCCSDSolver, QITESolver

problem = MolecularVQE.h2()
H_mat = build_hamiltonian_matrix(problem.hamiltonian)

# UCCSD
solver = UCCSDSolver(n_electrons=2, n_qubits=4)
result = solver.run(H_mat)
print(result.energy)

# QITE
qite = QITESolver(n_qubits=4)
res  = qite.run(H_mat, delta_tau=0.05, n_steps=80)
print(res.final_energy)

Physical validation¶

QITE imaginary-time evolution on H2 minimal basis converges to E_FCI = -1.8573 Hartree within 80 steps of delta_tau=0.05 (verified against exact diagonalisation).

quantx_engine.contrib.advanced_chemistry.hf_state(n_electrons, n_qubits)[source]¶

Return the Hartree-Fock reference state vector.

The HF state occupies the n_electrons lowest-indexed spin-orbitals. Qubit 0 is the most significant (leftmost) tensor factor, so the occupied qubits 0..n_electrons-1 give index 2ⁿ − 2^(n-n_e) = ... = integer with the top n_e bits set.

Parameters:

  • n_electrons (int) – Number of electrons (occupied spin-orbitals).

  • n_qubits (int) – Total number of spin-orbitals / qubits.

Return type:

numpy.ndarray of shape (2**n_qubits,), dtype complex128.

class quantx_engine.contrib.advanced_chemistry.UCCSDSolver(n_electrons, n_qubits)[source]¶

Bases: object

Unitary Coupled Cluster Singles and Doubles solver.

Builds the UCCSD ansatz by:

  1. Generating all single-excitation generators K_single = a†_v a_o − h.c. and double-excitation generators K_double = a†_v₁ a†_v₂ a_o₂ a_o₁ − h.c. in the Jordan-Wigner representation.

  2. Forming the combined anti-Hermitian operator A(θ) = Σ θ_s K_s + Σ θ_d K_d.

  3. Preparing the UCCSD state |ψ(θ)⟩ = expm(A(θ)) |HF⟩ via exact matrix exponentiation.

  4. Minimizing ⟨ψ(θ)|H|ψ(θ)⟩ over θ using coordinate descent.

Parameters:

  • n_electrons (int) – Number of electrons (occupied spin-orbitals in HF reference).

  • n_qubits (int) – Total number of spin-orbitals / qubits.

Examples

>>> from quantx_engine.contrib.chemistry import MolecularVQE
>>> from quantx_engine.contrib.advanced_chemistry import UCCSDSolver, build_hamiltonian_matrix
>>> problem = MolecularVQE.h2()
>>> H = build_hamiltonian_matrix(problem.hamiltonian)
>>> result = UCCSDSolver(n_electrons=2, n_qubits=4).run(H)
>>> abs(result.energy - problem.fci_energy) < 0.01

class quantx_engine.contrib.advanced_chemistry.ADAPTVQESolver(n_electrons, n_qubits, pool=None)[source]¶

Bases: object

Adaptive derivative-assembled pseudo-Trotter VQE (ADAPT-VQE).

At each iteration, finds the operator from the pool with the largest energy gradient and appends it to the ansatz with a new parameter. Stops when the maximum absolute gradient falls below threshold or max_operators is reached.

Parameters:

  • n_electrons (int) – Number of electrons in the HF reference.

  • n_qubits (int) – Total number of qubits.

  • pool (list[np.ndarray] | None) – List of anti-Hermitian generator matrices. If None, uses the UCCSD pool (all singles + doubles).

class quantx_engine.contrib.advanced_chemistry.QAOASolver(n_qubits)[source]¶

Bases: object

Quantum Approximate Optimization Algorithm.

Prepares the p-layer QAOA state:

|ψ(γ,β)⟩ = ∏_{l=1}^{p} exp(-iβ_l H_B) exp(-iγ_l H_C) |+⟩^⊗n

where H_B = Σ_i X_i is the mixer Hamiltonian and H_C is the cost Hamiltonian. Optimizes ⟨ψ(γ,β)|H_C|ψ(γ,β)⟩ over the 2p parameters.

Parameters:

n_qubits (int) – Number of qubits.

class quantx_engine.contrib.advanced_chemistry.QITESolver(n_qubits)[source]¶

Bases: object

Quantum Imaginary Time Evolution (QITE).

Evolves an initial state under:

|ψ(τ + Δτ)⟩ ∝ (I − ΔτH) |ψ(τ)⟩

which converges to the ground state of H as τ → ∞.

Parameters:

n_qubits (int) – Number of qubits.

Examples

>>> H = build_hamiltonian_matrix(MolecularVQE.h2().hamiltonian)
>>> result = QITESolver(n_qubits=4).run(H, delta_tau=0.05, n_steps=100)
>>> result.final_energy  # close to FCI energy -1.1373
