quantx_engine.qaoa_optim¶

M115: QAOA with CVaR objective — combinatorial optimisation.

Provides a complete QAOA pipeline for combinatorial optimisation problems:

  • CVaR-QAOA (CVaRQAOA) — replaces the standard ⟨H⟩ objective with the Conditional Value-at-Risk CVaR_α, which focuses training on the best-α fraction of measurement outcomes and significantly improves convergence.

  • MaxCut (MaxCutProblem) — builds the Ising cost Hamiltonian for graph max-cut and evaluates approximation ratios.

  • TSP (TSPProblem) — encodes the Traveling Salesman Problem as a QUBO/Ising Hamiltonian using the standard one-hot city-position encoding.

  • Parameter landscape (QAOALandscape) — scans a (γ, β) grid at depth p=1 and returns the full energy surface for visualisation and analysis.

  • Warm-start initialisation (warm_start_qaoa()) — returns informed initial parameter guesses via several strategies.

[2]

[3]

Wurtz, J. & Love, P. (2021). MaxCut quantum approximate optimization algorithm performance guarantees for p>1. Phys. Rev. A 103, 042612. https://doi.org/10.1103/PhysRevA.103.042612

Physical validation¶

QAOA p=1 on MaxCut for a 3-regular graph: approximation ratio >= 0.6924 [Farhi2014]. CVaR (alpha=0.25) improves the effective expected value by focusing on the best alpha-fraction of samples.

class quantx_engine.qaoa_optim.MaxCutProblem(n_nodes, edges)[source]¶

Bases: object

Graph Maximum Cut problem.

The cost function is C(x) = Σ_{(i,j)∈E} w_{ij} (1 − z_i z_j)/2 where z_i = 1 − 2x_i (z_i=+1 if qubit i is 0, z_i=−1 if qubit i is 1).

Parameters:

  • n_nodes (int) – Number of graph nodes (qubits).

  • edges (list[tuple[int, int]] | list[tuple[int, int, float]]) – Edge list. Each entry is (u, v) or (u, v, weight); default weight=1.

class quantx_engine.qaoa_optim.CVaRQAOA(cost_diagonal=None, n_qubits=None, n_layers=1, alpha=0.25, exact_optimum=None, *, problem=None, p=None, seed=None)[source]¶

Bases: object

QAOA with Conditional Value-at-Risk (CVaR) objective.

Replaces the standard expectation-value objective ⟨H_C⟩ with CVaR_α = E[C(x) | C(x) ≤ VaR_α], which focuses training on the best-α fraction of measurement outcomes.

Parameters:

  • cost_diagonal (np.ndarray, shape (2**n,)) – Pre-computed cost C(x) for every computational basis state.

  • n_qubits (int)

  • n_layers (int, default 1) – QAOA depth p.

  • alpha (float, default 0.25) – CVaR confidence level ∈ (0, 1]. alpha=1 recovers standard QAOA.

  • exact_optimum (float | None) – Known exact optimum for computing approximation ratio.

quantx_engine.qaoa_optim.warm_start_qaoa(n_layers, strategy='random', seed=None, prev_params=None)[source]¶

Return initial QAOA parameter guess using a given strategy.

Parameters:

  • n_layers (int) – QAOA depth p.

  • strategy ({"random", "fixed", "interpolated", "tqa"}) –

    Initialisation strategy:

    • "random" — uniform random in [0, π].

    • "fixed" — γ_k = 0.1k/p, β_k = π/4 (1 − k/p).

    • "interpolated" — linearly interpolate prev_params (depth p−1) to depth p. Requires prev_params.

    • "tqa" — Trotterised Quantum Annealing schedule.

  • seed (int | None) – Random seed (used only by "random").

  • prev_params (np.ndarray | None) – Previous depth’s parameters (needed for "interpolated").

Returns:

Concatenated [γ_1, …, γ_p, β_1, …, β_p].

Return type:

np.ndarray, shape (2*p,)
