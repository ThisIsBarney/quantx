quantx_engine.circuit¶

QuantumCircuit fluent builder API (M161).

A Qiskit/Cirq-style circuit construction layer built on top of StatevectorSimulator.

Example

>>> from quantx_engine import QuantumCircuit
>>> qc = QuantumCircuit(3)
>>> qc.h(0).cx(0, 1).cx(0, 2).measure_all()
>>> result = qc.run(n_shots=1024)
>>> print(result.counts)         # {'000': 510, '111': 514}
>>> print(result.statevector)    # np.ndarray shape (8,)

>>> from quantx_engine.circuit import Symbol
>>> theta = Symbol("theta")
>>> qc = QuantumCircuit(1)
>>> qc.rx(theta, 0)
>>> result = qc.run(params={"theta": 1.5707963})

Named symbolic parameter for parametric gates (e.g. in VQE).

Use a Symbol wherever a rotation angle is expected. Before calling QuantumCircuit.run() you must bind all symbols to numeric values via the params argument:

theta = Symbol("theta")
qc    = QuantumCircuit(1)
qc.rx(theta, 0)
result = qc.run(n_shots=0, params={"theta": math.pi / 2})

name (str) – Human-readable name used as the key in the params dict.

classmethod from_qasm3(qasm)[source]¶

Parse a basic OpenQASM 3.0 string and return a QuantumCircuit.

Supports: qubit declarations, standard gates (H/X/Y/Z/S/T/Sdg/Tdg/ Rx/Ry/Rz/P/U/CX/CY/CZ/CH/SWAP/iSWAP/CCX/CSWAP/id), measurements, and // comments. Symbolic angles (e.g. pi/2) are evaluated to floats.
