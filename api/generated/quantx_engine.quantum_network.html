quantx_engine.quantum_network¶

Quantum network simulation — M96.

Models quantum communication networks with:

  • QuantumNode — a network endpoint holding quantum memories.

  • QuantumChannel — a lossy, noisy optical channel between two nodes.

  • QuantumNetwork — a graph of nodes and channels.

  • BellPairGenerator — generates (possibly imperfect) Bell pairs.

  • EntanglementSwapper — performs BSM-based entanglement swapping.

  • QuantumRepeater — single-hop repeater with entanglement swapping.

  • NetworkResult — output container.

Physical model¶

Channels are characterised by:

  • Transmission η ∈ [0, 1] — probability that a photon arrives.

  • Dephasing rate p_deph ∈ [0, 1] — per-qubit dephasing probability of stored memories.

  • Gate fidelity F_gate ∈ [0, 1] — Bell-state-measurement (BSM) fidelity.

Bell pair quality is tracked as a fidelity F relative to the ideal singlet |Φ⁺⟩ = (|00⟩ + |11⟩)/√2. The fidelity of a Werner state ρ = F|Φ⁺⟩⟨Φ⁺| + (1−F)/4 · I₄ satisfies:

  • Generation: F_gen = η/2 + (1−η)/4 (photon loss → mixed state).

  • Dephasing: F_deph = F(1 − p) + (1−F)(p/3) [isotropic approx].

  • Swapping: F_swap(A,B) = F_A·F_B + (1−F_A)(1−F_B)/3.

  • Purification: F_pur(F) = F²/(F² + (1−F)²/3) [one round].

Classes¶

  • NetworkError — base exception.

  • QuantumNode — network node / quantum memory register.

  • QuantumChannel — noisy lossy channel link.

  • QuantumNetwork — network topology.

  • BellPairGenerator — Bell-pair source (inline or heralded).

  • EntanglementSwapper — BSM-based entanglement swapping.

  • QuantumRepeater — one repeater hop.

  • NetworkResult — simulation output.

Functions¶

  • fidelity_after_dephasing() — Werner-state dephasing formula.

  • fidelity_after_swapping() — entanglement swapping fidelity.

  • fidelity_after_purification() — one-round DEJMPS purification.

  • simulate_repeater_chain() — end-to-end fidelity for N-hop chain.

Physical validation¶

Werner state with fidelity F < 1/2 is separable (not entangled). DEJMPS purification starting from two Werner states with F=0.9: F_out = (F^2 + ((1-F)/3)^2) / (F^2 + (2F(1-F)/3) + 5((1-F)/3)^2) [Deutsch1996]. Verified numerically in test suite.

quantx_engine.quantum_network.fidelity_after_dephasing(F, p_deph)[source]¶

Werner fidelity after pair-level depolarising noise.

Models a two-qubit depolarising channel that with probability p_deph replaces the Bell pair with the maximally mixed state, and with probability (1 − p_deph) leaves it unchanged:

F' = (1 − p) F + p / 4

This is the exact Werner-state map for isotropic two-qubit noise with depolarising parameter p ∈ [0, 1]. Key properties:

  • p = 0 → identity (F’ = F).

  • p = 1 → fully depolarised (F’ = 1/4).

  • F = 1/4 is a fixed point for all p.

Parameters:

  • F (float ∈ [0, 1]) – Input Werner fidelity.

  • p_deph (float ∈ [0, 1]) – Two-qubit depolarising probability.

Return type:

float ∈ [0, 1]

quantx_engine.quantum_network.fidelity_after_swapping(F_A, F_B, F_gate=1.0)[source]¶

Fidelity after BSM-based entanglement swapping.

Given two Werner states with fidelities F_A and F_B and a BSM with fidelity F_gate, the output Werner-state fidelity is:

F_ideal = F_A · F_B + (1 − F_A)(1 − F_B) / 3
F_swap  = F_gate · F_ideal + (1 − F_gate) / 4

This is the exact formula derived from the Werner-state parameterisation p = (4F − 1)/3 and the multiplicative property p_out = p_A · p_B under a perfect BSM. Key properties:

  • F_A = 1 → F_swap = F_B (swapping a perfect pair preserves the other).

  • F_A = F_B = 1/4 → F_swap = 1/4 (maximally mixed is a fixed point).

Parameters:

  • F_A (float ∈ [0, 1]) – Fidelities of the two Bell pairs to be swapped.

  • F_B (float ∈ [0, 1]) – Fidelities of the two Bell pairs to be swapped.

  • F_gate (float ∈ [0, 1]) – BSM gate fidelity (1 = perfect BSM).

Return type:

float ∈ [0, 1]

Simulate an N-hop quantum repeater chain.

Builds an inline chain: Alice — [repeater] — … — [repeater] — Bob.

  • segment_length_km (float) – Length of each fibre segment.

  • dephasing_per_segment (float) – Depolarising probability per Bell pair per segment.
