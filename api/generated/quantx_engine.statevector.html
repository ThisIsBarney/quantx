quantx_engine.statevector¶

Pure-Python dense statevector simulator (M160).

A self-contained ~400-line NumPy statevector simulator that works with zero native dependencies. It is the fallback backend used by Engine when the native C++ library is absent, and can also be used directly for rapid prototyping and testing.

Supports up to 25 qubits (2^25 amplitudes ≈ 256 MB complex128).

Standard gate set¶

Single-qubit: H, X, Y, Z, S, T, Sdg, Tdg, Rx, Ry, Rz, P (phase), I Two-qubit: CNOT (CX), CY, CZ, SWAP, iSWAP, CH Three-qubit: CCX (Toffoli), CSWAP (Fredkin)

Usage¶

>>> from quantx_engine.statevector import StatevectorSimulator
>>> sim = StatevectorSimulator(2)
>>> sim.h(0).cnot(0, 1)
>>> sv = sim.statevector()          # np.ndarray[complex128], shape (4,)
>>> probs = sim.probabilities()     # np.ndarray[float64],   shape (4,)
>>> counts = sim.sample(1024)       # Counter[str]  e.g. {"00": 512, "11": 512}
>>> e = sim.expectation("ZZ")       # float

  • initial_state (int | np.ndarray | None) –

    • int (default 0): computational basis state |initial_state⟩.

    • np.ndarray of shape (2**n_qubits,): custom initial amplitudes (will be normalised).

    • None: same as 0 (|0…0⟩).
