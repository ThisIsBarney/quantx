quantx_engine.dmrg¶

M176 — DMRG ground-state solver for the QuantX engine.

Wraps the native C++ two-site DMRG implementation (src/dmrg_dense.cpp + src/dmrg_blocks.cpp + src/dmrg_mpo.cpp, exposed via src/dmrg_capi.cpp) with a clean Python API. Without the native library, ground_state() raises DMRGError, and DMRGSolver.solve() falls back to exact diagonalisation, for chains of up to 20 sites.

Supported Hamiltonians¶

  • The symmetric models of quantx_engine.models (XXZ, J1-J2, spin-1 Heisenberg, Fermi-Hubbard) through ground_state(), in a chosen symmetry sector, on the block-sparse engine. Spin couplings there use S = sigma/2:

    from quantx_engine.models import HubbardChain
from quantx_engine.dmrg import ground_state
gs = ground_state(HubbardChain(L=16, U=4.0), n_up=8, n_dn=8, max_bond=512)

  • Through DMRGSolver: the Heisenberg XXZ chain in the Pauli convention (J sigma.sigma), {"type": "heisenberg", "J": 1.0}, and general sums of Pauli strings, passed as hamiltonian_terms=[(coeff, "X0X1"), ...].

Maximum system size: 200 sites (C++ backend limit).

Quick-start example:

from quantx_engine import Engine
from quantx_engine.dmrg import DMRGSolver

solver = DMRGSolver(Engine())

# Heisenberg chain n=50, bond dim 100
result = solver.solve(
    n_qubits=50,
    hamiltonian_type="heisenberg",
    J=1.0,
    max_bond=100,
    n_sweeps=10,
)
print(f"Ground state energy: {result.energy:.8f}")
print(f"Converged in {result.n_sweeps_done} sweeps")

# General Hamiltonian via Pauli strings
result = solver.solve(
    n_qubits=10,
    hamiltonian_terms=[(1.0, "X0X1"), (1.0, "Y0Y1"), (1.0, "Z0Z1")],
    max_bond=32,
)

solve(n_qubits, *, hamiltonian_type='pauli_sum', J=1.0, delta=1.0, hamiltonian_terms=None, max_bond=64, cutoff=1e-10, n_sweeps=10, tol=1e-10, method='u1', seed=7, phys_spin=0.5)[source]¶

Run DMRG to find the ground-state energy.

Parameters:

  • n_qubits (int) – Number of spin-1/2 sites.

  • hamiltonian_type (str) – "heisenberg" for XXX Heisenberg chain, or "pauli_sum" for a general sum of Pauli strings (requires hamiltonian_terms).

  • J (float) – Heisenberg coupling constant (used when hamiltonian_type="heisenberg").

  • hamiltonian_terms (list of (float, str), optional) – List of (coefficient, pauli_label) pairs. Pauli labels may be in indexed format ("X0X1") or plain format ("XXI...").

  • max_bond (int) – For method="u1" (default): maximum MPS bond dimension χ (number of Sz states kept). For method="su2": the maximum number of spin multiplets kept — each multiplet of spin S stands for 2S+1 states, so a given accuracy is reached with far fewer multiplets.

  • cutoff (float) – SVD singular-value weight cutoff; states with discarded weight below cutoff² are dropped even if max_bond is not reached.

  • n_sweeps (int) – Maximum number of full left→right→left DMRG sweeps.

  • tol (float) – Energy convergence tolerance. Stops early when |ΔE| < tol.

  • method (str) – "u1" (default): Sz-conserving block-sparse two-site DMRG. "su2": SU(2) spin-symmetric DMRG (Heisenberg only); tracks spin multiplets, reaching a given accuracy with fewer kept states.

  • seed (int) – Random seed for the initial MPS (used by method="su2").

  • phys_spin (float) – Physical site spin for method="su2": 0.5 (spin-1/2 Heisenberg, sigma.sigma convention) or 1.0 (spin-1 Haldane chain, S.S convention), etc. Only the SU(2) path supports spin > 1/2.

Return type:

DMRGResult

Raises:

DMRGError – On invalid parameters or solver failure.

quantx_engine.dmrg.ground_state(model, *, sz=None, n_up=None, n_dn=None, max_bond=256, cutoff=1e-10, n_sweeps=20, tol=1e-10, engine=None)[source]¶

Ground state of a quantx_engine.models chain in one symmetry sector.

Runs two-site DMRG on the native block-sparse engine, which conserves the model’s U(1) charges exactly, so the result lies in the requested sector.

Parameters:

  • model (XXZChain, J1J2Chain, Spin1Chain, HubbardChain or HubbardLattice) – The Hamiltonian; see quantx_engine.models for the conventions.

  • sz (float, optional) – Spin models: total S^z (a multiple of 1/2). Default: the lowest |S^z| the chain allows (0, or 1/2 for an odd spin-1/2 chain).

  • n_up (int, optional) – Hubbard models: the numbers of up and down electrons. Default: half filling, n_up = ceil(L/2) and n_dn = floor(L/2).

  • n_dn (int, optional) – Hubbard models: the numbers of up and down electrons. Default: half filling, n_up = ceil(L/2) and n_dn = floor(L/2).

  • max_bond (int) – Maximum MPS bond dimension (states kept per bond, summed over sectors).

  • cutoff (float) – SVD truncation weight cutoff.

  • n_sweeps (int) – Maximum number of sweeps; stops early once the energy changes by less than tol.

  • tol (float) – Energy convergence tolerance.

  • engine (quantx_engine.Engine, optional) – Engine to run on; by default one is created (and reused) on first use.

Returns:

energy in the model’s convention, with sector set.

Return type:

DMRGResult

Raises:

  • ModelError – The sector is not valid for the model.

  • DMRGError – No native library, a sector argument the model does not take, or a solver failure.
