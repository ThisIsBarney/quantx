quantx_engine.contrib.qsp_qsvt¶

M123: Quantum signal processing (QSP) and quantum singular value transformation (QSVT).

Quantum Signal Processing¶

For a scalar signal x ∈ [-1, 1] and a degree-d polynomial P(x) satisfying |P(x)| ≤ 1, the QSP circuit realises the transformation

U_QSP(x, Φ) = e^{iφ₀Z} ∏ₖ [ Wx · e^{iφₖZ} ]

where Wx = [ x, i√(1-x²) ]

[ i√(1-x²), x ]

is the signal unitary and Φ = (φ₀, …, φ_d) are the phase angles.

Quantum Singular Value Transformation¶

QSVT extends QSP to matrices: given a block-encoding U_A of an operator A, QSVT realises polynomial transformations P(A/‖A‖) via a sequence of controlled-phase rotations interleaved with queries to U_A and U_A†.

Physical validation¶

Chebyshev polynomial approximation of sign function: maximum deviation from sign(x) bounded by 2*exp(-2*(k-1)^2/(2k-1)) for degree-k approximation. QSP phases reproduce polynomial values to within 1e-6 for degree <= 8 (verified against scipy.special.chebyt in test suite).

class quantx_engine.contrib.qsp_qsvt.QSPAnglesFinder(degree, n_grid=200, *, target=None)[source]¶

Compute QSP phase angles for standard polynomial targets.

QSP realises the top-left element of the QSP unitary

[U_QSP]₀₀ = P(x)

where P is a polynomial of degree d with |P(x)| ≤ 1 for x ∈ [-1, 1] and the parity of d matches the parity of the number of signal queries.

This class provides analytic angle sequences for common targets (where closed-form formulas are known) and a gradient-descent solver for arbitrary polynomials.

Parameters:

  • degree (int) – Target polynomial degree.

  • n_grid (int) – Number of grid points used for error estimation.

run()[source]¶

Compute phase angles for the configured target polynomial.

Dispatches based on the target kwarg passed to __init__: - "chebyshev" → chebyshev() with k = degree - "sign" → sign_function() - "threshold" → threshold() - None → chebyshev() (default)

chebyshev(k)[source]¶

Return phase angles that realise the Chebyshev polynomial T_k(x).

T_k(cos θ) = cos(kθ), so P(x) = Re[e^{ik·arccos x}].

The QSP angles are φⱼ = 0 for j = 1, …, d-1 and φ₀ = φ_d = π/4, scaled to match the Chebyshev target (analytic construction for even d).

Parameters:

k (int) – Chebyshev order (must equal self.degree).

sign_function(delta=0.1, scale=0.9)[source]¶

Return phase angles approximating sign(x) with error δ outside [-δ, δ].

Uses a degree-d odd polynomial approximation of the step function. The phases are found via a minimax gradient-descent fit.

Parameters:

  • delta (float) – Half-width of the transition region.

  • scale (float) – Target value: P(x) ≈ ±scale for |x| > delta.

hamiltonian_simulation(t, order=None)[source]¶

Phase angles for Hamiltonian simulation e^{-iHt} to a given order.

Realises the polynomial P(x) = Σ_{k=0}^{d/2} (-it)^k x^k / k! (truncated Taylor series of e^{-ixt}, rescaled for x ∈ [-1, 1]).

Parameters:

  • t (float) – Evolution time.

  • order (int or None) – Truncation order; defaults to self.degree.

threshold(threshold_x=0.0)[source]¶

Phase angles for a step function at threshold_x.

Approximates P(x) ≈ 0 for x < threshold_x and ≈ 1 for x > threshold_x. (Odd-degree polynomial approximation.)

class quantx_engine.contrib.qsp_qsvt.QSVTCircuit(phases, block_encoding, n_signal, alpha=1.0)[source]¶

Bases: object

Build and simulate a QSVT circuit given phase angles and a block-encoding.

QSVT applies a polynomial transformation P(σᵢ) to the singular values σᵢ of an operator A, where A is embedded as the top-left block of a unitary block-encoding U_A:

⟨G|U_A|G⟩ = A / α (‖A‖ ≤ α)

The QSVT circuit interleaves queries to U_A (and U_A†) with single-qubit Z-rotation projectors controlled on the block flag qubit:

U_QSVT = Π̃_{φ₀} ∏_{k=1}^{d} [ U_A · Π_{φₖ} ] (even d)

where Π_φ = e^{iφ|0⟩⟨0|} ⊗ I_A is a reflection through the signal subspace.

Parameters:

  • phases (array-like, shape (d+1,)) – QSP phase angles Φ.

  • block_encoding (array-like or callable) – Either a 2m × 2m unitary U_A (dense matrix) or a callable U_A(state) → state for larger spaces.

  • n_signal (int) – Dimension of the signal (block) subspace (= n_qubits of A).

  • alpha (float) – Block-encoding normalisation factor (‖A‖ ≤ alpha).
