quantx_engine.contrib.qiskit_compat module¶

M116: Qiskit 1.x Primitives V2 compatibility layer.

Implements QuantXSamplerV2 and QuantXEstimatorV2 following the Qiskit 1.x Primitives V2 specification so that existing Qiskit 1.x workflows can run against the QuantX statevector backend with minimal changes.

Key design¶

  • PUB format (Primitive Unified Bloc): (circuit, [observables,] [parameter_values,] [shots/precision]) where omitted fields use sensible defaults.

  • Results are returned as PrimitiveResult containing one PubResult per input PUB. Each PubResult.data is a DataBin whose fields mirror the Qiskit V2 specification: meas (BitArray) for the sampler, evs / stds (np.ndarray) for the estimator.

  • QuantX circuits (objects with .n_qubits and .gates) or plain statevectors are accepted. Parameterised circuits can be supplied as callables f(params) -> circuit.
