quantx_engine.optimal_control¶

Quantum Optimal Control — M84.

Implements two pulse-shaping algorithms:

  • GRAPESolver — Gradient Ascent Pulse Engineering (Khaneja et al. 2005). Computes analytical gradients of the gate fidelity with respect to piecewise- constant control amplitudes and performs gradient ascent.

  • CRABSolver — Chopped Random Basis (Doria et al. 2011). Parameterises each control as a sum of random Fourier harmonics and optimises the scalar coefficients with Nelder-Mead (gradient-free).

Both solvers work with pure-NumPy exact density-matrix / propagator arithmetic. Matrix exponentials are computed via eigendecomposition of the (Hermitian) total Hamiltonian at each time step, giving exact propagators for any step size.

Quick reference:

import numpy as np
from quantx_engine.optimal_control import GRAPESolver

# Drive a single qubit from |0⟩ to |1⟩ using an X-rotation
X = np.array([[0,1],[1,0]], dtype=complex)
Z = np.array([[1,0],[0,-1]], dtype=complex)
solver = GRAPESolver(
    H_drift=0.5 * Z,       # free precession along Z
    H_controls=[X],        # one control field along X
    U_target=np.array([[0,1],[1,0]], dtype=complex),  # X gate
    n_steps=20,
    total_time=math.pi,
)
result = solver.run(n_iterations=200, learning_rate=0.5)
print(f"Fidelity: {result.fidelity_history[-1]:.6f}")   # → ≈ 1.0

Physical validation¶

GRAPE gradient for a single-qubit pi rotation: analytic gradient of F = |<target|U>|^2 with respect to pulse amplitudes. The gradient has magnitude ~ |target - U| * |dU/dparam|. For a Gaussian ansatz, dF/da_k = 2*Re(<target|dU/da_k>) [Khaneja2005].

class quantx_engine.optimal_control.GRAPESolver(H_drift, H_controls, U_target, n_steps=20, total_time=3.141592653589793, seed=None)[source]¶

Bases: object

GRAPE — Gradient Ascent Pulse Engineering.

Maximises the gate fidelity:

Φ = |Tr(U†_target U_prop)|² / d²

with respect to piecewise-constant control amplitudes u[j, k] (j = control index, k = time step index).

The gradient is computed analytically:

∂Φ/∂u_j[k] = (2 dt / d²) Im(IP* · Tr(A[k+1] H_j F[k+1]))

where F[k+1] = U_k … U_0 (forward propagator through step k), A[k+1] = U†_target · U_{n-1} … U_{k+1} (backward propagator using forward unitaries, NOT their adjoints), and IP = Tr(U†_target U_prop).

Parameters:

  • H_drift (np.ndarray) – Time-independent drift Hamiltonian, shape (d, d), Hermitian.

  • H_controls (list[np.ndarray]) – List of control Hamiltonians H_j, each shape (d, d), Hermitian.

  • U_target (np.ndarray) – Target unitary, shape (d, d).

  • n_steps (int) – Number of piecewise-constant time steps.

  • total_time (float) – Total evolution time (same units as Hamiltonian).

  • seed (int | None) – Optional seed for initial random controls.

class quantx_engine.optimal_control.CRABSolver(H_drift, H_controls, U_target, n_steps=20, total_time=3.141592653589793, n_harmonics=4, seed=None)[source]¶

Bases: object

CRAB — Chopped Random Basis optimal control.

Represents each control field as a sum of n_harmonics random-frequency Fourier components:

u_j(t) = ∑_k (a_k cos(ω_k t) + b_k sin(ω_k t))

where {ω_k} are drawn randomly near integer multiples of 2π/T. The scalar coefficients {a_k, b_k} are optimised by Nelder-Mead.

Parameters:

  • H_drift (np.ndarray) – Same as GRAPESolver.

  • H_controls (list[np.ndarray]) – Same as GRAPESolver.

  • U_target (np.ndarray) – Same as GRAPESolver.

  • n_steps (int) – Same as GRAPESolver.

  • total_time (float) – Same as GRAPESolver.

  • seed (int | None) – Same as GRAPESolver.

  • n_harmonics (int) – Number of Fourier harmonics per control field.
