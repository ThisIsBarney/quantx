quantx_engine.contrib.ftqc_pipeline¶

M112: Fault-tolerant QC end-to-end pipeline.

Ties SurfaceCode and MWPMDecoder into a single FTQCPipeline object that simulates the complete error-correction cycle:

encode → (logical gate →)* n_rounds × syndrome extraction → MWPM decode → check

Two noise models are supported:

  • Code-capacity (n_rounds=1, p_meas=0): ideal stabilizer measurements; only data qubit errors are injected.

  • Phenomenological (n_rounds > 1, p_meas > 0): every syndrome measurement may flip independently with probability p_meas; data errors accumulate across rounds and the final ideal syndrome is decoded.

The threshold_curve() function sweeps p_phys over a range for multiple code distances and estimates the threshold crossing point — the physical error rate below which increasing d strictly improves the logical error rate.

Example:

from quantx_engine.contrib.ftqc_pipeline import FTQCPipeline, threshold_curve

# Single-pipeline run
pipe = FTQCPipeline(code_distance=5, p_physical=0.01)
result = pipe.run(n_shots=2000, seed=0)
print(result.logical_error_rate)   # should be ≪ 0.01 below threshold

# Threshold curve
curve = threshold_curve(distances=[3, 5, 7], n_shots=500, seed=42)
print(f"threshold ≈ {curve.threshold:.4f}")

class quantx_engine.contrib.ftqc_pipeline.FTQCPipeline(code_distance, p_physical, p_meas=0.0, decoder='mwpm')[source]¶

Bases: object

End-to-end fault-tolerant QC pipeline for a single logical qubit.

Simulates the full error-correction cycle:

  1. Encode logical |0⟩ (or |1⟩) using a distance-d surface code.

  2. Inject independent depolarizing noise on each data qubit per round.

  3. Extract stabilizer syndromes (optionally with measurement errors).

  4. Decode with MWPM (or greedy) to get a Pauli correction.

  5. Determine whether a logical error occurred.

Parameters:

  • code_distance (int) – Surface code distance d (must be ≥ 3, odd recommended).

  • p_physical (float) – Physical error rate per qubit per error-correction round (0 < p < 0.5).

  • p_meas (float, default 0.0) – Syndrome measurement error probability per stabilizer per round. Set to 0 for the ideal code-capacity noise model.

  • decoder ({"mwpm", "greedy"}, default "mwpm") – Syndrome decoder. "mwpm" uses minimum-weight perfect matching; "greedy" uses the built-in greedy matching in SurfaceCode.

quantx_engine.contrib.ftqc_pipeline.threshold_curve(distances=None, p_phys_range=(0.005, 0.2), n_points=15, n_shots=500, n_rounds=1, decoder='mwpm', seed=None)[source]¶

Sweep p_phys for multiple distances and estimate the threshold.

For each (d, p_phys) pair, a FTQCPipeline is constructed and n_shots trials are run. The threshold is estimated as the average of pairwise crossing points between adjacent distance curves (see threshold_crossing()).

Parameters:

  • distances (list[int] | None) – Code distances to sweep. Defaults to [3, 5, 7].

  • p_phys_range ((float, float)) – (p_min, p_max) interval for the sweep.

  • n_points (int) – Number of evenly-spaced points in p_phys_range.

  • n_shots (int) – Monte Carlo shots per (d, p_phys) point.

  • n_rounds (int) – Syndrome extraction rounds per trial.

  • decoder ({"mwpm", "greedy"})

  • seed (int | None)

Return type:

ThresholdCurveResult

quantx_engine.contrib.ftqc_pipeline.threshold_crossing(result)[source]¶

Re-estimate the threshold crossing from a ThresholdCurveResult.

Uses pairwise linear interpolation between consecutive distance curves to find the p_phys value where larger distance transitions from worse (above threshold) to better (below threshold).

Returns None if no crossing is detectable.

class quantx_engine.contrib.ftqc_pipeline.FTQCResourceEstimator(target_logical_error_rate, physical_error_rate, threshold=0.01, prefactor=0.1, max_distance=51)[source]¶

Bases: object

Estimate physical qubit and magic-state resources for fault-tolerant QC.

Uses the surface code threshold model from Fowler et al. (2012). The logical error rate per round scales as

p_L ≈ A × (p_phys / p_th)^{⌊(d+1)/2⌋}

where A ≈ 0.1, p_th ≈ 0.01 (1% threshold for the depolarizing model).

References

[Fowler2012]

Fowler, A. G. et al. (2012). Surface codes: Towards practical large-scale quantum computation. Phys. Rev. A 86, 032324. https://doi.org/10.1103/PhysRevA.86.032324

Parameters:

  • target_logical_error_rate (float) – Desired logical error rate per logical gate.

  • physical_error_rate (float) – Physical qubit error rate (must be < threshold ≈ 0.01).

  • threshold (float, default 0.01) – Surface code threshold (default: 1%).

  • prefactor (float, default 0.1) – Pre-exponential constant A in p_L = A * (p/p_th)^t.

  • max_distance (int, default 51) – Maximum code distance to search.

Examples

>>> est = FTQCResourceEstimator(target_logical_error_rate=1e-10,
...                             physical_error_rate=1e-3)
>>> result = est.estimate()
>>> print(result)
