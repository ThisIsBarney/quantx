quantx_engine.many_body¶

Many-body physics enhancements for the QuantX engine (M102).

Three additions:

Out-of-time-order correlators (OTOCs)

Measure quantum information scrambling via the squared commutator:

C(t) = -⟨[W(t), V]²⟩  =  1 - Re F(t)
F(t) = ⟨W†(t) V† W(t) V⟩

where W(t) = exp(iHt) W exp(-iHt) is the Heisenberg-picture operator. Fast scrambling (chaotic systems like SYK) drives C(t) → 1 on the scrambling time scale t* ~ β ln N.

Sachdev-Ye-Kitaev (SYK) model

Random all-to-all q-body Majorana fermion Hamiltonian:

H_SYK = (i^{q/2} / q!) Σ_{1≤i₁<…<i_q≤N} J_{i₁…i_q} χ_{i₁}…χ_{i_q}

The Majorana operators χ_i satisfy {χ_i, χ_j} = 2δ_{ij} and are mapped to qubits via a Jordan-Wigner-like transformation. The q=4 model is the minimal holographic (AdS/CFT dual) case.

2D DMRG via snake-path mapping

Maps a 2D Lx×Ly lattice to a 1D MPS via a snake (boustrophedon) path, then runs the existing DMRG sweep engine. Long-range 2D couplings become medium-range 1D interactions that DMRG can still handle efficiently with modest bond dimensions.

Quick start:

from quantx_engine.many_body import compute_otoc, SYKModel, dmrg_2d

# OTOC for a 4-qubit Ising chain
from quantx_engine.trotter import ising_trotter
sim = ising_trotter(n=4, J=1.0, h=0.5)
result = compute_otoc(sim.hamiltonian, op_w="X", op_v="Z",
                      site_w=0, site_v=3, t=1.0, n_qubits=4)
print(result.otoc_value)   # C(t) ∈ [0, 1]

# SYK model
model = SYKModel(N=8, q=4, seed=42)
print(model.ground_state_energy)

# 2D DMRG
result = dmrg_2d(Lx=2, Ly=2, J=1.0, bond_dim=8, sweeps=4)
print(result.energy)

Physical validation¶

SYK model ground state energy is negative for any random couplings J_ijkl (the random model has E_0 < 0 with probability 1) [Sachdev1993]. OTOC C(t) = -<[W(t),V]^2> grows from 0 and saturates at late times for chaotic systems (information scrambling).

quantx_engine.many_body.compute_otoc(hamiltonian, op_w, op_v, site_w, site_v, t, n_qubits, initial_state=None, n_steps=100, use_trotter=False)[source]¶

Compute the OTOC F(t) = ⟨ψ|W†(t) V† W(t) V|ψ⟩.

The scrambling diagnostic is C(t) = 1 − Re F(t).

For a thermalising system C(t) grows from 0 to ~1 on the scrambling time scale; for an integrable system it stays near 0.

Parameters:

  • hamiltonian (np.ndarray) – (2^n × 2^n) Hermitian Hamiltonian matrix.

  • op_w (str) – Single-site Pauli operators ('X', 'Y', 'Z', or 'I').

  • op_v (str) – Single-site Pauli operators ('X', 'Y', 'Z', or 'I').

  • site_w (int) – Qubit indices for W and V respectively.

  • site_v (int) – Qubit indices for W and V respectively.

  • t (float) – Time of evolution.

  • n_qubits (int) – System size (used to build operator matrices).

  • initial_state (np.ndarray or None) – State |ψ⟩ in which expectation value is taken. Defaults to |0…0⟩.

  • n_steps (int) – Trotter steps (only used when use_trotter=True).

  • use_trotter (bool) – If True, approximate exp(-iHt) via second-order Trotter; otherwise use scipy.linalg.expm (exact, requires scipy).

class quantx_engine.many_body.SYKModel(N=None, q=4, seed=None, *, n_sites=None)[source]¶

Bases: object

Sachdev-Ye-Kitaev random q-body Majorana fermion Hamiltonian.

The q=4 SYK model is the minimal model conjectured to have a holographic (AdS₂) dual at low temperatures; it exhibits maximal quantum chaos.

The Hamiltonian is:

H = (i^{q/2} / q!) Σ_{i₁<…<i_q} J_{i₁…i_q} γ_{i₁}…γ_{i_q}

where γ_i are Majorana fermion operators satisfying {γ_i, γ_j} = 2δ_{ij}, mapped to qubits via the Jordan-Wigner transformation.

Parameters:

  • N (int) – Number of Majorana modes (must be even). The qubit system has N//2 qubits; the Hilbert space has dimension 2^{N//2}.

  • q (int) – Body count (must be even, typically 4).

  • seed (int or None) – Random seed for reproducibility.

quantx_engine.many_body.dmrg_2d(Lx, Ly, J=1.0, bond_dim=16, sweeps=4, model='heisenberg')[source]¶

Ground-state DMRG for the 2D Heisenberg (or Ising) model on an Lx×Ly lattice.

Uses a snake-path MPS mapping to convert the 2D problem to 1D, then runs two-site DMRG sweeps. The 1D chain has Lx*Ly sites with both short-range (adjacent on snake path) and medium-range (cross-row) bonds.

Parameters:

  • Lx (int) – Lattice dimensions. Total sites = Lx * Ly.

  • Ly (int) – Lattice dimensions. Total sites = Lx * Ly.

  • J (float) – Exchange coupling (positive = antiferromagnetic).

  • bond_dim (int) – Maximum MPS bond dimension (controls accuracy).

  • sweeps (int) – Number of DMRG sweeps (left-to-right + right-to-left = one sweep).

  • model ({'heisenberg', 'ising'}) – ‘heisenberg’: H = J Σ (XX + YY + ZZ) ‘ising’: H = -J Σ ZZ

Return type:

DMRG2DResult
