quantx_engine.contrib.ray_sim¶

M111: Distributed statevector simulation via Ray.

Implements a sharded statevector simulator that distributes the 2^n amplitude array across multiple Ray actors (one per shard), enabling simulation of large circuits across a multi-core machine or cluster. Falls back transparently to single-process numpy when Ray is unavailable.

Sharding strategy¶

The 2^n statevector is partitioned into num_shards contiguous blocks, each of size shard_size = 2^n // num_shards. Shard k owns amplitudes with indices in the range [k * shard_size, (k+1) * shard_size).

Gate classification¶

For an n-qubit statevector split into 2^s shards (s = log2(num_shards)):

  • Local gates (qubit index < n − s): both paired amplitudes lie within the same shard → each actor applies the gate independently in parallel.

  • Global gates (qubit index >= n − s): paired amplitudes live in different shards → the two affected shard actors exchange data, apply the gate jointly, and write back. In the CPU-fallback path the same exchange is performed in-process using numpy.

Quick start:

from quantx_engine.contrib.ray_sim import DistributedSVSimulator

sim = DistributedSVSimulator(n_qubits=20, num_shards=4)
sim.h(0)
for q in range(19):
    sim.cx(q, q + 1)
sv = sim.to_statevector()        # numpy array of shape (2**20,)
print(abs(sv[0])**2, abs(sv[-1])**2)  # ≈ 0.5 each (GHZ)

Benchmark single-process vs distributed statevector simulation.

Runs a random brickwork circuit (alternating Ry + CZ layers) and measures wall-clock time for both the CPU reference and the sharded DistributedSVSimulator.

Parameters:

  • n_qubits (int, default 20)

  • circuit_depth (int, default 4)

  • num_shards (int, default 4)

  • seed (int, default 0)

  • warmup (bool, default True) – Run a tiny warm-up circuit before timing to avoid cold-start bias.

DistSVResult
