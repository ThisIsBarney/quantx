quantx_engine.quantum_channel module¶

Quantum channels and steady-state solver (M75).

Two main components:

QuantumChannel — a completely-positive trace-preserving (CPTP) map in the Kraus representation {K_i} with ρ’ = Σ_i K_i ρ K_i†.

Multiple representations are available:

  • choi_matrix() — Choi-Jamiołkowski matrix J = Σ_n |ψ_n⟩⟨ψ_n| where |ψ_n⟩ = vec_F(K_n) (column-major vectorisation). Size d²×d².

  • superoperator() — Liouville superoperator L where vec_C(ρ’) = L vec_C(ρ) (row-major vectorisation). L = Σ_n K_n ⊗ K_n*. Size d²×d².

  • apply() — direct application Σ_n K_n ρ K_n†.

Factory methods cover common channels: identity(), depolarizing(), amplitude_damping(), dephasing(), bit_flip(), phase_flip(), reset().

Channels can be composed (compose()) and tensored (tensor()).

SteadyStateSolver — finds the unique fixed point ρ_ss satisfying Φ(ρ_ss) = ρ_ss by computing the eigenvector of the superoperator with eigenvalue 1 (always exists for CPTP maps).

Quick start:

import numpy as np
from quantx_engine.quantum_channel import QuantumChannel, SteadyStateSolver

# Amplitude damping channel
ch = QuantumChannel.amplitude_damping(gamma=0.3)
rho0 = np.array([[0.5, 0.5], [0.5, 0.5]], dtype=complex)  # |+⟩⟨+|
rho1 = ch.apply(rho0)

# Steady state: should be |0⟩⟨0|
solver = SteadyStateSolver()
rho_ss = solver.solve(ch)
print(np.abs(rho_ss - np.array([[1,0],[0,0]])).max())  # ≈ 0

Physical validation¶

Choi-Kraus representation: a channel is completely positive iff its Choi matrix is positive semi-definite [Choi1975]. The Choi matrix of the identity channel I_n is the maximally entangled state |omega><omega| * d, where d = 2^n and |omega> = (1/sqrt(d)) * sum_i |ii>. Steady-state solver: Liouvillian L rho_ss = 0 (zero eigenvalue of L).

A completely-positive trace-preserving (CPTP) quantum channel.

Represented by a list of Kraus operators {K_i} satisfying Σ_i K_i† K_i = I. The channel acts on density matrices as ρ → Σ_i K_i ρ K_i†.

Parameters:

kraus_ops (list[np.ndarray]) – List of (d×d) complex Kraus operators. At least one required. The CPTP condition Σ K_i† K_i = I is verified by is_trace_preserving().

Raises:

ChannelError – If kraus_ops is empty, contains non-square or inconsistent shapes, or numpy is not available.

classmethod depolarizing(d=None, p=0.0, *, n_qubits=None)[source]¶

Depolarizing channel Φ(ρ) = (1−p)ρ + p·I/d.

Uses the Weyl-operator Kraus decomposition:

K_{(0,0)} = √(1 − p + p/d²) · I, K_{(m,n)} = √(p/d²) · W_{mn} for (m,n) ≠ (0,0).

Valid for p ∈ [0, 1]. At p = 1, every state maps to I/d.

Parameters:

  • d (int | None) – Hilbert-space dimension (d ≥ 2).

  • p (float) – Depolarizing probability ∈ [0, 1].

classmethod amplitude_damping(gamma)[source]¶

Qubit amplitude-damping channel with decay probability γ.

Kraus operators:

K₀ = [[1, 0], [0, √(1−γ)]],  K₁ = [[0, √γ], [0, 0]].

The steady state is |0⟩⟨0| (ground state).

Parameters:

gamma (float) – Decay probability ∈ [0, 1]. At γ = 1, ρ → |0⟩⟨0| completely.

classmethod dephasing(p, d=2)[source]¶

Dephasing (phase-damping) channel.

Diagonal elements are unchanged; off-diagonal elements are multiplied by (1−p).

For d = 2 uses K₀ = √(1−p/2) I, K₁ = √(p/2) Z (standard form that preserves |0⟩⟨0| and |1⟩⟨1|).

For d > 2 uses K₀ = √(1−p) I, Kᵢ = √p |i⟩⟨i| (i = 0…d−1).

Parameters:

  • p (float) – Dephasing probability ∈ [0, 1].

  • d (int) – Hilbert-space dimension (default 2).

superoperator()[source]¶

Liouville superoperator L (d²×d²) in row-major vectorisation.

Satisfies rho'.ravel() == L @ rho.ravel() where ravel uses the default NumPy C (row-major) order.

Computed as L = Σ_n K_n ⊗ K_n*.

choi_matrix()[source]¶

Choi-Jamiołkowski matrix J (d²×d²).

Computed as J = Σ_n |ψ_n⟩⟨ψ_n| where |ψ_n⟩ = K_n.ravel(order=’F’) (column-major vectorisation of K_n).

Properties of J for a CPTP channel:

  • J is positive semi-definite (completely positive).

  • Tr(J) = d (trace-preserving).

  • The partial trace Tr_B(J) = I_A/d (for a unital channel).

class quantx_engine.quantum_channel.SteadyStateSolver(tol=1e-08, *, H=None, jump_operators=None)[source]¶

Bases: object

Find a fixed point ρ_ss of a quantum channel: Φ(ρ_ss) = ρ_ss.

Algorithm:

  1. Build the Liouville superoperator L = Σ K_n ⊗ K_n*.

  2. Find eigenvalues/vectors of L.

  3. Among eigenvectors with eigenvalue closest to 1, select the one whose reshaped matrix is most positive (smallest negative eigenvalue mass).

  4. Project to Hermitian, project to PSD, normalise trace to 1.

For CPTP maps the eigenvalue 1 is always present; the corresponding eigenvector(s) span the set of fixed points.

Note

For channels with a degenerate fixed-point subspace (e.g. the identity channel, or p = 0 dephasing) the solver returns one valid fixed-point density matrix. The result is determined by the eigenvector ordering from numpy.linalg.eig() and is not guaranteed to be a specific state. If you need all fixed points, compute the nullspace of (L − I) manually.

Parameters:

tol (float) – Threshold for identifying eigenvalues as “equal to 1”.
