quantx_engine.mitigation¶

Quantum error mitigation for the QuantX engine.

Provides two complementary mitigation techniques:

Zero-Noise Extrapolation (ZNE) — run circuits at artificially amplified noise levels (via gate folding) then extrapolate the results back to zero noise using Richardson, polynomial, or exponential fitting.

Probabilistic Error Cancellation (PEC) — decompose ideal gates as a quasi-probability distribution over noisy implementations; sample circuits with associated ±weights and take a weighted mean to obtain an unbiased estimator of the noiseless expectation value.

Both techniques operate through a user-supplied executor callable:

executor(ops: list[dict]) -> float

where each op dict has the shape {"name": str, "qubits": list[int], "params": list[float]}. A convenience factory make_sv_executor() builds one from GpuStatevector.

Quick-start example:

from quantx_engine.mitigation import (
    zne_mitigate, pec_mitigate, make_sv_executor,
    RichardsonExtrapolator,
)

# Build a statevector executor: run bell-state circuit, measure <Z0>
executor = make_sv_executor(n_qubits=2, observable_fn=lambda sv: sv.expectation_z(0))

bell_ops = [
    {"name": "H",    "qubits": [0], "params": []},
    {"name": "CNOT", "qubits": [0, 1], "params": []},
]

# ZNE with Richardson extrapolation at scale factors 1, 3, 5
result = zne_mitigate(bell_ops, executor, scale_factors=[1, 3, 5])
print(result.mitigated_value)

# PEC with 2% depolarizing noise per gate, 500 samples
result = pec_mitigate(bell_ops, noisy_executor, noise_prob=0.02, n_samples=500)
print(result.mitigated_value, "±", result.std_error)

Physical validation¶

ZNE with Richardson extrapolation: for polynomial noise N(lambda) = N_0*(1+c*lambda), the zero-noise estimate is exact at degree 1 [Temme2017, Eq. 3]. For a depolarising noise model, the unbiased estimator has zero variance at the noise-extrapolation point (verified analytically).

quantx_engine.mitigation.fold_gates(ops, scale_factor)[source]¶

Amplify circuit noise by gate-level folding.

Each gate G is replaced by G·(G†·G)^k to inflate the effective noise by an integer factor (2k+1). For non-integer scale factors the last tail gates receive one additional fold so that the total gate count matches round(scale_factor * len(ops)).

Parameters:

  • ops (list[dict]) – List of gate operation dicts {"name": str, "qubits": list[int], "params": list[float]}.

  • scale_factor (float) – Desired noise amplification factor. Must be ≥ 1. Values of the form 2k+1 (odd integers) are exact; other values use partial folding.

Returns:

Folded gate sequence. Length ≈ scale_factor * len(ops).

Return type:

list[dict]

Examples

>>> ops = [{"name": "RY", "qubits": [0], "params": [0.5]}]
>>> fold_gates(ops, 3)  # G -> G·G†·G
[{"name": "RY", ...}, {"name": "RY", ..., "params": [-0.5]}, {"name": "RY", ...}]

class quantx_engine.mitigation.RichardsonExtrapolator[source]¶

Bases: Extrapolator

Richardson / Lagrange extrapolation to zero noise.

Fits the unique polynomial of degree len(scale_factors) - 1 passing through all data points and evaluates it at x = 0 using the closed-form Lagrange formula. Exact for polynomial noise models of matching degree.

This is the most commonly used ZNE extrapolator: it requires no hyperparameters and works with as few as 2 points.

quantx_engine.mitigation.zne_mitigate(ops, executor, scale_factors=None, extrapolator=None)[source]¶

Run zero-noise extrapolation and return the mitigated expectation value.

The circuit ops is run at each noise level (via gate folding) and the noisy results are extrapolated back to zero noise.

Parameters:

  • ops (list[dict]) – List of gate operation dicts {"name": str, "qubits": list[int], "params": list[float]}.

  • executor (Callable[[list[dict]], float]) – Callable (ops: list[dict]) -> float that runs the circuit and returns an expectation value. Build one with make_sv_executor().

  • scale_factors (list[float] | None) – Noise scale factors to evaluate. Default: [1, 3, 5]. Must all be ≥ 1; values of the form 2k+1 (odd integers) produce exact gate folding, while non-integer values use partial folding.

  • extrapolator (Extrapolator | None) – Extrapolation strategy. Default: RichardsonExtrapolator.

Return type:

ZNEResult

Examples

>>> def my_executor(ops):
...     sv = GpuStatevector(n_qubits=2)
...     for op in ops:
...         sv.apply_gate(op["name"], op["qubits"], op.get("params", ()))
...     return sv.expectation_z(0)
>>> result = zne_mitigate(bell_ops, my_executor, scale_factors=[1, 3, 5])
>>> print(result.mitigated_value)
class quantx_engine.mitigation.QuasiProbabilityDecomposition(basis, gamma)[source]¶

Bases: object

Quasi-probability decomposition (QPD) of an ideal single-qubit gate.

Represents the ideal gate as a signed sum of noisy implementations:

G_ideal = Σ_i q_i * (P_i · G_noisy)

where q_i can be negative (hence “quasi-probability”) and P_i is a Pauli operator prepended before the (noisy) gate.

The one-norm γ = Σ_i |q_i| > 1 quantifies the sampling overhead; the total number of circuit samples required to achieve standard error ε scales as O(γ^{2m} / ε²) for an m-gate circuit.

Variables:

  • basis (list[tuple[str, float, float]]) – List of (pauli_name, sign, sample_prob) tuples where: - pauli_name ∈ {"I", "X", "Y", "Z"}, - sign = +1.0 or −1.0, - sample_prob = |q_i| / γ (positive, sums to 1).

  • gamma (float) – One-norm of the quasi-probability distribution.

classmethod from_depolarizing(noise_prob)[source]¶

Build the QPD for a gate subject to single-qubit depolarizing noise.

Models the noisy channel as:

Λ_p(ρ) = (1-p)ρ + (p/3)(XρX + YρY + ZρZ)

and inverts it to recover the ideal gate. This is the Pauli-error parameterisation: DepolarizingNoise with probability p is (1 − p)ρ + p·I/2, which is this channel at noise_prob = 3p/4. The resulting quasi-probability weights are:

  • q_I = (1 − p/3) / (1 − 4p/3) [positive]

  • q_X = q_Y = q_Z = −(p/3) / (1 − 4p/3) [negative for p > 0]

  • γ = (1 + 2p/3) / (1 − 4p/3)

Parameters:

noise_prob (float) – Depolarizing probability p per gate, in [0, 3/4).

Raises:

MitigationError – If noise_prob is out of range.

quantx_engine.mitigation.pec_mitigate(ops, noisy_executor, noise_prob, n_samples=100, seed=None)[source]¶

Run probabilistic error cancellation and return the mitigated expectation.

For each of the n_samples Monte Carlo trials, an independent Pauli twirl is sampled for every single-qubit gate in ops and prepended to it. The trial result is multiplied by a weight of γ^m · Π sign_i and the weighted mean over all trials converges to the noiseless expectation value.

Two-qubit gates are passed through unmodified (no twirl applied).

Parameters:

  • ops (list[dict]) – List of gate operation dicts {"name": str, "qubits": list[int], "params": list[float]}.

  • noisy_executor (Callable[[list[dict]], float]) – Callable (ops: list[dict]) -> float that runs the circuit with noise (e.g. backed by a noisy simulator or real hardware) and returns an expectation value.

  • noise_prob (float) – Single-qubit depolarizing noise probability per gate, in [0, 3/4). Used to build the quasi-probability decomposition.

  • n_samples (int) – Number of Monte Carlo samples. Larger values reduce statistical error but increase runtime. Standard error ∝ 1/√n_samples.

  • seed (int | None) – Optional random seed for reproducibility.

Return type:

PECResult

Notes

The statistical error of PEC scales as O(γ^m / √n_samples) where γ is the one-norm of the QPD and m is the number of single-qubit gates. For deep circuits this overhead becomes prohibitive, making PEC suitable mainly for shallow circuits on near-term devices.

quantx_engine.mitigation.make_sv_executor(n_qubits, observable_fn, backend='numpy', dtype='complex128')[source]¶

Create a noiseless statevector executor for use with ZNE.

The returned callable initialises a fresh GpuStatevector for each circuit run, applies all gates, and returns observable_fn(sv).

Parameters:

  • n_qubits (int) – Number of qubits.

  • observable_fn (Callable[[Any], float]) – Function that takes a GpuStatevector and returns a float. Common choices: lambda sv: sv.expectation_z(0) or lambda sv: float(sv.probabilities([0])[1]).

  • backend (str) – "numpy" (default), "cupy", or "auto".

  • dtype (str) – "complex128" (default, fp64) or "complex64" (fp32).

Returns:

An executor compatible with zne_mitigate().

Return type:

Callable[[list[dict]], float]

Examples

>>> executor = make_sv_executor(2, lambda sv: sv.expectation_z(0))
>>> result = zne_mitigate(ops, executor, scale_factors=[1, 3, 5])
