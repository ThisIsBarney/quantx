quantx_engine.mps¶

Matrix-product states that stay in the engine (M11).

A state the engine makes stays there, under a handle, until it is freed: a ground state, one-site operators, time evolution and measurements chain without the state passing through Python or JSON. The methods that change a state do it in place and return it, so they compose:

from quantx_engine import mps
from quantx_engine.models import XXZChain

chain = XXZChain(L=32)
gs = mps.ground_state(chain, max_bond=128)
phi = gs.copy().apply("Sz", 16)                 # S^z_16 |GS>, not renormalized
gs.evolve(chain, dt=0.05, steps=20)             # e^{-iHt} |GS> = e^{-i E0 t} |GS>
phi.evolve(chain, dt=0.05, steps=20)
c = gs.matrix_elements("Sz", phi)               # <GS| e^{iHt} S^z_j e^{-iHt} S^z_16 |GS>

Operators may change the charge. S^+ and S^- move a spin state to the next S^z sector, and the Hubbard Cdag_up, C_dn, … add or remove an electron, carrying the Jordan-Wigner string on every site to their left, so a Green’s function is:

from quantx_engine.models import HubbardChain

chain = HubbardChain(L=16, U=4.0)
gs = mps.ground_state(chain, n_up=8, n_dn=8)
phi = gs.copy().apply("Cdag_up", 8)             # c+_{8 up} |GS>, now n_up = 9
phi.evolve(dt=0.05, steps=20)
g = gs.matrix_elements("C_up", phi)             # e^{-i E0 t} <GS| c_{j up}(t) c+_{8 up} |GS>

The diagonal operators of each local space are in OPERATORS, the ones that change the charge in CHARGED_OPERATORS, in the conventions of quantx_engine.models (S = sigma/2). Any other one-site operator can be given as its matrix. Evolution is two-site TDVP; a state may be evolved under another model of the same length and local space than the one it was made with (a quench).

A matrix-product state held by the native engine, until it is freed.

Make one with ground_state() or product(). The methods that change it do so in place and return it; copy() makes an independent state. The engine frees the state when this object is collected, or at free().

matrix_elements(op, ket, *, string=None)[source]¶

<self| O_j |ket> for every site j, as they are: neither state is normalized.

O_j carries its string on the sites left of j. For an operator that changes the charge, the values are zero unless self is in the sector O takes ket to.

Real for a real diagonal operator, complex otherwise; zero for one that changes the charge.

copy()[source]¶
apply(op, site, *, string=None)[source]¶

O_site |self>, in place and not renormalized.

O is a name from OPERATORS or CHARGED_OPERATORS, a diagonal, or a matrix on the local space, <s'|O|s> with row s’ the result. string is a diagonal of phases applied on every site left of site too, as a fermion operator’s Jordan-Wigner string is; the named fermion operators bring their own. An operator that changes the charge moves the state to its new sector (sector). It must change it by one amount, so S^x is refused: its correlations are sums of those of S^+ and S^-, each applied to a copy.

evolve(model=None, *, dt, steps=1, imaginary=False, max_bond=256, cutoff=1e-10)[source]¶

steps two-site TDVP steps of exp(-i H dt), in place.

With imaginary, of exp(-H dt), renormalized after each step. model is the Hamiltonian (default: the one this state was made with); another of the same length and local space is a quench.
