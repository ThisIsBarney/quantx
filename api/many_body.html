Many-Body Physics¶

Modules for simulating correlated many-body quantum systems.

Many-Body Solvers¶

Hubbard model, Ising chain, SYK model, finite-temperature calculations.

Many-body physics enhancements for the QuantX engine (M102).

Three additions:

Out-of-time-order correlators (OTOCs)

Measure quantum information scrambling via the squared commutator:

C(t) = -⟨[W(t), V]²⟩  =  1 - Re F(t)
F(t) = ⟨W†(t) V† W(t) V⟩

where W(t) = exp(iHt) W exp(-iHt) is the Heisenberg-picture operator. Fast scrambling (chaotic systems like SYK) drives C(t) → 1 on the scrambling time scale t* ~ β ln N.

Sachdev-Ye-Kitaev (SYK) model

Random all-to-all q-body Majorana fermion Hamiltonian:

H_SYK = (i^{q/2} / q!) Σ_{1≤i₁<…<i_q≤N} J_{i₁…i_q} χ_{i₁}…χ_{i_q}

The Majorana operators χ_i satisfy {χ_i, χ_j} = 2δ_{ij} and are mapped to qubits via a Jordan-Wigner-like transformation. The q=4 model is the minimal holographic (AdS/CFT dual) case.

2D DMRG via snake-path mapping

Maps a 2D Lx×Ly lattice to a 1D MPS via a snake (boustrophedon) path, then runs the existing DMRG sweep engine. Long-range 2D couplings become medium-range 1D interactions that DMRG can still handle efficiently with modest bond dimensions.

Quick start:

from quantx_engine.contrib.many_body import compute_otoc, SYKModel, dmrg_2d

# OTOC for a 4-qubit Ising chain
from quantx_engine.contrib.trotter import ising_trotter
sim = ising_trotter(n=4, J=1.0, h=0.5)
result = compute_otoc(sim.hamiltonian, op_w="X", op_v="Z",
                      site_w=0, site_v=3, t=1.0, n_qubits=4)
print(result.otoc_value)   # C(t) ∈ [0, 1]

# SYK model
model = SYKModel(N=8, q=4, seed=42)
print(model.ground_state_energy)

# 2D DMRG
result = dmrg_2d(Lx=2, Ly=2, J=1.0, bond_dim=8, sweeps=4)
print(result.energy)

Finite-Size Scaling¶

Binder cumulant, finite-size extrapolation, critical exponent fitting.

Finite-size scaling and quantum phase-transition analysis (M74).

Three main components:

binder_cumulant — compute the Binder cumulant U = 1 − ⟨m⁴⟩/(3⟨m²⟩²) from order-parameter samples. U → 0 in the disordered phase (Gaussian fluctuations) and U → 2/3 in the ordered phase (bimodal distribution).

entanglement_scaling — compute the bipartite von Neumann entropy S(A) for all subsystem sizes A = 1, …, L−1 via SVD of the reshaped state vector, and fit the 1D CFT formula S(A) = (c/3) ln[(L/π) sin(πA/L)] + const to extract the central charge c.

FiniteSizeScaling — locate the critical coupling J_c from Binder cumulant data at multiple system sizes L:

  1. binder_crossings() finds parameter values where adjacent-size curves intersect (linear interpolation).

  2. fit_critical_point() averages those crossings into a single estimate of J_c ± σ.

  3. data_collapse(jc, nu) measures how well data from different L collapse onto a single scaling curve when plotted against (J − J_c) L^{1/ν}.

Quick start:

import numpy as np
from quantx_engine.contrib.finite_size import FiniteSizeScaling, binder_cumulant

# Simulated Binder cumulants near J_c = 1.0
params = np.linspace(0.7, 1.3, 30)
sizes  = [8, 16, 32, 64]
nu     = 1.0  # correlation-length exponent
J_c    = 1.0
def logistic(x): return (2/3) / (1 + np.exp(-4 * x))
binder = np.array([logistic((params - J_c) * L**(1/nu)) for L in sizes])

fss    = FiniteSizeScaling(sizes, params, binder)
result = fss.fit_critical_point()
print(f"J_c = {result.critical_point:.4f} ± {result.critical_point_std:.4f}")

Physical validation¶

Binder cumulant U_4 = 1 - <m^4>/(3*<m^2>^2): at the critical point, U_4 curves for different system sizes L all cross at the same value U_4^* (≈ 0.610 for the 3D Ising model) [Binder1981]. For an ordered phase (T << T_c): U_4 -> 2/3. For disordered (T >> T_c): U_4 -> 0.

quantx_engine.contrib.finite_size.binder_cumulant(samples)[source]¶

Compute the Binder cumulant U = 1 − ⟨m⁴⟩ / (3⟨m²⟩²).

The Binder cumulant is a dimensionless ratio that distinguishes phases without needing the thermodynamic limit:

  • U → 0 disordered phase (Gaussian fluctuations: ⟨m⁴⟩ = 3⟨m²⟩²)

  • U → 2/3 ordered phase (bimodal: |m| ≈ const)

At the critical point, Binder cumulant curves for different system sizes L cross at a universal value U* ∈ (0, 2/3).

Note

This function uses raw moments ⟨m²⟩ and ⟨m⁴⟩ (the standard definition in the condensed-matter literature). These are not centred cumulants. Passing samples with a non-zero mean correctly gives U ≈ 2/3 for a biased ordered phase (e.g. ferromagnet in an external field), which is the physically correct result.

Parameters:

samples (ndarray) – 1D (or ravelled) array of order-parameter values. At least 2 samples are required.

Returns:

Binder cumulant U. Theoretically in [0, 2/3], but may be slightly outside this range due to finite sampling.

Return type:

float

Raises:

FiniteSizeError – If fewer than 2 samples are provided or ⟨m²⟩ ≈ 0.

quantx_engine.contrib.finite_size.entanglement_scaling(psi, L, d=2)[source]¶

Compute bipartite von Neumann entropy S(A) for all bipartitions.

Reshapes the length-d^L state vector as a (d^A, d^{L−A}) matrix and computes the von Neumann entropy

S(A) = −Tr(ρ_A ln ρ_A) = −∑_i λ_i ln λ_i,

where λ_i = σ_i² are the eigenvalues of the reduced density matrix ρ_A obtained from the singular values σ_i of the reshaped matrix.

For a 1D critical system described by a CFT with central charge c, the entropy satisfies

S(A) = (c/3) ln[(L/π) sin(πA/L)] + s₀.

A least-squares fit of this formula (for L ≥ 4) returns the central charge.

Parameters:

  • psi (ndarray) –

    State vector, shape (d^L,). Must be exactly d^L elements. Need not be normalised (normalisation is applied internally).

    Storage convention: the state is indexed in standard tensor-product (row-major / C) order, i.e. psi[i] = ⟨s_0 s_1 … s_{L-1}|ψ⟩ where site 0 is the most-significant index. Equivalently, index = s_0·d^{L-1} + s_1·d^{L-2} + … + s_{L-1}. This is the natural NumPy ordering and the convention used throughout QuantX.

  • L (int) – Number of lattice sites.

  • d (int) – Local Hilbert-space dimension (default 2 for qubits/spin-1/2).

Return type:

EntanglementResult

Raises:

FiniteSizeError – If len(psi) != d^L or psi has near-zero norm.

MPS Simulator¶

Matrix product state (MPS) simulator with TEBD time evolution.

M104/M109: MPS simulator — adaptive bond dimension, environment caching, GPU acceleration (CuPy backend), and benchmarks for 50+ qubit circuits.

Three additions to the existing tensor-network stack:

Adaptive truncation

SVD-compress each bond to keep only singular values above a relative threshold eps * S_max, up to max_bond. Bond dimension grows and shrinks dynamically instead of being pinned at a fixed value.

MPSSimulator

Gate-level MPS circuit simulator:

  • Single-qubit gates — applied directly (no truncation needed).

  • Two-qubit gates on adjacent sites — two-site SVD with adaptive truncation.

  • Accumulated truncation error tracked across all gates.

  • Left/right environment cache for fast expectation-value sweeps.

CachedDMRG

DMRG variant that retains the left-environment stack built during the left-to-right pass and reuses it during the right-to-left pass, reducing environment reconstruction from O(N²) to O(N) per sweep.

Benchmark + validation helpers

mps_benchmark — time a random circuit, report truncation error. ghz_fidelity — fidelity of MPS-prepared GHZ state vs exact. compare_mps_sv — cross-validate MPS against statevector for n ≤ 20.

from quantx_engine.contrib.mps_simulator import (

)

sim_gpu.h(0)

Tensor Network¶

Generic tensor network contraction framework.

Tensor Network methods for the QuantX engine.

Implements Matrix Product States (MPS), Matrix Product Operators (MPO), Time-Evolving Block Decimation (TEBD), and Density Matrix Renormalization Group (DMRG) in pure Python / NumPy.

Classes:

MPS — Matrix Product State representation of N-qubit states MPO — Matrix Product Operator representation of Hamiltonians TEBD — Trotterized time evolution under nearest-neighbor Hamiltonians DMRG — Two-site DMRG ground-state search DMRGResult — Result container returned by DMRG.run()

Usage:

from quantx_engine.contrib.tensor_network import MPS, MPO, TEBD, DMRG

# Build a 6-qubit |000000⟩ product state
mps = MPS.product_state([0, 0, 0, 0, 0, 0])

# Time-evolve with TEBD
tebd = TEBD(mps=MPS.product_state([0]*6), max_chi=16)
history = tebd.evolve_ising(J=1.0, h=0.5, dt=0.01, n_steps=100)

Time-Dependent DMRG (TD-DMRG)¶

Time-Dependent DMRG (tDMRG) — M94.

Provides real- and imaginary-time MPS evolution under arbitrary MPO Hamiltonians using the TEBD Trotter-gate machinery with DMRG-style bond-dimension control.

Algorithm¶

Two-site Trotter gates are extracted from the MPO by contracting adjacent tensors along the MPO bond index:

h_{i,i+1}[s0,s1,t0,t1] = Σ_k  W_i[-1, k, s0, t0] · W_{i+1}[k, 0, s1, t1]

i.e., the left tensor contributes its “last row” (the one that starts building up the operator from the left) and the right tensor its “first column” (the one that finalises the action on the right).

For real-time evolution each gate is U = exp(−i h_bond dt). For imaginary-time evolution each gate is Γ = exp(−h_bond dτ) followed by re-normalisation.

Trotter order 2 (default):

U(dt) ≈ [Π_{even} U_bond(dt/2)] · [Π_{odd} U_bond(dt)] · [Π_{even} U_bond(dt/2)]

Entanglement entropy is the von Neumann entropy of the bipartition at each internal bond after each sweep:

S_i = −Σ_k λ_k² log λ_k²

where {λ_k} are the normalised singular values kept at bond i.

Spectral Functions¶

Dynamical structure factor, spectral weight, Lehmann representation.

Spectral functions and Krylov time evolution for the QuantX engine (M73).

Two main components:

SpectralResult — wraps the raw output of Engine.run_spectral() into a typed, queryable object. Contains the dynamical structure factor S(k, ω), k-point grid, frequency axis, and spectral gap.

KrylovEvolver — pure-Python Arnoldi-Krylov implementation for time-evolution without full diagonalization:

  • evolve(H, psi0, t) → |ψ(t)⟩ = e^{−iHt}|ψ₀⟩

  • imaginary_evolve(H, psi0, tau) → normalised e^{−Hτ}|ψ₀⟩ (converges to the ground state)

Both methods scale as O(N·m²) where N = Hilbert-space dimension and m is the Krylov dimension (default 30), vs O(N³) for full diagonalisation.

Quick start:

import numpy as np
from quantx_engine.contrib.spectral import KrylovEvolver
from quantx_engine.contrib.lanczos import SparseHamiltonian, LanczosSolver

# Real-time evolution: 4-site Heisenberg, Néel initial state
H = SparseHamiltonian.heisenberg_1d(4, J=1.0)
neel = np.zeros(16, dtype=complex)
neel[0b0101] = 1.0          # |↑↓↑↓⟩ in the binary basis
evolver = KrylovEvolver(m=20)
psi_t = evolver.evolve(H, neel, t=2.0)
print(abs(neel @ psi_t.conj())**2)  # autocorrelation |⟨Néel|ψ(t)⟩|²

# Ground-state projection via imaginary-time evolution
psi_gs = evolver.imaginary_evolve(H, neel, tau=5.0)
e0_krylov = float(np.real(psi_gs.conj() @ H.matvec(psi_gs)))

# Reference
e0_lanczos = LanczosSolver(k=1, seed=0).solve(H).ground_state_energy()
print(abs(e0_krylov - e0_lanczos))  # < 1e-6

class quantx_engine.contrib.spectral.KrylovEvolver(m=30, dt=0.1, *, H=None, psi0=None, krylov_dim=None)[source]¶

Bases: object

Arnoldi-Krylov time evolution: e^{−iHt}|ψ₀⟩ without full diagonalisation.

The algorithm builds an m-dimensional Krylov subspace span{|ψ₀⟩, H|ψ₀⟩, H²|ψ₀⟩, …, H^{m-1}|ψ₀⟩} via the Arnoldi recurrence, then computes the matrix exponential of the small (m×m) upper Hessenberg projection. This requires only m matrix-vector products (each O(N·nnz)) instead of O(N³) for full diagonalisation.

Parameters:

  • m (int) – Krylov subspace dimension. Larger values are more accurate but more expensive. m=30 is suitable for moderate accuracy on systems with N ≤ 10⁶.

  • dt (float) – Default time step for long-time evolution (used when dt is not specified in evolve()).

Examples

>>> evolver = KrylovEvolver(m=20)
>>> psi_t = evolver.evolve(H, psi0, t=1.0)   # single step
>>> result = evolver.evolve_trajectory(H, psi0, t_max=5.0, n_steps=20)
