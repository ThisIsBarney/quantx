Machine Learning & Characterisation¶

Modules bridging quantum simulation and machine learning, plus benchmarking and device characterisation tools.

Quantum Machine Learning¶

Variational quantum classifiers, data embedding, QNN training.

Quantum Machine Learning module for the QuantX engine.

Implements variational quantum circuits for supervised learning tasks. State evolution is delegated to GpuStatevector, which supports both NumPy (CPU) and CuPy (GPU) backends — pass backend="cupy" to run on GPU with no other changes.

Classes:

QuantumNeuralNetwork — parameterized circuit (forward pass + gradients) QuantumClassifier — sklearn-style binary/multi-class classifier

The circuit architecture:

  1. Angle encoding: Ry(2·x_i) on qubit i for each input feature.

  2. Hardware-efficient ansatz (repeated n_layers times):

    • Ry(θ_{l,i}) on every qubit i

    • CNOT ladder: (0→1), (1→2), …, (n_qubits-2→n_qubits-1)

  3. Measurement: ⟨Z_0⟩ (binary) or ⟨Z_i⟩ per output qubit (multi-class).

Parameter-shift rule (exact gradient):

∂f/∂θ = [f(θ + π/2) − f(θ − π/2)] / 2

Usage:

from quantx_engine.contrib.qml import QuantumClassifier

clf = QuantumClassifier(n_features=4, n_layers=2) history = clf.fit(X_train, y_train, n_epochs=100, learning_rate=0.05) predictions = clf.predict(X_test) probabilities = clf.predict_proba(X_test)

# GPU-accelerated (requires CuPy): clf_gpu = QuantumClassifier(n_features=4, n_layers=2, backend=”cupy”)

Physical validation¶

ZZ feature map: kernel K(x,y) = |<phi(x)|phi(y)>|^2 is bounded in [0,1]. For identical inputs K(x,x) = 1 (perfect self-similarity) [Havlicek2019]. Quantum-classical kernel PSD (positive semi-definite): Gram matrix K_ij should have all non-negative eigenvalues (verified in test suite).

Quantum Kernel Methods¶

Fidelity kernels, projected kernels, kernel matrix estimation.

Quantum kernel methods and Quantum Support Vector Machine (M80).

Implements a ZZ-entanglement circuit feature map (IBM Qiskit convention), the fidelity quantum kernel K(x,x’) = |⟨φ(x)|φ(x’)⟩|², kernel target alignment metrics, and a soft-margin QSVM trained with a simplified SMO.

All computations are pure NumPy; no external quantum-computing or ML framework is required.

Quick reference:

from quantx_engine.contrib.quantum_kernel import ZZFeatureMap, QSVM
import numpy as np

fm  = ZZFeatureMap(n_qubits=2, n_reps=2)
clf = QSVM(feature_map=fm, C=1.0)
X   = np.array([[0.1, 0.2], [0.8, 0.9], [0.2, 0.1], [0.9, 0.8]])
y   = np.array([-1.0, 1.0, -1.0, 1.0])
res = clf.fit(X, y)
print(clf.score(X, y))   # 1.0

class quantx_engine.contrib.quantum_kernel.ZZFeatureMap(n_qubits, n_reps=2)[source]¶

Bases: QuantumFeatureMap

ZZ-entanglement circuit feature map (IBM Qiskit convention).

Each of n_reps repetitions applies:

  1. Hadamard on every qubit: H^⊗n

  2. Phase encoding: Rz(2 x_i) on qubit i for all i

  3. Pairwise ZZ interactions for all ordered pairs (i, j), i < j:

    CX_{i,j} → Rz_j(2(π − x_i)(π − x_j)) → CX_{i,j}

This realises the unitary U_φ(x) such that |φ(x)⟩ = U_φ(x)|0…0⟩.

Parameters:

  • n_qubits (int) – Number of qubits (must equal the dimension of the input vectors).

  • n_reps (int) – Number of encoding layers.

quantx_engine.contrib.quantum_kernel.target_alignment(K, y)[source]¶

Kernel-Target Alignment (KTA) between kernel K and labels y.

Measures how well K separates the two classes:

KTA = ⟨K, yy^T⟩_F / (n · ‖K‖_F)

where ⟨·,·⟩_F is the Frobenius inner product and y ∈ {−1, +1}. KTA = 1 when K = yy^T (perfect alignment).

Parameters:

  • K (ndarray) – Kernel matrix of shape (n, n).

  • y (ndarray) – Binary labels ±1, shape (n,).

Return type:

float in [−1, 1] (0 for trivial/zero kernel).

Trains a soft-margin SVM using the fidelity quantum kernel:

Randomised Benchmarking & Quantum Volume¶

Randomized Benchmarking and Quantum Volume (M81).

Provides a pure-NumPy implementation of:

  • StandardRB: 1-qubit randomized benchmarking using the full Clifford group; fits the exponential decay P(m) = A·p^m + B and extracts the Error Per Clifford (EPC).

  • QuantumVolume: IBM quantum-volume protocol for n qubits; evaluates the heavy-output-generation probability and returns the QV number.

Both solvers use exact density-matrix simulation with a global depolarizing noise channel; no external framework is required.

Quick reference:

from quantx_engine.contrib.rb_qv import StandardRB, QuantumVolume
result = StandardRB(p_error=0.01).run([1, 5, 10, 20, 50], n_sequences=30)
print(result.epc)          # ~ 0.01/2

qv = QuantumVolume(p_error=0.005)
qv_results = qv.run(max_qubits=3, n_trials=100)
print(qv_results[-1].quantum_volume)  # largest passing QV

References

[1]

Knill, E. et al. (2008). Randomized benchmarking of quantum gates. Phys. Rev. A 77, 012307. https://doi.org/10.1103/PhysRevA.77.012307

[2]

Cross, A. W. et al. (2019). Validating quantum computers using randomized model circuits. Phys. Rev. A 100, 032328. https://doi.org/10.1103/PhysRevA.100.032328

[3]

Magesan, E., Gambetta, J. M. & Emerson, J. (2011). Scalable and robust randomized benchmarking of quantum processes. Phys. Rev. Lett. 106, 180504. https://doi.org/10.1103/PhysRevLett.106.180504

Physical validation¶

Standard RB: EPC (error per Clifford gate) extracted from exponential decay A + B*p^m, where p = 1 - EPC/(1 - 1/d^2), d = 2^n [Magesan2011]. Quantum Volume: QV = 2^m where m is the largest m s.t. the heavy-output probability of m-qubit random circuits exceeds 2/3 [Cross2019].

Cross-Entropy Benchmarking (XEB)¶

Cross-Entropy Benchmarking (XEB) — M82.

Implements the linear cross-entropy benchmarking protocol as used in Google’s quantum supremacy experiments and IBM’s heavy-output benchmarks.

Linear XEB fidelity:

F_XEB = d · E_x~P_noisy[P_ideal(x)] - 1

where d = 2**n_qubits, P_ideal is the ideal probability distribution from a noiseless circuit, and x is sampled from P_noisy (the noisy circuit). For an exact density-matrix simulation both distributions are known, so the fidelity simplifies to:

F_XEB = d · ∑_x P_ideal(x) · P_noisy(x) - 1

For noiseless circuits F_XEB ≈ 1; for fully depolarised circuits F_XEB ≈ 0.

Quick reference:

from quantx_engine.contrib.xeb import CrossEntropyBenchmarking
result = CrossEntropyBenchmarking(n_qubits=2, p_error=0.01).run(
    depths=[1, 2, 4, 8], n_trials=50
)
print(result.mean_fidelity)  # ~ exp(-p * d * depth) for small p

References

[1]

Arute, F. et al. (2019). Quantum supremacy using a programmable superconducting processor. Nature 574, 505–510. https://doi.org/10.1038/s41586-019-1666-5

[2]

Boixo, S. et al. (2018). Characterizing quantum supremacy in near-term devices. Nat. Phys. 14, 595–600. https://doi.org/10.1038/s41567-018-0124-x

[3]

Morvan, A. et al. (2024). Phase transitions in random circuit sampling. Nature 634, 328–333. https://doi.org/10.1038/s41586-024-07998-6

Physical validation¶

XEB fidelity F_XEB = <P_ideal> * D - 1, where D = 2^n is the Hilbert-space dimension and P_ideal is the ideal distribution probability [Arute2019]. For a perfect noiseless device F_XEB = 1; for a maximally mixed output F_XEB = 0.

Quantum Tomography¶

State tomography, process tomography, maximum-likelihood estimation.

Quantum State and Process Tomography — M83.

Provides pure-NumPy implementations of:

  • StateTomography: reconstruct a density matrix from ideal Pauli expectation values via linear inversion; compute state fidelity.

  • ProcessTomography: compute the Pauli-basis chi (χ) process matrix for an n-qubit unitary, compute average gate fidelity and process fidelity.

No classical optimisation or maximum-likelihood estimation is performed — all reconstruction uses exact linear inversion. This makes the module suitable for exact simulation workflows where shot noise is absent.

Quick reference:

from quantx_engine.contrib.tomography import StateTomography, ProcessTomography
import numpy as np

# State tomography
rho = np.array([[0.9, 0.05], [0.05, 0.1]], dtype=complex)
st = StateTomography(n_qubits=1)
exp_vals = st.pauli_expectations(rho)       # {'X': ..., 'Y': ..., 'Z': ...}
rho_rec = st.reconstruct_linear(exp_vals)   # recovered density matrix
print(st.state_fidelity(rho, rho_rec))      # ~1.0

# Process tomography
pt = ProcessTomography(n_qubits=1)
chi = pt.chi_matrix(np.array([[0,1],[1,0]], dtype=complex))  # X gate
print(pt.average_gate_fidelity(chi, chi))   # 1.0
