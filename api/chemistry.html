Quantum Chemistry¶

Molecular Hamiltonians, second-quantized operators, VQE driver.

Quantum chemistry module for the QuantX engine.

Provides Jordan-Wigner transformation of molecular Hamiltonians and pre-built molecular VQE problem instances for small molecules.

Molecules included:

H2 (hydrogen molecule) — 2 electrons, 2 spatial orbitals → 4 qubits LiH (lithium hydride) — 4 active electrons, 5 spatial orbitals → 10 qubits BeH2 (beryllium hydride) — 4 active electrons, 6 spatial orbitals → 12 qubits

Usage:

from quantx_engine.chemistry import MolecularVQE problem = MolecularVQE.h2(bond_length=0.735) vqe_opts = problem.to_vqe_options(ansatz=”uccsd”, shots=1024) result = engine.run_vqe(vqe_opts)

References

[1]

Peruzzo, A. et al. (2014). A variational eigenvalue solver on a photonic chip. Nat. Commun. 5, 4213. https://doi.org/10.1038/ncomms5213

[2]

Jordan, P. & Wigner, E. (1928). Ueber das Paulische Aequivalenzverbot. Z. Phys. 47, 631–651. https://doi.org/10.1007/BF01331938

[3]

Helgaker, T., Jorgensen, P. & Olsen, J. (2000). Molecular Electronic- Structure Theory. Wiley. ISBN 978-0-471-96755-2.

Physical validation¶

H2 minimal-basis VQE (4 qubits, UCCSD ansatz, bond length 0.735 Angstrom) converges to E_FCI = -1.8572750 Hartree (Full-CI reference from Peruzzo 2014, Table 1).

quantx_engine.chemistry.jordan_wigner(one_body, two_body, n_orbitals, constant=0.0)[source]¶

Apply the Jordan-Wigner transform to a second-quantized Hamiltonian.

H = constant + Σ h_pq a†_p a_q + ½ Σ g_pqrs a†_p a†_q a_r a_s

Each fermionic mode p maps to qubit p via:

a†_p = (X_p - iY_p)/2 × Z_0 ⊗ … ⊗ Z_{p-1} a_p = (X_p + iY_p)/2 × Z_0 ⊗ … ⊗ Z_{p-1}

Parameters:

  • one_body (list[tuple[int, int, float]]) – List of (p, q, h_pq) tuples for one-body integrals.

  • two_body (list[tuple[int, int, int, int, float]]) – List of (p, q, r, s, g_pqrs) tuples for two-body integrals (physicist notation: ⟨pq|rs⟩).

  • n_orbitals (int) – Number of spin-orbitals (= 2 × spatial orbitals for spin ½).

  • constant (float) – Nuclear repulsion / constant energy shift.

Returns:

Qubit Hamiltonian in the Pauli basis.

Return type:

PauliHamiltonian

Advanced Chemistry¶

Noise-aware VQE, excited-state solver, CASSCF, multi-reference methods.

Advanced quantum chemistry algorithms (M79).

Implements UCCSD, ADAPT-VQE, QAOA, and QITE as pure-Python/NumPy exact statevector solvers. All methods operate on the full 2ⁿ-dimensional Hilbert space (feasible for n ≤ 16) and build on the PauliHamiltonian representation from quantx_engine.chemistry.

Quick reference:

from quantx_engine.chemistry import MolecularVQE
from quantx_engine.advanced_chemistry import UCCSDSolver, QITESolver

problem = MolecularVQE.h2()
H_mat = build_hamiltonian_matrix(problem.hamiltonian)

# UCCSD
solver = UCCSDSolver(n_electrons=2, n_qubits=4)
result = solver.run(H_mat)
print(result.energy)

# QITE
qite = QITESolver(n_qubits=4)
res  = qite.run(H_mat, delta_tau=0.05, n_steps=80)
print(res.final_energy)

References

[1]

Grimsley, H. R. et al. (2019). An adaptive variational algorithm for exact molecular simulations on a quantum computer. Nat. Commun. 10, 3007. https://doi.org/10.1038/s41467-019-10988-2

[2]

Motta, M. et al. (2020). Determining eigenstates and thermal states on a quantum computer using quantum imaginary time evolution. Nat. Phys. 16, 205. https://doi.org/10.1038/s41567-019-0704-4

[3]

Romero, J. et al. (2018). Strategies for quantum computing molecular energies using the unitary coupled cluster ansatz. Quantum Sci. Technol. 4, 014008. https://doi.org/10.1088/2058-9565/aad3e4

QITE imaginary-time evolution on H2 minimal basis converges to E_FCI = -1.8573 Hartree within 80 steps of delta_tau=0.05 (verified against exact diagonalisation).

class quantx_engine.advanced_chemistry.UCCSDSolver(n_electrons, n_qubits)[source]¶

Bases: object

Unitary Coupled Cluster Singles and Doubles solver.

Builds the UCCSD ansatz by:

  1. Generating all single-excitation generators K_single = a†_v a_o − h.c. and double-excitation generators K_double = a†_v₁ a†_v₂ a_o₂ a_o₁ − h.c. in the Jordan-Wigner representation.

  2. Forming the combined anti-Hermitian operator A(θ) = Σ θ_s K_s + Σ θ_d K_d.

  3. Preparing the UCCSD state |ψ(θ)⟩ = expm(A(θ)) |HF⟩ via exact matrix exponentiation.

  4. Minimizing ⟨ψ(θ)|H|ψ(θ)⟩ over θ using coordinate descent.

Parameters:

  • n_electrons (int) – Number of electrons (occupied spin-orbitals in HF reference).

  • n_qubits (int) – Total number of spin-orbitals / qubits.

Examples

>>> from quantx_engine.chemistry import MolecularVQE
>>> from quantx_engine.advanced_chemistry import UCCSDSolver, build_hamiltonian_matrix
>>> problem = MolecularVQE.h2()
>>> H = build_hamiltonian_matrix(problem.hamiltonian)
>>> result = UCCSDSolver(n_electrons=2, n_qubits=4).run(H)
>>> abs(result.energy - problem.fci_energy) < 0.01
True

OO-VQE (Orbital-Optimised VQE)¶

M124: Orbital-optimised VQE (OO-VQE).

Orbital-optimised VQE simultaneously minimises the energy with respect to both the circuit (ansatz) parameters θ and the orbital rotation parameters κ. The orbital rotation is parametrised as an anti-Hermitian matrix K = κ^a_p q and applied as U(κ) = exp(K) to the one-body integral matrices.

Key components¶

OOVQEResult

Container for the OO-VQE optimisation trajectory.

OOVQESolver

Alternating-minimisation solver: inner VQE step (parametric circuit) + outer orbital gradient step.

Molecular Hamiltonian model¶

The Hamiltonian is specified in second quantisation as

H = Σ_{pq} h_pq a†_p a_q + ½ Σ_{pqrs} g_pqrs a†_p a†_q a_r a_s

Orbital rotations transform the one-electron integrals by

h̃_pq = (U^† h U)_pq, Ũ = exp(K)

where K is a real skew-symmetric matrix. For simplicity this module operates in the qubit representation via Jordan–Wigner with two spin-orbitals mapped to the Z and X Pauli terms, supporting up to 8 orbitals.

References

[1]

Sokolov, I. O. et al. (2020). Quantum orbital-optimised coupled-cluster doubles. J. Chem. Phys. 152, 124107. https://doi.org/10.1063/1.5141835

[2]

Takeshita, T. et al. (2020). Increasing the representation accuracy of quantum simulations of chemistry without extra quantum resources. Phys. Rev. X 10, 011004. https://doi.org/10.1103/PhysRevX.10.011004

[3]

Peruzzo, A. et al. (2014). A variational eigenvalue solver on a photonic chip. Nat. Commun. 5, 4213. https://doi.org/10.1038/ncomms5213

Physical validation¶

OO-VQE on H2 minimal basis (2 spatial orbitals, 4 spin-orbitals) converges to the FCI energy E_FCI = -1.8573 Hartree. The orbital-rotation step reduces the energy by at least 0.01 Hartree vs. standard VQE with identity orbitals for stretched geometries (bond length > 1.0 Angstrom).

Orbital-optimised VQE solver.

Uses an alternating minimisation strategy:

  1. Inner VQE: minimise ⟨ψ(θ)|H(κ)|ψ(θ)⟩ over circuit parameters θ by gradient descent.

  2. Orbital gradient step: update orbital parameters κ by one step of gradient descent on the orbital rotation manifold.

Parameters:

  • energy_fn (callable or None) – energy_fn(h_rotated, theta) -> float computing the VQE energy for given rotated one-electron integrals and circuit parameters. If None, the built-in 2-orbital JW model is used.

  • max_iterations (int) – Maximum number of macro (OO) iterations.

  • inner_steps (int) – Number of circuit gradient steps per macro iteration.

  • lr_circuit (float) – Learning rate for circuit parameter updates.

  • lr_orbital (float) – Learning rate for orbital rotation parameter updates.

  • conv_tol (float) – Convergence threshold: |ΔE| < conv_tol terminates the loop.

  • eps (float) – Finite-difference step for gradient estimates.

Noise-Aware VQE¶

VQE with device-level noise characterisation and mitigation loops.

Noise-aware VQE — M95.

Extends the existing VQE machinery with:

  • Shot noise — expectation values are estimated from a finite number of measurement samples rather than exact computation.

  • Hardware noise model — each gate application is followed by the appropriate depolarizing / amplitude-damping channel (via the density-matrix simulator in quantx_engine.primitives).

  • SPSA optimizer — Simultaneous Perturbation Stochastic Approximation uses only 2 function evaluations per iteration regardless of parameter count and is therefore well-suited for noisy landscapes.

  • Nelder-Mead fallback — included for noiseless or low-shot settings.

class quantx_engine.noise_vqe.SPSAOptimizer(a=0.1, c=0.1, A=10.0, alpha=0.602, gamma=0.101, seed=42)[source]¶

Bases: object

Simultaneous Perturbation Stochastic Approximation (SPSA) optimizer.

Uses only 2 function evaluations per iteration regardless of parameter count, making it efficient for noisy energy landscapes.

The gradient estimate is:

ĝ_k = [f(θ_k + c_k Δ_k) − f(θ_k − c_k Δ_k)] / (2 c_k) · Δ_k⁻¹

where Δ_k is a random ±1 Bernoulli vector (Rademacher distribution).

Update rule:

θ_{k+1} = θ_k − a_k ĝ_k
a_k = a / (A + k + 1)^α
c_k = c / (k + 1)^γ
Parameters:

  • a (float) – Initial step size numerator (controls learning rate magnitude).

  • c (float) – Initial perturbation size (should be ≈ noise level in f).

  • A (float) – Stability constant (typically set to ≈ 10 % of max_iter).

  • alpha (float) – Step-size decay exponent (theory: 0.602).

  • gamma (float) – Perturbation-size decay exponent (theory: 0.101).

  • seed (int or None) – Random seed for reproducibility.

CVaR-QAOA Optimizer¶

Conditional Value-at-Risk QAOA for combinatorial problems (MaxCut, TSP).

Note

The class exported as CVaRQAOAResult in quantx_engine is the result dataclass from this module (renamed to avoid a clash with advanced_chemistry.QAOAResult).

M115: QAOA with CVaR objective — combinatorial optimisation.

Provides a complete QAOA pipeline for combinatorial optimisation problems:

  • CVaR-QAOA (CVaRQAOA) — replaces the standard ⟨H⟩ objective with the Conditional Value-at-Risk CVaR_α, which focuses training on the best-α fraction of measurement outcomes and significantly improves convergence.

  • MaxCut (MaxCutProblem) — builds the Ising cost Hamiltonian for graph max-cut and evaluates approximation ratios.

  • TSP (TSPProblem) — encodes the Traveling Salesman Problem as a QUBO/Ising Hamiltonian using the standard one-hot city-position encoding.

  • Parameter landscape (QAOALandscape) — scans a (γ, β) grid at depth p=1 and returns the full energy surface for visualisation and analysis.

  • Warm-start initialisation (warm_start_qaoa()) — returns informed initial parameter guesses via several strategies.

Excited-State Methods¶

M113: Excited-state quantum chemistry.

Provides tools for computing excited-state energies and wavefunctions using variational quantum methods:

  • Exact diagonalization (ED) — exact for n_qubits ≤ 16; returns all eigenvalues/vectors via numpy.linalg.eigh.

  • Deflation VQE — iteratively adds a penalty λ|ψ_k⟩⟨ψ_k| to the Hamiltonian so that subsequent minimizations converge to the next excited state rather than repeating the ground state.

  • Folded-spectrum VQE — minimises ⟨(H − ω)²⟩ to target the eigenstate closest to a chosen energy ω.

Conical-intersection (near-degeneracy) detection sweeps a molecular geometry parameter and finds the crossing points between adjacent eigenvalue curves.
