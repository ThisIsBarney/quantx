Core Engine¶

The core engine module provides the C++ backend dispatcher and the fundamental sparse Hamiltonian solvers.

Engine¶

C++ engine bridge — ctypes / pybind11 interface to the QuantX native library.

Provides the Engine facade that dispatches to native C++ solvers (Lanczos, Trotter, MPS) when the shared library is available, and falls back transparently to the pure-Python implementations otherwise.

M159 adds a pybind11 fast path: when the _quantx_py extension module is importable (built with QX_ENABLE_PYBIND=ON), methods such as Engine.run_statevector() and Engine.run_circuit_sv() return NumPy arrays directly without any JSON round-trip overhead.

The native library is located via the environment variable QUANTX_LIB_PATH or by searching the standard platform-specific paths (quantx_engine.dll on Windows, libquantx_engine.so on Linux, libquantx_engine.dylib on macOS).

Lanczos Eigensolver¶

Lanczos and Arnoldi sparse eigensolver for large quantum Hamiltonians.

Fills the gap for systems too large for dense O(n³) Jacobi diagonalization. The Lanczos algorithm reduces an N×N symmetric matrix to a k×k tridiagonal form in k matrix-vector products, making it practical for quantum Hamiltonians with dim = 2^n where n is the system size.

References

[1]

Lanczos, C. (1950). An iteration method for the solution of the eigenvalue problem of linear differential and integral operators. J. Res. Natl. Bur. Stand. 45, 255–282. https://doi.org/10.6028/jres.045.026

[2]

Cullum, J. K. & Willoughby, R. A. (1985). Lanczos Algorithms for Large Symmetric Eigenvalue Computations, Vol. 1. Birkhäuser. ISBN 978-0-8176-3058-4.

[3]

Paige, C. C. (1971). The computation of eigenvalues and eigenvectors of very large sparse matrices. PhD thesis, University of London.

Physical validation¶

The 4-site antiferromagnetic Heisenberg chain (H = ½ Σ σ_i·σ_{i+1}, open BC) has ground-state energy E₀ = −3.2321 with our normalization, corresponding to E₀/J = −1.6160254 in the standard S = σ/2 convention.

static heisenberg_1d(n_sites, J=1.0, hz=0.0)[source]¶

1D Heisenberg H = J sum (Xi Xi+1 + Yi Yi+1 + Zi Zi+1) + hz sum Zi (open BC).

XX+YY = 2(S+S- + S-S+): flips adjacent antiparallel spins. ZZ: diagonal. For spin-1/2: S+|0>=|1>, S+|1>=0; S-|1>=|0>, S-|0>=0 (|0>=up, |1>=down). Xi Xi+1 + Yi Yi+1 = 2(S+i S-i+1 + S-i S+i+1) where S+/- = sigma+/-/2. Matrix element for antiparallel flip: J * 0.5.

static xxz_chain(n_sites, J=1.0, delta=1.0, hz=0.0)[source]¶

1D XXZ spin chain (open BC).

\[H = J \sum_{i=0}^{n-2} \left[ \frac{1}{2}(\sigma^+_i \sigma^-_{i+1} + \text{h.c.}) + \Delta\, Z_i Z_{i+1} \right] + h_z \sum_i Z_i\]

where \(\sigma^+ = \begin{pmatrix}0&1\\0&0\end{pmatrix}\), J is the overall exchange scale, and delta (Δ) is the anisotropy ratio.

Special cases:

  • delta=1: isotropic Heisenberg antiferromagnet; xxz_chain(n, J=J, delta=1) equals heisenberg_1d(n, J=J)

  • delta=0: XX model (free-fermion), no ZZ coupling

  • delta→∞: classical Ising limit

Parameters:

  • n_sites (int) – Number of spins. Must be >= 1.

  • J (float) – Overall exchange coupling (energy scale).

  • delta (float) – Anisotropy Δ = J_z / J_xy.

  • hz (float) – Uniform longitudinal field.

2D Heisenberg model on an Lx × Ly rectangular lattice (open BC).

\[H = J \sum_{\langle ij \rangle} \left[ Z_i Z_j + \frac{1}{2}(\sigma^+_i \sigma^-_j + \text{h.c.}) \right]\]

Sites are labelled (x, y) → x + y·Lx. Bonds connect (x, y)–(x+1, y) (horizontal) and (x, y)–(x, y+1) (vertical).

Parameters:

static bose_hubbard(L, t=1.0, U=4.0, max_occ=4)[source]¶

Bose-Hubbard model on a 1D chain (open BC).

\[H = -t \sum_i (a^\dagger_i a_{i+1} + \text{h.c.}) + \frac{U}{2} \sum_i n_i(n_i - 1)\]

Fock basis: each site holds 0 … max_occ bosons. State index:

\[\text{idx} = \sum_{i=0}^{L-1} n_i \cdot M^i, \quad M = \text{max\_occ} + 1\]

Hilbert space dimension: (max_occ + 1)^L.

Parameters:

  • L (int) – Number of sites.

  • t (float) – Hopping amplitude.

Physical validation¶

For non-commuting terms, the 2nd-order (symmetric) decomposition S₂ satisfies ‖S₂(t,n) − e^{−iHt}‖ = O((t/n)³) while 1st-order satisfies O((t/n)²). With H = 0.5·XZ + 0.3·ZZ (non-commuting), t = 1, n = 4 steps:

order-1 error ≈ 3.5 × 10⁻², order-2 error ≈ 1.2 × 10⁻³.

Provides first-, second-, and fourth-order Suzuki-Trotter decompositions for Hamiltonians expressed as weighted sums of Pauli strings:

H = Σ_k  c_k  P_k,   P_k ∈ {I, X, Y, Z}^⊗n

Each term is exponentiated analytically using the identity:

exp(-i θ P) = cos(θ) I - i sin(θ) P

which holds for any Pauli string because P² = I. No full matrix exponentiation is needed for individual terms.

McLachlan Variational Integration¶

M122: McLachlan variational quantum dynamics.

Implements time evolution of parametrised quantum states via the McLachlan variational principle (MVP), which minimises

‖(iδ/δt - H)|ψ(θ)⟩‖²

M(θ) θ̇ = V(θ)

where M_ij = Re⟨∂_i ψ|∂_j ψ⟩ is the quantum geometric tensor (real part) and V_i = Re⟨∂_i ψ|(-iH)|ψ⟩ is the force vector.

Both real-time (Schrödinger) and imaginary-time evolution are supported.

Combination of multiple noise models applied simultaneously.

to_dict() is the union of the models’ payloads, so the models must emit disjoint keys. If two models emit the same key, building the composite (constructor or +) raises NoiseModelError; no entry is ever silently replaced.

In practice this allows at most one noise-kind model per composite. ThermalRelaxationNoise (t1_decay) and ReadoutNoise (bit_flip) both put their channel under the single key noise, because the native backend parses exactly one noise object per circuit (parse_noise_config in src/json_utils.cpp). A second one has no slot to go to: merging the two would drop a channel. CompositeNoise([DepolarizingNoise(0.005),

CompositeNoise([ThermalRelaxationNoise(T1=1e5, T2=6e4, t_gate=50),

Error Mitigation¶

Quantum error mitigation for the QuantX engine.

Provides two complementary mitigation techniques:

Zero-Noise Extrapolation (ZNE) — run circuits at artificially amplified noise levels (via gate folding) then extrapolate the results back to zero noise using Richardson, polynomial, or exponential fitting.

Probabilistic Error Cancellation (PEC) — decompose ideal gates as a quasi-probability distribution over noisy implementations; sample circuits with associated ±weights and take a weighted mean to obtain an unbiased estimator of the noiseless expectation value.

Both techniques operate through a user-supplied executor callable:

executor(ops: list[dict]) -> float

where each op dict has the shape {"name": str, "qubits": list[int], "params": list[float]}. A convenience factory make_sv_executor() builds one from GpuStatevector.

Quick-start example:

from quantx_engine.mitigation import (
    zne_mitigate, pec_mitigate, make_sv_executor,
    RichardsonExtrapolator,
)

# Build a statevector executor: run bell-state circuit, measure <Z0>
executor = make_sv_executor(n_qubits=2, observable_fn=lambda sv: sv.expectation_z(0))

bell_ops = [
    {"name": "H",    "qubits": [0], "params": []},
    {"name": "CNOT", "qubits": [0, 1], "params": []},
]

# ZNE with Richardson extrapolation at scale factors 1, 3, 5
result = zne_mitigate(bell_ops, executor, scale_factors=[1, 3, 5])
print(result.mitigated_value)

# PEC with 2% depolarizing noise per gate, 500 samples
result = pec_mitigate(bell_ops, noisy_executor, noise_prob=0.02, n_samples=500)
print(result.mitigated_value, "±", result.std_error)

class quantx_engine.mitigation.QuasiProbabilityDecomposition(basis, gamma)[source]¶

Bases: object

Quasi-probability decomposition (QPD) of an ideal single-qubit gate.

Represents the ideal gate as a signed sum of noisy implementations:

G_ideal = Σ_i q_i * (P_i · G_noisy)

where q_i can be negative (hence “quasi-probability”) and P_i is a Pauli operator prepended before the (noisy) gate.

The one-norm γ = Σ_i |q_i| > 1 quantifies the sampling overhead; the total number of circuit samples required to achieve standard error ε scales as O(γ^{2m} / ε²) for an m-gate circuit.

  • basis (list[tuple[str, float, float]]) – List of (pauli_name, sign, sample_prob) tuples where: - pauli_name ∈ {"I", "X", "Y", "Z"}, - sign = +1.0 or −1.0, - sample_prob = |q_i| / γ (positive, sums to 1).

  • gamma (float) – One-norm of the quasi-probability distribution.

classmethod from_depolarizing(noise_prob)[source]¶

Build the QPD for a gate subject to single-qubit depolarizing noise.

Models the noisy channel as:

Λ_p(ρ) = (1-p)ρ + (p/3)(XρX + YρY + ZρZ)

and inverts it to recover the ideal gate. This is the Pauli-error parameterisation: DepolarizingNoise with probability p is (1 − p)ρ + p·I/2, which is this channel at noise_prob = 3p/4. The resulting quasi-probability weights are:

  • q_I = (1 − p/3) / (1 − 4p/3) [positive]

  • q_X = q_Y = q_Z = −(p/3) / (1 − 4p/3) [negative for p > 0]

  • γ = (1 + 2p/3) / (1 − 4p/3)

Run probabilistic error cancellation and return the mitigated expectation.

For each of the n_samples Monte Carlo trials, an independent Pauli twirl is sampled for every single-qubit gate in ops and prepended to it. The trial result is multiplied by a weight of γ^m · Π sign_i and the weighted mean over all trials converges to the noiseless expectation value.

Two-qubit gates are passed through unmodified (no twirl applied).

Lindblad Master Equation¶

Lindblad open-system dynamics for the QuantX engine.

Wraps the native C++ lindblad_backend (RK4 density-matrix evolution, Wootters concurrence, log-negativity, mutual information) with a clean Python API.

The Lindblad master equation:

dρ/dt = −i[H, ρ] + Σ_k γ_k (L_k ρ L_k† − ½{L_k†L_k, ρ})

is integrated by the C++ backend using a 4th-order Runge-Kutta scheme with automatic Hermitian re-symmetrisation at every step to suppress numerical drift.

Supported collapse channels (single-qubit, specified via JumpOperator):

  • "amplitude_damping" — L = √γ σ⁻ (energy relaxation T₁)

  • "dephasing" — L = √γ σz/2 (pure dephasing T₂)

  • "depolarizing" — three operators √(γ/3)·{σx, σy, σz}

Maximum system size: 10 qubits (C++ backend limit; dense 2ⁿ × 2ⁿ matrix).

Quick-start example:

from quantx_engine import Engine
from quantx_engine.lindblad import LindbladSolver, JumpOperator

engine = Engine()
solver = LindbladSolver(engine)

# Single qubit with amplitude damping (T1 decay)
result = solver.solve(
    n_qubits=1,
    hamiltonian_terms=[],          # no coherent drive
    jump_operators=[JumpOperator("amplitude_damping", qubit=0, rate=0.5)],
    total_time=4.0,
    dt=0.05,
)
print(result.final_purity)         # → ~0 (fully mixed at long time)
print(result.times[-1])            # → 4.0

# Two-qubit system: Heisenberg XY + dephasing on both qubits
result = solver.solve(
    n_qubits=2,
    hamiltonian_terms=[(0.5, "X0X1"), (0.5, "Y0Y1")],
    jump_operators=[
        JumpOperator("dephasing", qubit=0, rate=0.1),
        JumpOperator("dephasing", qubit=1, rate=0.1),
    ],
    total_time=10.0,
    dt=0.1,
    entanglement_cut=1,            # track bipartite entanglement A=[0], B=[1]
)
print(result.entanglement.concurrence[-1])  # concurrence decays to 0

Physical validation¶

Single-qubit amplitude damping (L = sqrt(gamma)*sigma-): the excited state population decays exponentially as p_e(t) = exp(-gamma*t) [Lindblad1976]. Trace preservation: Tr(rho(t)) = 1 for all t (Lindblad master equation preserves positivity and trace) [Gorini1976].
