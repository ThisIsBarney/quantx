Quantum Error Correction¶

Modules implementing quantum error correcting codes, fault-tolerant architectures, logical qubit encodings, and bosonic codes.

Stabilizer Codes¶

Quantum Error Correction research toolkit for the QuantX engine.

Implements stabilizer codes, syndrome decoding, and logical error rate estimation in pure Python / NumPy.

Codes included:

RepetitionCode(n) — [[n, 1, n]] (odd n): protects against bit-flip errors SurfaceCode(d) — rotated planar [[d², 1, d]]: industry standard for FTQC

Decoders:

RepetitionCode — majority vote (optimal for independent errors) SurfaceCode — minimum-weight syndrome graph matching (greedy MWPM)

Usage:

from quantx_engine.contrib.qec import SurfaceCode, LogicalErrorSimulator

code = SurfaceCode(d=3) sim = LogicalErrorSimulator(code)

# Single-shot logical error rate at p=0.01 p_L = sim.logical_error_rate(p_phys=0.01, n_trials=10000)

# Threshold sweep result = sim.threshold_sweep(p_range=(0.001, 0.15), n_points=12, n_trials=5000) print(f”Estimated threshold: {result.threshold:.4f}”)

d=3 surface code with MWPM decoding has threshold ~1% for independent depolarising noise [Fowler2012]. Repetition code corrects all single-qubit bit-flip errors for any distance d >= 3 (verified in test suite).

class quantx_engine.contrib.qec.MWPMDecoder(code, max_exact=10)[source]¶

Bases: object

Minimum-Weight Perfect Matching decoder for stabilizer codes (M78).

Uses an exact bitmask-DP MWPM solver for small syndrome sizes and a greedy nearest-neighbour fallback for larger ones. The syndrome graph infrastructure from SurfaceCode is reused directly, so the decoder is compatible with any code that exposes _build_syndrome_graph, _syndrome_graph_bfs, z_stabs, x_stabs, and n.

Unlike the built-in greedy decoder in SurfaceCode, MWPM finds the globally optimal correction (minimum total edge weight), which reduces the logical error rate — especially at low physical error rates.

Parameters:

  • code (SurfaceCode | RepetitionCode) – A SurfaceCode or RepetitionCode instance.

  • max_exact (int) – Maximum number of actual defects for which the exact bitmask-DP solver is used. The DP operates on 2 * n_defects nodes; the default of 10 defects corresponds to 20 DP nodes, which runs in ~20 ms. For larger syndrome sizes the greedy fallback is used.

Examples

>>> code = SurfaceCode(d=5)
>>> decoder = MWPMDecoder(code)
>>> x_errors = [0] * 25
>>> x_errors[3] = 1
>>> syn = code.z_syndrome(x_errors)
>>> correction = decoder.decode_x(syn)

Surface Code & Fault-Tolerant Thresholds¶

Fault-tolerant logical qubits — M91.

Provides:

  • LogicalQubit — encode, apply logical Clifford gates, and decode using a distance-d repetition code or surface code backed by the MWPM decoder from quantx_engine.contrib.qec.

  • MagicStateDistillery — 15-to-1 magic state distillation protocol for injecting T gates into a fault-tolerant computation.

  • FaultTolerantCircuit — compile a logical gate sequence to a list of physical operations that can be dispatched to LogicalQubit.

All simulations are purely classical (no statevector), operating on syndrome tables and logical Pauli frames, which is the standard technique for fault-tolerant threshold analysis.

Fault-Tolerant T-Gate Synthesis¶

Magic state distillation, T-gate synthesis via resource states.

M120: Fault-tolerant T gate via magic state injection.

Implements four components for fault-tolerant T-gate synthesis:

  • MagicStateFactory — simulates 7-to-1 and 15-to-1 magic state distillation protocols to produce high-fidelity |T⟩ states.

  • FTTGate — gate-teleportation T gate consuming one |T⟩ magic state.

  • FTCCXGate — fault-tolerant Toffoli via the Clifford+T decomposition (7 T gates, Selinger 2013).

  • TCountOptimizer — T-count/T-depth analyser and algebraic reducer.

Fault-Tolerant QC Pipeline¶

End-to-end FTQC pipeline: logical encoding → magic-state distillation → decoding.

M112: Fault-tolerant QC end-to-end pipeline.

Ties SurfaceCode and MWPMDecoder into a single FTQCPipeline object that simulates the complete error-correction cycle:

encode → (logical gate →)* n_rounds × syndrome extraction → MWPM decode → check

Two noise models are supported:

  • Code-capacity (n_rounds=1, p_meas=0): ideal stabilizer measurements; only data qubit errors are injected.

  • Phenomenological (n_rounds > 1, p_meas > 0): every syndrome measurement may flip independently with probability p_meas; data errors accumulate across rounds and the final ideal syndrome is decoded.

The threshold_curve() function sweeps p_phys over a range for multiple code distances and estimates the threshold crossing point — the physical error rate below which increasing d strictly improves the logical error rate.

Simulates the full error-correction cycle:

  1. Encode logical |0⟩ (or |1⟩) using a distance-d surface code.

  2. Inject independent depolarizing noise on each data qubit per round.

Bosonic Qubits (M120)¶

Cat qubits, GKP codes, Fock-space operators, bosonic channel noise.

M119: Bosonic codes — cat qubits and GKP (Gottesman-Kitaev-Preskill) codes.

Provides hardware-biased-noise bosonic encodings that are at the centre of near-term fault-tolerant quantum computing roadmaps (AWS, Yale cat-qubit, INRIA/Alice&Bob).

Cat qubits¶

A Kerr-cat qubit encodes a logical qubit in the two coherent-state superpositions |C_α±⟩ ∝ |α⟩ ± |−α⟩ inside a driven Kerr oscillator:

H = −K a†²a² + ε₂(a†² + a²)

Bit-flip errors (X_L) are exponentially suppressed ~ exp(−2|α|²) while phase-flip errors (Z_L) scale polynomially, yielding a biased noise channel ideal for concatenation with a repetition code.

GKP codes¶

The Gottesman-Kitaev-Preskill code encodes a qubit in a harmonic oscillator whose Hilbert space is infinite-dimensional (or truncated at N_max photons). The logical code words are superpositions of squeezed states on a square phase-space lattice with spacing √π. We implement the finite-energy (approximate) GKP state with Gaussian envelope parameter δ and the small-big-small (SBS) correction sequence for shift errors.

Measurement-Based QC (MBQC)¶

Graph states, cluster state preparation, one-way computation.

M125: Measurement-based quantum computation (MBQC).

Implements the one-way quantum computation model (1WQC / cluster-state QC):

  1. Prepare a resource state — a graph state |G⟩ on the vertices of a graph G.

  3. Read off the result from the remaining (output) qubits, correcting for the randomness of each measurement outcome using feed-forward (Pauli corrections).
